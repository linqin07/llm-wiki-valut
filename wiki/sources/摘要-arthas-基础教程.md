## 核心摘要
Arthas 基础教程共 4 篇，系统介绍了阿里巴巴开源的 Java 诊断工具。涵盖基础命令（sc/sm/watch/trace）、线程诊断（thread 命令及 CPU 占比统计）、热部署（redefine 命令实现字节码替换）和编译反编译（jad/mc 命令）。核心工作流为：sc 定位类 → sm 定位方法 → watch/trace 深度观察，热更新通过 jad → mc → redefine 实现。
