## 定义
JHipster 是快速开发 Web 应用的脚手架工具，支持 Java 和多种前端框架。

## 安装
- JDK8：`npm install -g generator-jhipster@5.7.0`
- Java11+：`npm install -g generator-jhipster`

## 官方蓝图
- Kotlin 蓝图：`npm install -g generator-jhipster-kotlin`，使用 `khipster` 命令
- Vue.js 蓝图：`npm install -g generator-jhipster-vuejs`，使用 `jhipster --blueprints vuejs`
