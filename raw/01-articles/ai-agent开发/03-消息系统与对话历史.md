## 消息类型详解

LangChain 中的消息是与 LLM 交互的基本单元。每种消息类型有不同的用途。

### HumanMessage（用户消息）

代表用户的输入。

```python
from langchain_core.messages import HumanMessage

# 创建用户消息
msg = HumanMessage(content="你好，今天天气怎么样？")

print(msg.type)     # "human"
print(msg.content)  # "你好，今天天气怎么样？"
```

### AIMessage（AI回复）

代表 AI 的回复，包含回复内容和元数据。

```python
from langchain_core.messages import AIMessage

# 创建 AI 消息
msg = AIMessage(content="你好！今天天气很好，适合出门。")

print(msg.type)     # "ai"
print(msg.content)  # "你好！今天天气很好，适合出门。"

# 当 AI 调用工具时，AIMessage 会包含 tool_calls
# msg.tool_calls = [{"name": "get_weather", "args": {...}, "id": "..."}]
```

### SystemMessage（系统消息）

定义 AI 的角色、行为规则和上下文。通常放在对话的最前面。

```python
from langchain_core.messages import SystemMessage

# 创建系统消息
msg = SystemMessage(content="你是一个专业的Python编程助手，请用中文回答。")

print(msg.type)     # "system"
print(msg.content)  # "你是一个专业的Python编程助手，请用中文回答。"
```

### ToolMessage（工具消息）

代表工具调用的结果，由工具执行后自动生成。

```python
from langchain_core.messages import ToolMessage

# 通常由系统自动生成，不需要手动创建
msg = ToolMessage(
    content='{"temperature": 25, "condition": "晴天"}',
    tool_call_id="call_abc123"  # 关联到哪个工具调用
)

print(msg.type)     # "tool"
print(msg.content)  # '{"temperature": 25, "condition": "晴天"}'
```

### 四种消息类型对比

```
对话流程中的消息类型：

[SystemMessage]  →  设置 AI 的角色和规则（通常只在开头）
      │
[HumanMessage]   →  用户的输入/问题
      │
[AIMessage]      →  AI 的回复（纯文本或包含工具调用）
      │
[ToolMessage]    →  工具执行的结果（如果 AI 调用了工具）
      │
[AIMessage]      →  AI 基于工具结果的最终回复
      │
[HumanMessage]   →  用户的下一个问题
      │
    ...（循环）
```

### 消息类型详细对比表

| 消息类型 | type 值 | 来源 | 常见用途 | 是否需要手动创建 |
|---------|---------|------|---------|----------------|
| SystemMessage | "system" | 开发者 | 设定角色、规则 | 是 |
| HumanMessage | "human" | 用户 | 用户输入 | 是 |
| AIMessage | "ai" | AI | AI 回复 | 通常由模型返回 |
| ToolMessage | "tool" | 工具 | 工具执行结果 | 通常自动生成 |

## 字典格式 vs 对象格式

LangChain 同时支持字典格式和消息对象格式，它们可以互相转换。

### 字典格式

```python
# 字典格式：简单直观
messages = [
    {"role": "system", "content": "你是一个AI助手"},
    {"role": "user", "content": "你好"},
]

response = model.invoke(messages)
```

### 对象格式

```python
from langchain_core.messages import HumanMessage, AIMessage, SystemMessage

# 对象格式：类型安全
messages = [
    SystemMessage(content="你是一个AI助手"),
    HumanMessage(content="你好"),
]

response = model.invoke(messages)
```

### 格式转换

```python
from langchain_core.messages import HumanMessage, AIMessage, SystemMessage

# 字典 → 对象
def dict_to_message(msg_dict):
    role = msg_dict["role"]
    content = msg_dict["content"]

    if role == "system":
        return SystemMessage(content=content)
    elif role == "user":
        return HumanMessage(content=content)
    elif role == "assistant":
        return AIMessage(content=content)
    else:
        raise ValueError(f"Unknown role: {role}")

# 对象 → 字典
def message_to_dict(msg):
    return {"role": msg.type, "content": msg.content}


# 批量转换
dict_messages = [
    {"role": "system", "content": "你是一个AI助手"},
    {"role": "user", "content": "你好"},
]

obj_messages = [dict_to_message(m) for m in dict_messages]
```

### 对比表

| 特性 | 字典格式 | 对象格式 |
|------|---------|---------|
| 代码简洁度 | 更简洁 | 稍长 |
| 类型安全 | 无 | 有 |
| IDE 自动补全 | 无 | 有 |
| 可读性 | 好 | 更好 |
| 错误提示 | 运行时报错 | 编辑时提示 |
| 推荐场景 | 快速脚本 | **正式开发** |

## 对话历史管理核心规则

### 规则一：每次调用必须传递完整历史

LLM 是**无状态的**——每次调用都是独立的，不记得之前的对话。
要实现多轮对话，必须在每次调用时把**完整的对话历史**一起发送。

```
第 1 轮对话：
发送给 LLM：[SystemMessage, HumanMessage("你好")]

第 2 轮对话：
发送给 LLM：[SystemMessage, HumanMessage("你好"), AIMessage("你好！..."),
              HumanMessage("你叫什么名字？")]

第 3 轮对话：
发送给 LLM：[SystemMessage, HumanMessage("你好"), AIMessage("你好！..."),
              HumanMessage("你叫什么名字？"), AIMessage("我叫..."),
              HumanMessage("还记得我吗？")]
```

### 规则二：历史必须按顺序排列

消息的顺序很重要，必须严格按照对话的时间顺序排列。

```
正确顺序：
[SystemMessage] → [HumanMessage] → [AIMessage] → [HumanMessage] → [AIMessage]

错误顺序：
[HumanMessage] → [AIMessage] → [SystemMessage]  ← System 消息应在最前面
[HumanMessage] → [HumanMessage] → [AIMessage]   ← 连续两条用户消息不符合对话逻辑
```

### 规则三：历史消息的结构

```
完整对话历史结构：

[
    SystemMessage("你是一个AI助手"),           ← 系统提示（可选，但推荐）
    HumanMessage("第1个问题"),                  ← 用户输入
    AIMessage("第1个回答"),                     ← AI 回复
    HumanMessage("第2个问题"),                  ← 用户输入
    AIMessage("第2个回答"),                     ← AI 回复
    ...                                         ← 更多轮次
    HumanMessage("当前问题"),                   ← 当前用户输入
]
```

## "错误方式"演示：不传历史导致AI失忆

### 错误示例：每次只传当前消息

```python
"""
错误示例：不传递对话历史
结果：AI 完全不记得之前的对话内容
"""

import os
from dotenv import load_dotenv
from langchain.chat_models import init_chat_model
from langchain_core.messages import HumanMessage

load_dotenv()
model = init_chat_model("groq:llama-3.3-70b-versatile")

# 第1轮：告诉AI名字
response1 = model.invoke([HumanMessage(content="你好，我叫小明")])
print(f"AI: {response1.content}")

# 第2轮：问AI是否记得名字（错误方式：不传历史）
response2 = model.invoke([HumanMessage(content="你还记得我叫什么名字吗？")])
print(f"AI: {response2.content}")  # AI 不记得！因为没有传历史
```

**输出示例：**
```
AI: 你好小明！很高兴认识你。
AI: 抱歉，我无法记住之前的对话内容...（AI 失忆了！）
```

### 正确示例：传递完整历史

```python
"""
正确示例：传递完整对话历史
结果：AI 能够记住之前的对话内容
"""

import os
from dotenv import load_dotenv
from langchain.chat_models import init_chat_model
from langchain_core.messages import HumanMessage, AIMessage, SystemMessage

load_dotenv()
model = init_chat_model("groq:llama-3.3-70b-versatile")

# 初始化对话历史
chat_history = [SystemMessage(content="你是一个友好的AI助手")]

# 第1轮：告诉AI名字
chat_history.append(HumanMessage(content="你好，我叫小明"))
response1 = model.invoke(chat_history)
chat_history.append(AIMessage(content=response1.content))  # 保存AI回复！
print(f"AI: {response1.content}")

# 第2轮：问AI是否记得名字（正确方式：传完整历史）
chat_history.append(HumanMessage(content="你还记得我叫什么名字吗？"))
response2 = model.invoke(chat_history)
chat_history.append(AIMessage(content=response2.content))  # 保存AI回复！
print(f"AI: {response2.content}")  # AI 记得！因为传了完整历史
```

**输出示例：**
```
AI: 你好小明！很高兴认识你。
AI: 当然记得！你叫小明。（AI 记住了！）
```

### 错误 vs 正确对比图

```
❌ 错误方式（AI 失忆）：

第1轮：model.invoke(["我叫小明"])  →  AI: "你好小明！"
第2轮：model.invoke(["我叫什么"])  →  AI: "我不知道..."  ← 历史丢失！

✅ 正确方式（AI 记忆）：

历史 = []

第1轮：
  历史 += ["我叫小明"]
  model.invoke(历史)  →  AI: "你好小明！"
  历史 += ["你好小明！"]

第2轮：
  历史 += ["我叫什么"]
  model.invoke(历史)  →  AI: "你叫小明！"  ← 历史完整！
```

## 对话历史管理策略

### 策略 1：保存所有消息

最简单的策略，保留完整的对话历史。

```python
class ChatSession:
    """简单的对话会话管理"""

    def __init__(self, model, system_prompt="你是一个AI助手"):
        self.model = model
        self.history = [SystemMessage(content=system_prompt)]

    def chat(self, user_input: str) -> str:
        """发送消息并获取回复"""
        # 添加用户消息
        self.history.append(HumanMessage(content=user_input))

        # 调用模型（传递完整历史）
        response = self.model.invoke(self.history)

        # 保存AI回复到历史
        self.history.append(AIMessage(content=response.content))

        return response.content

    def get_history(self):
        """获取对话历史"""
        return self.history

    def clear_history(self):
        """清空历史"""
        self.history = [self.history[0]]  # 保留系统提示


# 使用示例
if __name__ == "__main__":
    import os
    from dotenv import load_dotenv
    from langchain.chat_models import init_chat_model

    load_dotenv()
    model = init_chat_model("groq:llama-3.3-70b-versatile")

    session = ChatSession(model, system_prompt="你是一个Python编程助手")

    # 多轮对话
    print(f"用户: 什么是列表？")
    print(f"AI: {session.chat('什么是列表？')}")

    print(f"\n用户: 能给个例子吗？")
    print(f"AI: {session.chat('能给个例子吗？')}")

    print(f"\n用户: 之前你解释了什么？")
    print(f"AI: {session.chat('之前你解释了什么？')}")
```

### 策略 2：保留最近N条消息（滑动窗口）

当对话很长时，保留所有历史会消耗大量 token。滑动窗口策略只保留最近的 N 条消息。

```python
from langchain_core.messages import SystemMessage, HumanMessage, AIMessage

class SlidingWindowChat:
    """滑动窗口对话管理"""

    def __init__(self, model, system_prompt="你是一个AI助手", max_messages=10):
        self.model = model
        self.system_msg = SystemMessage(content=system_prompt)
        self.messages = []  # 不含系统消息
        self.max_messages = max_messages

    def _get_window(self):
        """获取当前窗口内的消息"""
        # 保留最近 max_messages 条消息
        recent = self.messages[-self.max_messages:] if len(self.messages) > self.max_messages else self.messages
        return [self.system_msg] + recent

    def chat(self, user_input: str) -> str:
        # 添加用户消息
        self.messages.append(HumanMessage(content=user_input))

        # 获取窗口内的消息
        window = self._get_window()

        # 调用模型
        response = self.model.invoke(window)

        # 保存AI回复
        self.messages.append(AIMessage(content=response.content))

        return response.content


# 使用示例
if __name__ == "__main__":
    from dotenv import load_dotenv
    from langchain.chat_models import init_chat_model

    load_dotenv()
    model = init_chat_model("groq:llama-3.3-70b-versatile")

    session = SlidingWindowChat(model, max_messages=6)  # 保留最近6条（3轮对话）

    # 进行多轮对话
    questions = [
        "你好，我叫小明",
        "我今年25岁",
        "我在学Python",
        "我喜欢数据科学",
        "你还记得我叫什么吗？",   # 可能记得
        "我最开始说了什么？",     # 可能不记得（已超出窗口）
    ]

    for q in questions:
        print(f"用户: {q}")
        print(f"AI: {session.chat(q)}")
        print()
```

### 策略 3：智能压缩历史

当历史过长时，使用 LLM 将历史压缩成摘要。

```python
class CompressedHistoryChat:
    """带历史压缩的对话管理"""

    def __init__(self, model, system_prompt="你是一个AI助手", max_messages=20):
        self.model = model
        self.system_msg = SystemMessage(content=system_prompt)
        self.messages = []
        self.max_messages = max_messages

    def _compress_history(self):
        """使用 LLM 压缩历史消息"""
        # 将历史消息转换为文本
        history_text = "\n".join([
            f"{msg.type}: {msg.content}" for msg in self.messages
        ])

        # 用 LLM 生成摘要
        compress_prompt = [
            SystemMessage(content="请将以下对话历史压缩成简短摘要，保留关键信息："),
            HumanMessage(content=history_text)
        ]

        summary = self.model.invoke(compress_prompt)

        # 用摘要替代历史
        self.messages = [
            HumanMessage(content=f"[对话历史摘要] {summary.content}")
        ]

    def chat(self, user_input: str) -> str:
        # 检查是否需要压缩
        if len(self.messages) > self.max_messages:
            self._compress_history()

        # 添加用户消息
        self.messages.append(HumanMessage(content=user_input))

        # 调用模型
        full_messages = [self.system_msg] + self.messages
        response = self.model.invoke(full_messages)

        # 保存AI回复
        self.messages.append(AIMessage(content=response.content))

        return response.content
```

### 三种策略对比

| 策略 | Token 消耗 | 记忆完整性 | 实现复杂度 | 适用场景 |
|------|-----------|-----------|-----------|---------|
| 保存全部 | 高 | 完整 | 最简单 | 短对话 |
| 滑动窗口 | 中 | 部分 | 简单 | **大多数场景** |
| 智能压缩 | 低 | 摘要级 | 复杂 | 超长对话 |

## 核心规则：保存AI回复到历史

这是实现多轮对话时**最容易遗漏**的关键步骤。

### 忘记保存的后果

```python
# ❌ 错误：忘记保存 AI 回复
def chat_wrong(self, user_input):
    self.history.append(HumanMessage(content=user_input))
    response = self.model.invoke(self.history)
    # 忘记这行：self.history.append(AIMessage(content=response.content))
    return response.content

# 第1轮：正常
chat_wrong("你好")  # AI: "你好！"

# 第2轮：历史中没有 AI 的上一条回复，对话逻辑断裂
chat_wrong("你刚才说了什么？")  # AI: "我没有说过什么..."（困惑）
```

### 正确实现

```python
# ✅ 正确：完整的消息保存流程
def chat_correct(self, user_input):
    # 1. 保存用户消息
    self.history.append(HumanMessage(content=user_input))

    # 2. 调用模型
    response = self.model.invoke(self.history)

    # 3. 保存 AI 回复（关键步骤！）
    self.history.append(AIMessage(content=response.content))

    # 4. 返回回复
    return response.content
```

## 对话历史与token消耗的关系

### Token 消耗计算

```
每次调用消耗的 token = 系统提示 + 完整对话历史 + 当前输入 + AI 输出

示例：
  SystemMessage:    20 tokens
  第1轮 Human:      10 tokens
  第1轮 AI:         50 tokens
  第2轮 Human:      10 tokens
  第2轮 AI:         50 tokens
  第3轮 Human:      10 tokens  ← 当前输入
  第3轮 AI:         50 tokens  ← AI 输出
  ─────────────────────────
  总计：200 tokens（第3轮调用）

随着对话轮次增加，token 消耗呈线性增长！
```

### Token 增长图

```
Token消耗
    │
2000│                                              *
    │                                          *
1500│                                      *
    │                                  *
1000│                             *
    │                        *
 500│                   *
    │              *
 100│         *
    │    *
   0│*
    └──────────────────────────────────────────→ 对话轮次
     1    2    3    4    5   ...   10   ...   20
```

### 控制 Token 消耗的方法

```python
# 方法1：限制对话轮次
class LimitedRoundChat:
    def __init__(self, model, max_rounds=10):
        self.model = model
        self.history = []
        self.max_rounds = max_rounds

    def chat(self, user_input):
        self.history.append(HumanMessage(content=user_input))

        # 如果超过最大轮次，只保留最近的消息
        if len(self.history) // 2 > self.max_rounds:
            # 保留最近 max_rounds 轮对话
            self.history = self.history[-(self.max_rounds * 2):]

        response = self.model.invoke(self.history)
        self.history.append(AIMessage(content=response.content))
        return response.content


# 方法2：限制总 token 数
class TokenLimitedChat:
    def __init__(self, model, max_tokens=4000):
        self.model = model
        self.history = []
        self.max_tokens = max_tokens

    def _estimate_tokens(self, messages):
        """粗略估算 token 数（1个中文字约2-3个token）"""
        total = 0
        for msg in messages:
            total += len(msg.content) * 2  # 粗略估算
        return total

    def chat(self, user_input):
        self.history.append(HumanMessage(content=user_input))

        # 如果 token 超限，移除最早的消息
        while self._estimate_tokens(self.history) > self.max_tokens and len(self.history) > 2:
            self.history.pop(0)  # 移除最早的消息

        response = self.model.invoke(self.history)
        self.history.append(AIMessage(content=response.content))
        return response.content
```

## 完整多轮对话示例

### 终端聊天程序

```python
"""
完整多轮对话示例
功能：终端交互式聊天机器人
"""

import os
from dotenv import load_dotenv
from langchain.chat_models import init_chat_model
from langchain_core.messages import HumanMessage, AIMessage, SystemMessage

load_dotenv()


class ChatBot:
    """聊天机器人"""

    def __init__(self, model_id="groq:llama-3.3-70b-versatile", system_prompt=None):
        self.model = init_chat_model(model_id)
        self.system_prompt = system_prompt or "你是一个友好的AI助手，请用中文回答。"
        self.history = [SystemMessage(content=self.system_prompt)]
        self.max_history = 20  # 最多保留20条消息

    def chat(self, user_input: str) -> str:
        """发送消息并获取回复"""
        # 添加用户消息
        self.history.append(HumanMessage(content=user_input))

        # 裁剪历史（保留系统消息 + 最近的消息）
        if len(self.history) > self.max_history + 1:
            self.history = [self.history[0]] + self.history[-(self.max_history):]

        # 调用模型
        response = self.model.invoke(self.history)

        # 保存AI回复
        self.history.append(AIMessage(content=response.content))

        return response.content

    def show_history(self):
        """显示对话历史"""
        print("\n--- 对话历史 ---")
        for msg in self.history:
            if msg.type == "system":
                print(f"[系统] {msg.content[:50]}...")
            elif msg.type == "human":
                print(f"[用户] {msg.content}")
            elif msg.type == "ai":
                print(f"[AI] {msg.content[:80]}...")
        print("--- 历史结束 ---\n")

    def clear(self):
        """清空历史"""
        self.history = [SystemMessage(content=self.system_prompt)]
        print("对话历史已清空。")


def main():
    """主函数：交互式聊天"""
    bot = ChatBot(
        system_prompt="你是一个Python编程专家，请用中文简洁地回答问题。"
    )

    print("=" * 50)
    print("聊天机器人已启动！")
    print("输入 'quit' 退出，'history' 查看历史，'clear' 清空历史")
    print("=" * 50)

    while True:
        user_input = input("\n你: ").strip()

        if not user_input:
            continue

        if user_input.lower() == 'quit':
            print("再见！")
            break

        if user_input.lower() == 'history':
            bot.show_history()
            continue

        if user_input.lower() == 'clear':
            bot.clear()
            continue

        # 获取AI回复
        try:
            response = bot.chat(user_input)
            print(f"\nAI: {response}")
        except Exception as e:
            print(f"\n错误：{e}")


if __name__ == "__main__":
    main()
```

## 常见错误

### 错误 1：忘记保存 AI 回复

```python
# ❌ 错误
history.append(HumanMessage(content="你好"))
response = model.invoke(history)
# 忘记：history.append(AIMessage(content=response.content))

# ✅ 正确
history.append(HumanMessage(content="你好"))
response = model.invoke(history)
history.append(AIMessage(content=response.content))  # 必须保存！
```

### 错误 2：消息顺序错误

```python
# ❌ 错误：SystemMessage 放在中间
history = [
    HumanMessage(content="你好"),
    SystemMessage(content="你是AI助手"),  # 应该在最前面！
]

# ✅ 正确：SystemMessage 放在最前面
history = [
    SystemMessage(content="你是AI助手"),
    HumanMessage(content="你好"),
]
```

### 错误 3：每轮都重新创建历史

```python
# ❌ 错误：每轮都创建新历史
for user_input in user_inputs:
    history = [SystemMessage(content="你是AI助手")]  # 每次都重置！
    history.append(HumanMessage(content=user_input))
    response = model.invoke(history)

# ✅ 正确：在循环外创建历史，循环内累积
history = [SystemMessage(content="你是AI助手")]
for user_input in user_inputs:
    history.append(HumanMessage(content=user_input))
    response = model.invoke(history)
    history.append(AIMessage(content=response.content))
```

### 错误 4：使用错误的消息类型

```python
# ❌ 错误：把用户输入放在 AIMessage 中
history.append(AIMessage(content="你好"))  # 这不是AI说的！

# ✅ 正确：使用正确的消息类型
history.append(HumanMessage(content="你好"))  # 用户说的
history.append(AIMessage(content="你好！"))   # AI说的
```

### 错误 5：历史过长导致超限

```python
# ❌ 错误：无限制地累积历史
history = []
for i in range(1000):
    history.append(HumanMessage(content=f"问题{i}"))
    history.append(AIMessage(content=f"回答{i}"))
# 历史太长，超过模型的上下文窗口！

# ✅ 正确：限制历史长度
MAX_HISTORY = 20
if len(history) > MAX_HISTORY:
    history = [history[0]] + history[-(MAX_HISTORY-1):]  # 保留系统消息 + 最近消息
```

## 最佳实践

1. **始终保存 AI 回复**：这是实现多轮对话的关键步骤。

2. **系统消息放在最前面**：`SystemMessage` 应该是历史中的第一条消息。

3. **限制历史长度**：避免历史过长导致 token 超限或成本过高。

4. **使用滑动窗口**：对于大多数场景，保留最近 10-20 条消息即可。

5. **监控 token 消耗**：通过 `response.usage_metadata` 跟踪每轮的 token 使用量。

6. **清理历史**：提供清空历史的功能，方便用户重新开始对话。

7. **错误处理**：处理模型调用失败的情况，避免历史中出现空消息。
