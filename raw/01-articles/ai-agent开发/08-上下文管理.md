## 1. 上下文窗口问题

### 什么是上下文窗口

上下文窗口（Context Window）是 LLM 单次调用能够处理的最大 token 数量。不同模型有不同的限制：

| 模型 | 上下文窗口 | 大约字数（中文） |
|------|-----------|----------------|
| Llama 3.3 70B | 128K tokens | ~64,000 字 |
| GPT-4 | 8K/32K/128K tokens | ~4,000/16,000/64,000 字 |
| Claude 3 | 200K tokens | ~100,000 字 |
| 小型模型 | 4K tokens | ~2,000 字 |

### Token 计算的基本概念

```python
# Token 不等于字符或单词
# 英文：1个单词 ≈ 1-2个tokens
# 中文：1个汉字 ≈ 1-2个tokens

# 示例
text = "Hello, how are you?"  # ~5 tokens
text = "你好，你怎么样？"       # ~6 tokens
```

### 上下文窗口的组成

```
┌─────────────────────────────────────────────────────┐
│              上下文窗口 (例如 8192 tokens)            │
├─────────────────────────────────────────────────────┤
│                                                     │
│  ┌───────────────────────────────────────────────┐  │
│  │ 系统消息 (System Prompt)                      │  │
│  │ ~200-500 tokens                               │  │
│  └───────────────────────────────────────────────┘  │
│  ┌───────────────────────────────────────────────┐  │
│  │ 对话历史 (History)                            │  │
│  │ 随对话轮次增长...                              │  │
│  └───────────────────────────────────────────────┘  │
│  ┌───────────────────────────────────────────────┐  │
│  │ 工具调用结果 (Tool Results)                   │  │
│  │ 可能非常大...                                 │  │
│  └───────────────────────────────────────────────┘  │
│  ┌───────────────────────────────────────────────┐  │
│  │ 当前用户输入 (Current Input)                  │  │
│  │ ~100-1000 tokens                              │  │
│  └───────────────────────────────────────────────┘  │
│  ┌───────────────────────────────────────────────┐  │
│  │ 保留给回复的空间 (Reserved for Response)      │  │
│  │ ~1000-2000 tokens                             │  │
│  └───────────────────────────────────────────────┘  │
│                                                     │
└─────────────────────────────────────────────────────┘
```

## 2. 无限增长上下文的后果

### 超出限制报错

```python
# 当消息总token超过模型限制时
response = agent.invoke({
    "messages": [
        {"role": "user", "content": "很长的消息..." * 1000}
    ]
})
# 可能报错：BadRequestError: This model's maximum context length is 8192 tokens
```

### 成本增加

```
对话轮次    消息token数    API成本（假设$0.01/1K tokens）
─────────────────────────────────────────────────────
第1轮       500            $0.005
第5轮       2,500          $0.025
第10轮      5,000          $0.050
第50轮      25,000         $0.250   ← 成本飙升！
第100轮     50,000         $0.500   ← 可能超出限制
```

### 性能下降

1. **响应延迟增加**：处理更多token需要更长时间
2. **注意力分散**：模型可能忽略早期的重要信息
3. **重复输出**：模型可能重复之前说过的内容

## 3. SummarizationMiddleware 自动摘要

### 基本用法

```python
from langchain.agents.middleware import SummarizationMiddleware
from langchain.chat_models import init_chat_model
from langchain.agents import create_agent
from langgraph.checkpoint.memory import InMemorySaver

model = init_chat_model("groq:llama-3.3-70b-versatile")
checkpointer = InMemorySaver()

# 创建带自动摘要的Agent
agent = create_agent(
    model=model,
    tools=[],
    system_prompt="你是一个有帮助的助手。",
    checkpointer=checkpointer,
    middleware=[
        SummarizationMiddleware(token_threshold=2000)  # 超过2000 tokens时自动摘要
    ]
)
```

### token_threshold 参数

```python
# token_threshold：触发摘要的token阈值
SummarizationMiddleware(token_threshold=2000)   # 2000 tokens后触发
SummarizationMiddleware(token_threshold=4000)   # 4000 tokens后触发
SummarizationMiddleware(token_threshold=8000)   # 8000 tokens后触发

# 选择建议：
# - 小型模型（4K窗口）：token_threshold=1500
# - 中型模型（8K窗口）：token_threshold=3000
# - 大型模型（128K窗口）：token_threshold=30000
```

### summary_prompt 参数

```python
# 自定义摘要提示词
SummarizationMiddleware(
    token_threshold=2000,
    summary_prompt="请将以下对话历史压缩为简洁的摘要，保留关键信息："
)

# 中文优化的摘要提示词
SummarizationMiddleware(
    token_threshold=2000,
    summary_prompt="""请将以下对话历史压缩为简洁的中文摘要。
要求：
1. 保留用户的关键需求和偏好
2. 保留重要的事实信息
3. 保留未完成的任务
4. 忽略闲聊和重复内容
5. 摘要控制在200字以内"""
)
```

### 工作原理

```
┌─────────────────────────────────────────────────────────────┐
│              SummarizationMiddleware 工作流程                 │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  消息历史: [msg1, msg2, msg3, ..., msgN]                     │
│                                                             │
│  步骤1: 计算总token数                                        │
│  total_tokens = sum(token_count(msg) for msg in messages)   │
│                                                             │
│  步骤2: 检查是否超过阈值                                      │
│  if total_tokens > token_threshold:                         │
│                                                             │
│  步骤3: 将早期消息压缩为摘要                                  │
│  [msg1, msg2, ..., msgK] → summary_message                  │
│                                                             │
│  步骤4: 替换消息历史                                         │
│  [summary_message, msgK+1, ..., msgN]                       │
│                                                             │
│  步骤5: 继续正常执行                                         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 摘要前后对比

```
摘要前（3000 tokens）：
┌─────────────────────────────────────────────────────┐
│ System: 你是一个助手 (200 tokens)                    │
│ User: 我叫张三，我是程序员... (300 tokens)            │
│ AI: 你好张三... (200 tokens)                         │
│ User: 我住在北京... (250 tokens)                     │
│ AI: 好的... (150 tokens)                             │
│ User: 我的爱好是... (300 tokens)                     │
│ AI: 明白... (200 tokens)                             │
│ ... 更多对话 ... (1400 tokens)                       │
│ User: 最新的问题 (200 tokens)                        │
└─────────────────────────────────────────────────────┘

摘要后（1200 tokens）：
┌─────────────────────────────────────────────────────┐
│ System: 你是一个助手 (200 tokens)                    │
│ Summary: 用户张三，北京程序员，爱好篮球... (300 tokens) │
│ User: 最新的问题 (200 tokens)                        │
│ AI: 基于摘要的回答 (500 tokens)                      │
└─────────────────────────────────────────────────────┘
```

## 4. trim_messages 手动裁剪

### 基本用法

```python
from langchain_core.messages import trim_messages, SystemMessage, HumanMessage, AIMessage

# 原始消息列表
messages = [
    SystemMessage(content="你是一个助手"),
    HumanMessage(content="第一条消息"),
    AIMessage(content="第一条回复"),
    HumanMessage(content="第二条消息"),
    AIMessage(content="第二条回复"),
    HumanMessage(content="第三条消息"),
    AIMessage(content="第三条回复"),
    HumanMessage(content="当前问题"),
]

# 保留最近3条消息
trimmed = trim_messages(
    messages,
    max_tokens=1000,      # 最大token数
    strategy="last",       # 保留最后的消息
    token_counter=len,     # 简单计数（实际应使用tiktoken）
)

print(trimmed)
# [AIMessage(content="第三条回复"),
#  HumanMessage(content="当前问题")]
```

### 策略1：保留最近 N 条消息

```python
from langchain_core.messages import trim_messages

# 保留最近5条消息
trimmed = trim_messages(
    messages,
    max_messages=5,        # 最多5条消息
    strategy="last",
    start_on="human",      # 从Human消息开始
)

# 示例结果：
# 输入: [System, Human1, AI1, Human2, AI2, Human3, AI3, Human4]
# 输出: [AI2, Human3, AI3, Human4]  (从Human2开始的5条)
```

### 策略2：保留 System 消息 + 最近 N 条

```python
# 保留System消息 + 最近4条非System消息
trimmed = trim_messages(
    messages,
    max_messages=5,        # 总共5条（包括System）
    strategy="last",
    include_system=True,   # 始终保留System消息
)

# 示例结果：
# 输入: [System, Human1, AI1, Human2, AI2, Human3, AI3, Human4]
# 输出: [System, Human3, AI3, Human4]  (System + 最近3条)
```

### 策略3：按 token 数裁剪

```python
import tiktoken

# 使用tiktoken计算token数
def count_tokens(messages):
    encoding = tiktoken.encoding_for_model("gpt-4")
    total = 0
    for msg in messages:
        total += len(encoding.encode(msg.content))
    return total

# 按token数裁剪
trimmed = trim_messages(
    messages,
    max_tokens=2000,       # 最多2000 tokens
    token_counter=count_tokens,
    strategy="last",
    include_system=True,
)
```

### trim_messages 高级配置

```python
from langchain_core.messages import trim_messages

trimmed = trim_messages(
    messages,
    # 裁剪策略
    max_tokens=2000,
    max_messages=20,
    strategy="last",

    # 消息处理
    include_system=True,        # 保留System消息
    start_on="human",           # 从Human消息开始
    end_on=("human", "ai"),     # 以Human或AI消息结束

    # token计算
    token_counter=len,          # 或自定义函数

    # 允许的部分消息
    allow_partial=False,        # 是否允许截断单条消息
)
```

## 5. 策略对比表

| 特性 | SummarizationMiddleware | trim_messages | 组合策略 |
|------|------------------------|---------------|----------|
| **信息保留** | 高（摘要保留关键信息） | 低（直接丢弃旧消息） | 最高 |
| **实现复杂度** | 低（自动） | 中（需手动配置） | 中 |
| **Token控制** | 精确 | 精确 | 精确 |
| **历史连续性** | 好（摘要保持连续） | 差（可能断层） | 好 |
| **适用场景** | 长对话 | 短对话/高频调用 | 通用 |
| **性能开销** | 中（需要LLM生成摘要） | 低（纯裁剪） | 中 |
| **成本** | 中（额外LLM调用） | 低 | 中 |

## 6. 何时选择哪种策略

### 选择决策树

```
                    需要上下文管理？
                         │
                         ▼
                ┌────────────────┐
                │ 对话会很长吗？  │
                └────────────────┘
                   │           │
                  是           否
                   │           │
                   ▼           ▼
          ┌──────────────┐  ┌──────────────┐
          │ 需要保留关键  │  │ trim_messages│
          │ 信息吗？     │  │ 就够了       │
          └──────────────┘  └──────────────┘
             │         │
            是         否
             │         │
             ▼         ▼
    ┌──────────────┐  ┌──────────────┐
    │Summarization │  │ trim_messages│
    │Middleware    │  │              │
    └──────────────┘  └──────────────┘
```

### 具体场景推荐

| 场景 | 推荐策略 | 原因 |
|------|---------|------|
| 客服对话（长对话） | SummarizationMiddleware | 需要保留客户问题历史 |
| 实时聊天机器人 | trim_messages | 快速响应，历史不重要 |
| 代码助手 | 组合策略 | 需要保留代码上下文 |
| 翻译助手 | trim_messages | 只需要最近的翻译请求 |
| 知识问答 | SummarizationMiddleware | 需要保留问答历史 |
| 工具调用密集 | 组合策略 | 工具结果可能很大 |

## 7. 完整代码示例

### 示例1：SummarizationMiddleware 基础用法

```python
"""
SummarizationMiddleware 自动摘要示例
"""
from langchain.chat_models import init_chat_model
from langchain.agents import create_agent
from langchain.agents.middleware import SummarizationMiddleware
from langgraph.checkpoint.memory import InMemorySaver


def summarization_example():
    """演示自动摘要功能"""

    model = init_chat_model("groq:llama-3.3-70b-versatile")
    checkpointer = InMemorySaver()

    # 创建带自动摘要的Agent
    agent = create_agent(
        model=model,
        tools=[],
        system_prompt="你是一个有帮助的助手。",
        checkpointer=checkpointer,
        middleware=[
            SummarizationMiddleware(
                token_threshold=1500,  # 1500 tokens后触发摘要
                summary_prompt="请将对话历史压缩为简洁摘要，保留关键信息："
            )
        ]
    )

    config = {"configurable": {"thread_id": "summary-demo"}}

    # 模拟长对话
    conversations = [
        "我叫张三，我是一名Python程序员，住在北京。",
        "我今年28岁，已经工作5年了。",
        "我的公司是一家AI创业公司，我们做自然语言处理。",
        "最近我在学习LangChain，想构建AI应用。",
        "我的目标是做一个智能客服系统。",
        "你能帮我总结一下我们之前的对话吗？",
    ]

    for i, user_input in enumerate(conversations, 1):
        print(f"\n[轮次 {i}] 用户: {user_input}")
        response = agent.invoke(
            {"messages": [{"role": "user", "content": user_input}]},
            config=config
        )
        print(f"[轮次 {i}] AI: {response['messages'][-1].content}")


if __name__ == "__main__":
    summarization_example()
```

```python
        HumanMessage(content="能解释一下闭包吗？"),
    ]

    # 裁剪策略1：保留最近3条消息
    print("=" * 50)
    print("策略1：保留最近3条消息")
    print("=" * 50)

    trimmed = trim_messages(
        messages,
        max_messages=3,
        strategy="last",
        start_on="human",
    )

    for msg in trimmed:
        print(f"{msg.__class__.__name__}: {msg.content[:50]}...")

    # 裁剪策略2：保留System + 最近4条
    print("\n" + "=" * 50)
    print("策略2：保留System + 最近4条")
    print("=" * 50)

    trimmed = trim_messages(
        messages,
        max_messages=5,  # 1 System + 4 其他
        strategy="last",
        include_system=True,
    )

    for msg in trimmed:
        print(f"{msg.__class__.__name__}: {msg.content[:50]}...")

    # 裁剪策略3：按token数裁剪（简化示例）
    print("\n" + "=" * 50)
    print("策略3：按token数裁剪")
    print("=" * 50)

    def simple_token_counter(messages):
        """简单的token计数（实际应使用tiktoken）"""
        return sum(len(msg.content) // 2 for msg in messages)

    trimmed = trim_messages(
        messages,
        max_tokens=500,
        token_counter=simple_token_counter,
        strategy="last",
        include_system=True,
    )

    print(f"裁剪后消息数: {len(trimmed)}")
    for msg in trimmed:
        print(f"{msg.__class__.__name__}: {msg.content[:50]}...")


if __name__ == "__main__":
    trim_messages_example()
```

### 示例3：组合策略

```python
"""
组合策略示例：SummarizationMiddleware + trim_messages
"""
from langchain.chat_models import init_chat_model
from langchain.agents import create_agent
from langchain.agents.middleware import SummarizationMiddleware
from langchain_core.messages import trim_messages
from langgraph.checkpoint.memory import InMemorySaver


def combined_strategy():
    """组合策略：先摘要，再裁剪"""

    model = init_chat_model("groq:llama-3.3-70b-versatile")
    checkpointer = InMemorySaver()

    # 使用SummarizationMiddleware进行自动摘要
    # 当消息过多时，自动压缩为摘要
    agent = create_agent(
        model=model,
        tools=[],
        system_prompt="""你是一个有帮助的助手。
当对话历史很长时，请基于摘要回答问题。
不要重复已经说过的内容。""",
        checkpointer=checkpointer,
        middleware=[
            SummarizationMiddleware(
                token_threshold=2000,
                summary_prompt="""请将以下对话压缩为简洁摘要。

要求：
1. 保留用户的关键需求和偏好
2. 保留重要的事实信息
3. 保留未完成的任务
4. 忽略闲聊内容
5. 控制在200字以内"""
            )
        ]
    )

    config = {"configurable": {"thread_id": "combined-demo"}}

    # 模拟长对话
    long_conversations = [
        "我正在开发一个电商网站。",
        "后端用Python Flask，前端用React。",
        "数据库用PostgreSQL。",
        "需要实现用户注册登录功能。",
        "商品管理包括增删改查。",
        "订单系统需要支持多种支付方式。",
        "现在遇到一个性能问题...",
        "查询商品列表时很慢。",
        "已经加了索引但还是慢。",
        "你觉得应该怎么优化？",
    ]

    for i, user_input in enumerate(long_conversations, 1):
        print(f"\n[轮次 {i}] 用户: {user_input}")
        response = agent.invoke(
            {"messages": [{"role": "user", "content": user_input}]},
            config=config
        )
        print(f"[轮次 {i}] AI: {response['messages'][-1].content[:100]}...")


if __name__ == "__main__":
    combined_strategy()
```

### 示例4：自定义上下文管理器

```python
"""
自定义上下文管理器示例
"""
from langchain_core.messages import BaseMessage, SystemMessage, HumanMessage, AIMessage
from typing import List


class ContextManager:
    """自定义上下文管理器"""

    def __init__(self, max_tokens: int = 2000, keep_system: bool = True):
        self.max_tokens = max_tokens
        self.keep_system = keep_system

    def count_tokens(self, messages: List[BaseMessage]) -> int:
        """计算消息的token数（简化版本）"""
        total = 0
        for msg in messages:
            # 简化计算：中文约1.5 token/字
            total += int(len(msg.content) * 1.5)
        return total

    def trim(self, messages: List[BaseMessage]) -> List[BaseMessage]:
        """裁剪消息到指定token数"""
        if self.count_tokens(messages) <= self.max_tokens:
            return messages

        # 分离System消息
        system_messages = []
        other_messages = []

        for msg in messages:
            if isinstance(msg, SystemMessage) and self.keep_system:
                system_messages.append(msg)
            else:
                other_messages.append(msg)

        # 计算System消息的token数
        system_tokens = self.count_tokens(system_messages)
        available_tokens = self.max_tokens - system_tokens

        # 从后往前保留消息
        result = []
        current_tokens = 0

        for msg in reversed(other_messages):
            msg_tokens = self.count_tokens([msg])
            if current_tokens + msg_tokens <= available_tokens:
                result.insert(0, msg)
                current_tokens += msg_tokens
            else:
                break

        return system_messages + result

    def summarize(self, messages: List[BaseMessage], summary: str) -> List[BaseMessage]:
        """将消息替换为摘要"""
        system_messages = [msg for msg in messages if isinstance(msg, SystemMessage)]
        return system_messages + [AIMessage(content=f"[对话摘要] {summary}")]


# 使用示例
def custom_context_manager_example():
    """自定义上下文管理器示例"""

    manager = ContextManager(max_tokens=100, keep_system=True)

    messages = [
        SystemMessage(content="你是一个助手。"),
        HumanMessage(content="这是一条很长的消息" * 10),

    custom_context_manager_example()
```

## 8. 常见错误

### 错误1：token_threshold 设置过小

```python
# 错误：阈值太小，频繁触发摘要
SummarizationMiddleware(token_threshold=100)
# 问题：几乎每次调用都会触发摘要，增加延迟和成本

# 正确：根据模型窗口大小合理设置
# 8K窗口模型
SummarizationMiddleware(token_threshold=3000)
# 128K窗口模型
SummarizationMiddleware(token_threshold=30000)
```

### 错误2：忘记保留 System 消息

```python
# 错误：裁剪时丢失了System消息
trimmed = trim_messages(messages, max_messages=5, strategy="last")
# 问题：System消息可能被裁剪掉，Agent丢失角色设定

# 正确：始终保留System消息
trimmed = trim_messages(
    messages,
    max_messages=5,
    strategy="last",
    include_system=True
)
```

### 错误3：过度依赖摘要

```python
# 错误：将token_threshold设置得很大，几乎不触发摘要
SummarizationMiddleware(token_threshold=100000)
# 问题：对于8K窗口模型，可能在摘要触发前就超出限制

# 正确：设置合理的阈值，留出缓冲空间
# 对于8K窗口模型
SummarizationMiddleware(token_threshold=3000)
```

### 错误4：裁剪后消息不完整

```python
# 错误：裁剪后消息以ToolMessage结尾
# 问题：模型可能困惑，因为没有对应的AI请求

# 正确：使用end_on参数确保消息完整
trimmed = trim_messages(
    messages,
    max_tokens=2000,
    strategy="last",
    end_on=("human", "ai"),  # 确保以Human或AI消息结束
)
```
