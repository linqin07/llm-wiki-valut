## 核心摘要
JDK8 新特性共 4 篇，系统介绍 Java 8 的核心改进。Stream API 支持声明式集合操作（filter/map/reduce/collect），Collectors 提供丰富的收集器（groupingBy/toMap/joining）。函数式接口（Function/Predicate/Supplier/Consumer）配合 Lambda 表达式。全新的 java.time 时间日期 API 替代旧的 Date/SimpleDateFormat，解决线程安全问题。
