## 什么是条件路由

### 概念介绍

条件路由是 LangGraph 的核心特性之一，它允许图根据**运行时状态**动态决定执行路径，而不是预先固定。

```
静态边（固定路径）:
  A --> B --> C    （每次都走同一条路）

条件路由（动态路径）:
  A --> 判断?
         |
    +----+----+
    |         |
    v         v
    B         C    （根据状态选择路径）
```

### 为什么需要条件路由

| 场景 | 说明 |
|------|------|
| Agent 工具调用 | LLM 决定是否调用工具 |
| 错误重试 | 失败时决定重试还是降级 |
| 多轮对话 | 判断是否需要继续对话 |
| 任务分派 | 根据任务类型分派给不同 Agent |
| 质量检查 | 检查结果是否达标，不达标则重做 |

## add_conditional_edges() 详解

### 函数签名

```python
graph.add_conditional_edges(
    source,          # 源节点名称
    path_function,   # 条件函数（路由函数）
    path_map=None,   # 条件值到目标节点的映射（可选）
)
```

### 参数说明

| 参数 | 类型 | 说明 |
|------|------|------|
| `source` | `str` | 源节点的名称，从此节点出发 |
| `path_function` | `Callable` | 接收状态，返回路由键（字符串） |
| `path_map` | `dict[str, str]` | 路由键到目标节点名的映射 |

### 基本用法

```python
from langgraph.graph import StateGraph, START, END

# 定义条件函数
def decide_path(state: MyState) -> str:
    """根据状态决定下一步"""
    if state.get("need_tool"):
        return "use_tool"
    else:
        return "direct_reply"

# 构建图
graph = StateGraph(MyState)
graph.add_node("think", think_node)
graph.add_node("use_tool", tool_node)
graph.add_node("direct_reply", reply_node)

# 添加条件边
graph.add_conditional_edges(
    "think",           # 从 think 节点出发
    decide_path,       # 使用 decide_path 函数决定路径
    {
        "use_tool": "use_tool",       # 返回 "use_tool" -> 去 tool 节点
        "direct_reply": "direct_reply", # 返回 "direct_reply" -> 去 reply 节点
    }
)
```

### path_map 的作用

`path_map` 将条件函数的返回值映射到实际的节点名：

```python
# 条件函数返回简短的键
def route(state) -> str:
    return "a"  # 或 "b" 或 "c"

# path_map 将键映射到节点名
graph.add_conditional_edges(
    "decision",
    route,
    {
        "a": "process_a",    # "a" -> 节点 "process_a"
        "b": "process_b",    # "b" -> 节点 "process_b"
        "c": "process_c",    # "c" -> 节点 "process_c"
    }
)
```

### 省略 path_map

如果条件函数直接返回节点名，可以省略 `path_map`：

```python
def route_to_node(state) -> str:
    """直接返回目标节点名"""
    if state["type"] == "A":
        return "node_a"   # 直接返回节点名
    return "node_b"

graph.add_conditional_edges(
    "decision",
    route_to_node,
    # 省略 path_map，因为 route_to_node 直接返回节点名
)
```

## 条件函数设计

### 基本原则

1. **输入**：当前状态（TypedDict）
2. **输出**：字符串（路由键或节点名）
3. **返回值必须对应一个有效的目标节点**

### 简单条件

```python
def simple_condition(state: AgentState) -> str:
    """简单的二元条件"""
    if len(state["messages"]) > 10:
        return "summarize"
    return "continue"
```

### 多条件分支

```python
def multi_condition(state: AgentState) -> str:
    """多条件分支"""
    score = state.get("quality_score", 0)

    if score >= 90:
        return "excellent"
    elif score >= 70:
        return "good"
    elif score >= 50:
        return "acceptable"
    else:
        return "retry"
```

### 使用 Literal 类型提示

```python
from typing import Literal

def typed_condition(state: AgentState) -> Literal["option_a", "option_b", "option_c"]:
    """使用 Literal 类型提示，提高代码可读性"""
    result = state.get("analysis_result")

    if result == "复杂":
        return "option_a"
    elif result == "中等":
        return "option_b"
    else:
        return "option_c"
```

### 基于 LLM 决策的条件

```python
def llm_decision(state: AgentState) -> str:
```

## 循环控制

### 条件退出循环

条件路由最常见的用途之一是实现循环：

```
                +--------+
                | 开始   |
                +---+----+
                    |
              +-----v------+
              |  处理节点   | <--------+
              +-----+------+          |
                    |                 |
              +-----v------+          |
              |  判断条件   |          |
              +--+-------+--+          |
                 |       |            |
            继续 |       | 结束       |
                 v       v            |
             +---+---+ +--+--+        |
             | 循环  | | 输出 |       |
             | 处理  | +-----+       |
             +---+---+                |
                 |                    |
                 +--------------------+
```

### 代码实现

```python
from typing import TypedDict, Annotated
from langgraph.graph import StateGraph, START, END
from langgraph.graph.message import add_messages
from langchain_core.messages import BaseMessage

class LoopState(TypedDict):
    messages: Annotated[list[BaseMessage], add_messages]
    iteration: int
    max_iterations: int
    quality_score: float

def process_node(state: LoopState) -> dict:
    """处理节点：执行任务并评估质量"""
    # 模拟处理和质量评估
    import random
    score = random.uniform(60, 100)

    return {
        "iteration": state["iteration"] + 1,
        "quality_score": score,
    }

def should_continue(state: LoopState) -> str:
    """判断是否继续循环"""
    # 条件1：达到最大迭代次数
    if state["iteration"] >= state["max_iterations"]:
        return "end"

    # 条件2：质量达标
    if state["quality_score"] >= 85:
        return "end"

    # 继续循环
    return "continue"

# 构建图
graph = StateGraph(LoopState)
graph.add_node("process", process_node)

graph.add_edge(START, "process")
graph.add_conditional_edges(
    "process",
    should_continue,
    {
        "continue": "process",  # 继续循环
        "end": END,             # 退出循环
    }
)

app = graph.compile()
result = app.invoke({
    "messages": [],
    "iteration": 0,
    "max_iterations": 5,
    "quality_score": 0.0,
})
```

### 最大迭代次数保护

**永远要设置最大迭代次数**，防止无限循环：

```python
def safe_continue(state: LoopState) -> str:
    """带保护的循环判断"""
    # 强制退出保护
    MAX_ITERATIONS = 10
    if state["iteration"] >= MAX_ITERATIONS:
        print(f"警告：达到最大迭代次数 {MAX_ITERATIONS}，强制退出")
        return "end"

    # 正常退出条件
    if state.get("task_completed"):
        return "end"

    return "continue"
```

## 错误处理路由

### 重试（Retry）

```
执行任务 --> 成功？
              |
        +-----+-----+
        |           |
       是          否
        |           |
        v           v
     完成      重试次数 < 最大值？
                  |
            +-----+-----+
            |           |
           是          否
            |           |
            v           v
         重试执行    降级处理
```

```python
class RetryState(TypedDict):
    messages: Annotated[list[BaseMessage], add_messages]
    retry_count: int
    max_retries: int
    error: str
    result: str

def execute_task(state: RetryState) -> dict:
    """执行任务（可能失败）"""
    try:
        # 模拟可能失败的任务
        import random
        if random.random() < 0.5:
            raise Exception("任务执行失败")

        return {
            "result": "任务成功完成",
            "error": "",
        }
    except Exception as e:
        return {
            "error": str(e),
            "retry_count": state["retry_count"] + 1,
        }

def handle_result(state: RetryState) -> str:
    """处理执行结果，决定下一步"""
    # 成功
    if not state.get("error"):
        return "success"

    # 还有重试机会
    if state["retry_count"] < state["max_retries"]:
        return "retry"

    # 重试次数用尽，降级处理
    return "fallback"

def fallback_node(state: RetryState) -> dict:
    """降级处理"""
    return {"result": "使用默认结果（降级）"}

# 构建图
graph = StateGraph(RetryState)
graph.add_node("execute", execute_task)
graph.add_node("fallback", fallback_node)

graph.add_edge(START, "execute")
graph.add_conditional_edges(
    "execute",
    handle_result,
    {
        "success": END,
        "retry": "execute",    # 重试
        "fallback": "fallback", # 降级
    }
)
graph.add_edge("fallback", END)

app = graph.compile()
```

### 降级（Fallback）

```python
def try_primary(state: AppState) -> dict:
    """尝试主服务"""
    try:
        result = primary_api_call(state["query"])
        return {"result": result, "source": "primary"}
    except Exception as e:
        return {"error": str(e)}

def check_primary(state: AppState) -> str:
    """检查主服务结果"""
    if state.get("error"):
        return "fallback"
    return "success"

def use_fallback(state: AppState) -> dict:
    """使用备用服务"""
    result = fallback_api_call(state["query"])
    return {"result": result, "source": "fallback", "error": ""}

graph = StateGraph(AppState)
graph.add_node("primary", try_primary)
graph.add_node("fallback", use_fallback)

graph.add_edge(START, "primary")
graph.add_conditional_edges(
    "primary",
    check_primary,
    {"success": END, "fallback": "fallback"}
)
graph.add_edge("fallback", END)
```

### 中止（Abort）

```python
def check_critical_error(state: AppState) -> str:
    """检查是否为致命错误"""
    error = state.get("error", "")

    # 致命错误：直接中止
    if "AUTHENTICATION" in error.upper():
        return "abort"
    if "QUOTA_EXCEEDED" in error.upper():
        return "abort"

    # 可恢复错误：重试
    if error:
        return "retry"

    return "success"

def abort_node(state: AppState) -> dict:
    """中止处理"""
    return {
        "result": f"操作中止: {state['error']}",
        "status": "aborted",
    }
```

## 复杂决策树

### 多层条件嵌套

```
用户输入
    |
    v
+---+---+
| 分类  |
+---+---+
    |
    +--------+--------+
    |        |        |
    v        v        v
+------+ +------+ +------+
| 技术 | | 商务 | | 其他 |
+--+---+ +--+---+ +--+---+
   |        |        |
   v        v        v
+------+ +------+ +------+
| 细分 | | 细分 | | 默认 |
+--+---+ +--+---+ +--+---+
   |        |        |
   +--------+--------+
            |
            v
       +----+----+
       |  执行   |
       +---------+
```

### 代码实现

```python
"""
复杂决策树示例
"""
from typing import TypedDict, Literal
from langgraph.graph import StateGraph, START, END

class DecisionState(TypedDict):
    user_input: str
    category: str       # "tech", "business", "other"
    sub_category: str   # 细分类别
    action: str         # 最终执行的动作
    result: str

# 第一层分类
def classify(state: DecisionState) -> str:
    """分类用户请求"""
    input_text = state["user_input"].lower()

    if any(kw in input_text for kw in ["代码", "编程", "开发", "bug"]):
        return "tech"
    elif any(kw in input_text for kw in ["价格", "报价", "合同", "商务"]):
        return "business"
    else:
        return "other"

# 第二层：技术细分
def tech_subclassify(state: DecisionState) -> str:
    """技术类别细分"""
    input_text = state["user_input"].lower()

    if any(kw in input_text for kw in ["python", "java", "代码"]):
        return "coding"
    elif any(kw in input_text for kw in ["bug", "错误", "异常"]):
        return "debugging"
    else:
        return "general_tech"

# 第二层：商务细分
def business_subclassify(state: DecisionState) -> str:
    """商务类别细分"""
    input_text = state["user_input"].lower()

    if any(kw in input_text for kw in ["价格", "报价"]):
        return "pricing"
    elif any(kw in input_text for kw in ["合同"]):
        return "contract"
    else:
        return "general_business"

# 执行节点
def tech_handler(state: DecisionState) -> dict:
    return {"result": f"技术处理: {state['sub_category']}"}

def business_handler(state: DecisionState) -> dict:
    return {"result": f"商务处理: {state['sub_category']}"}

def default_handler(state: DecisionState) -> dict:
    return {"result": "默认处理"}

# 构建图
graph = StateGraph(DecisionState)
graph.add_node("tech", tech_handler)
graph.add_node("business", business_handler)
graph.add_node("default", default_handler)

graph.add_edge(START, "classify")  # 注意：这里需要一个分类节点

# 实际上需要这样设计：
# 先添加分类节点
def classify_node(state: DecisionState) -> dict:
    category = classify(state)
    sub = ""
    if category == "tech":
        sub = tech_subclassify(state)
    elif category == "business":
        sub = business_subclassify(state)
    return {"category": category, "sub_category": sub}

graph.add_node("classifier", classify_node)
graph.add_edge(START, "classifier")
graph.add_conditional_edges(
    "classifier",
    lambda s: s["category"],
    {
        "tech": "tech",
        "business": "business",
        "other": "default",
    }
)
graph.add_edge("tech", END)
graph.add_edge("business", END)
graph.add_edge("default", END)

app = graph.compile()
```

## 完整代码示例

### 示例1：带条件路由的 Agent 图

```python
"""
完整的条件路由 Agent 示例
支持工具调用、重试、质量检查
"""
from typing import TypedDict, Annotated
from langgraph.graph import StateGraph, START, END
from langgraph.graph.message import add_messages
from langchain_core.messages import BaseMessage, HumanMessage, AIMessage, SystemMessage
from langchain.chat_models import init_chat_model

model = init_chat_model("groq:llama-3.3-70b-versatile")

# ---- 状态定义 ----
class AgentState(TypedDict):
    messages: Annotated[list[BaseMessage], add_messages]
    tool_calls: list
    tool_results: list
    retry_count: int
    quality_ok: bool

# ---- 工具定义 ----
def search_tool(query: str) -> str:
    """模拟搜索工具"""
    return f"搜索结果: 关于 '{query}' 的信息..."

def calculate_tool(expression: str) -> str:
    """模拟计算工具"""
    try:
        result = eval(expression)  # 仅作演示
        return f"计算结果: {result}"
    except:
        return "计算错误"

# ---- 节点函数 ----
def think_node(state: AgentState) -> dict:
    """思考节点：LLM 分析是否需要工具"""
    response = model.invoke([
        SystemMessage(content="""你是智能助手。根据用户问题判断：
1. 如果需要搜索信息，回复 "SEARCH: <搜索词>"
2. 如果需要计算，回复 "CALC: <表达式>"
3. 如果可以直接回答，回复 "ANSWER: <你的回答>"
只回复上述格式之一。"""),
        *state["messages"]
    ])

    content = response.content.strip()

    if content.startswith("SEARCH:"):
        query = content[7:].strip()
        return {
            "tool_calls": [{"tool": "search", "args": query}],
            "messages": [AIMessage(content=f"[思考] 需要搜索: {query}")],
        }
    elif content.startswith("CALC:"):
        expr = content[5:].strip()
        return {
            "tool_calls": [{"tool": "calculate", "args": expr}],
            "messages": [AIMessage(content=f"[思考] 需要计算: {expr}")],
        }
    else:
        answer = content[7:].strip() if content.startswith("ANSWER:") else content
        return {
            "tool_calls": [],
            "messages": [AIMessage(content=answer)],
        }

def tool_node(state: AgentState) -> dict:
    """工具执行节点"""
    results = []
    for call in state["tool_calls"]:
        if call["tool"] == "search":
            result = search_tool(call["args"])
        elif call["tool"] == "calculate":
            result = calculate_tool(call["args"])
        else:
            result = "未知工具"
        results.append(result)

    return {
        "tool_results": results,
        "tool_calls": [],  # 清空工具调用
        "messages": [AIMessage(content=f"[工具] 执行完成: {results}")],
    }

def quality_check(state: AgentState) -> dict:
    """质量检查节点"""
    # 简单的质量检查逻辑
    has_response = len(state["messages"]) > 0
    no_pending_tools = len(state.get("tool_calls", [])) == 0

    return {
        "quality_ok": has_response and no_pending_tools,
    }

# ---- 条件函数 ----
def route_after_think(state: AgentState) -> str:
    """思考后路由"""
    if state.get("tool_calls"):
        return "tools"
    return "quality_check"

def route_after_quality(state: AgentState) -> str:
    """质量检查后路由"""
    if state["quality_ok"]:
        return "end"
    if state["retry_count"] < 3:
        return "retry"
    return "end"

# ---- 构建图 ----
graph = StateGraph(AgentState)

graph.add_node("think", think_node)
graph.add_node("tools", tool_node)
graph.add_node("quality_check", quality_check)

graph.add_edge(START, "think")
graph.add_conditional_edges(
    "think",
    route_after_think,
    {
        "tools": "tools",
        "quality_check": "quality_check",
    }
)
graph.add_edge("tools", "think")  # 工具执行后回到思考
graph.add_conditional_edges(
    "quality_check",
    route_after_quality,
    {
        "end": END,
        "retry": "think",
    }
)

app = graph.compile()

# 运行
result = app.invoke({
    "messages": [HumanMessage(content="帮我搜索一下 Python 3.12 的新特性")],
    "tool_calls": [],
    "tool_results": [],
    "retry_count": 0,
    "quality_ok": False,
})
```

## 常见错误

### 1. 条件函数返回了不存在的节点

```python
# 错误：返回值没有对应的节点或 path_map 条目
def bad_condition(state):
    return "nonexistent_node"  # 这个节点不存在！

graph.add_conditional_edges(
    "source",
    bad_condition,
    {"option_a": "node_a"}  # 没有 "nonexistent_node" 的映射
)
# 运行时会报错
```

### 2. path_map 不完整

## 最佳实践

### 1. 条件函数要简洁明了

```python
# 好：逻辑清晰，一行一个判断
def route(state: AgentState) -> str:
    if state.get("error"):
        return "error_handler"
    if state.get("need_tool"):
        return "tool_executor"
    if state.get("need_review"):
        return "reviewer"
    return "output"

# 不好：嵌套复杂
def bad_route(state: AgentState) -> str:
    if state.get("x"):
        if state.get("y"):
            if state.get("z"):
                return "a"
            return "b"
        return "c"
    return "d"
```

### 2. 使用有意义的路由键名称

```python
# 好：路由键描述了决策
graph.add_conditional_edges(
    "analyze",
    decide_action,
    {
        "needs_more_info": "search",     # 需要更多信息
        "ready_to_answer": "respond",    # 可以回答
        "error_occurred": "handle_error", # 出错了
    }
)

# 不好：路由键无意义
graph.add_conditional_edges(
    "analyze",
    decide_action,
    {"a": "search", "b": "respond", "c": "handle_error"}
)
```

### 3. 总是设置最大迭代保护

```python
# 好的模式
MAX_RETRIES = 3
MAX_ITERATIONS = 10

def safe_route(state):
    if state["iteration"] >= MAX_ITERATIONS:
        return "force_exit"
    if state.get("success"):
        return "done"
    if state["retry_count"] >= MAX_RETRIES:
        return "fallback"
    return "retry"
```

### 4. 为条件函数添加日志

```python
def logged_condition(state: AgentState) -> str:
    """带日志的条件函数"""
    decision = _make_decision(state)
    print(f"[Router] 状态: error={state.get('error')}, "
          f"iteration={state.get('iteration')} -> {decision}")
    return decision
```
