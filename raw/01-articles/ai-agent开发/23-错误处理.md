## LLM 应用中的常见错误类型

### 错误分类总览

```
LLM 应用中的错误
├── 网络错误
│   ├── TimeoutError (请求超时)
│   └── ConnectionError (连接失败)
│
├── API 错误
│   ├── RateLimitError (速率限制)
│   ├── AuthenticationError (认证失败)
│   ├── APIError (服务端错误)
│   └── InvalidRequestError (请求无效)
│
├── 模型错误
│   ├── ContextWindowExceededError (上下文窗口超限)
│   └── ContentFilterError (内容过滤)
│
└── 应用错误
    ├── ToolExecutionError (工具执行失败)
    ├── ParsingError (解析错误)
    └── ValidationError (验证失败)
```

### 详细说明

#### 1. RateLimitError - 速率限制

```python
# 触发原因：短时间内发送了太多请求
# 错误信息：Rate limit reached for model

# 常见场景：
# - 并发请求过多
# - 批量处理时没有限流
# - API 配额用尽

# 解决方案：
# 1. 实现重试机制（指数退避）
# 2. 限制并发数量
# 3. 升级 API 配额
```

#### 2. TimeoutError - 请求超时

```python
# 触发原因：请求在规定时间内未返回
# 错误信息：Request timed out

# 常见场景：
# - 输入过长，模型处理时间长
# - 网络不稳定
# - 服务端负载过高

# 解决方案：
# 1. 增加超时时间
# 2. 减少输入长度
# 3. 实现重试机制
```

#### 3. AuthenticationError - 认证失败

```python
# 触发原因：API Key 无效或过期
# 错误信息：Invalid API key / Authentication failed

# 常见场景：
# - API Key 配置错误
# - API Key 已过期
# - 环境变量未正确加载

# 解决方案：
# 1. 检查 .env 文件
# 2. 重新生成 API Key
# 3. 验证环境变量
```

#### 4. APIError - API 服务端错误

```python
# 触发原因：API 服务端内部错误
# 错误信息：Internal server error / Service unavailable

# 常见场景：
# - API 服务暂时不可用
# - 服务端过载

# 解决方案：
# 1. 实现重试机制
# 2. 使用备用 API
# 3. 降级处理
```

#### 5. ContextWindowExceededError - 上下文窗口超限

```python
# 触发原因：输入 token 数超过模型限制
# 错误信息：Maximum context length exceeded

# 常见场景：
# - 对话历史太长
# - 文档太大
# - 多轮对话未清理历史

# 解决方案：
# 1. 截断输入
# 2. 压缩历史消息
# 3. 使用支持更长上下文的模型
```

### 错误严重性分类

```
可恢复错误（应重试）:
  - RateLimitError
  - TimeoutError
  - APIError (5xx)

不可恢复错误（应中止或降级）:
  - AuthenticationError
  - InvalidRequestError (4xx)
  - ContextWindowExceededError
```

## 重试策略

### model.with_retry() 指数退避

LangChain 提供了内置的重试机制：

```python
from langchain.chat_models import init_chat_model

# 创建带重试的模型
model = init_chat_model("groq:llama-3.3-70b-versatile")

# 使用 with_retry 添加重试机制
model_with_retry = model.with_retry(
    stop_after_attempt=3,        # 最多重试 3 次
    wait_exponential=True,       # 指数退避
    retry_if_exception_type=(    # 只对这些异常重试
        "RateLimitError",
        "TimeoutError",
        "APIError",
    ),
)

# 使用
response = model_with_retry.invoke("你好")
```

### 重试参数详解

| 参数 | 类型 | 说明 |
|------|------|------|
| `stop_after_attempt` | `int` | 最大重试次数（包含首次尝试） |
| `wait_exponential` | `bool` | 是否使用指数退避 |
| `wait_exponential_min` | `float` | 最小等待时间（秒） |
| `wait_exponential_max` | `float` | 最大等待时间（秒） |
| `retry_if_exception_type` | `tuple` | 只对指定异常重试 |

### 指数退避原理

```
指数退避（Exponential Backoff）:
  第1次重试：等待 1 秒
  第2次重试：等待 2 秒
  第3次重试：等待 4 秒
  第4次重试：等待 8 秒
  ...

计算公式：
  wait_time = min(initial_wait * 2^attempt, max_wait)

示例（initial_wait=1, max_wait=60）:
  Attempt 1: wait 1s
  Attempt 2: wait 2s
  Attempt 3: wait 4s
  Attempt 4: wait 8s
  Attempt 5: wait 16s
  Attempt 6: wait 32s
  Attempt 7: wait 60s (达到上限)
```

### 代码示例

```python
from langchain.chat_models import init_chat_model
from langchain_core.rate_limiters import InMemoryRateLimiter

# 方式1：使用 with_retry
model = init_chat_model("groq:llama-3.3-70b-versatile")
model_with_retry = model.with_retry(
    stop_after_attempt=3,
    wait_exponential=True,
    wait_exponential_min=1,
    wait_exponential_max=60,
)

# 方式2：使用速率限制器

    requests_per_second=10,  # 每秒最多 10 个请求
    check_every_n_seconds=0.1,
    max_bucket_size=20,
)

model_with_limiter = init_chat_model(
    "groq:llama-3.3-70b-versatile",
    rate_limiter=rate_limiter,
)
```

## 降级策略

### model.with_fallbacks() 模型降级链

当主模型不可用时，自动切换到备用模型：

```python
from langchain.chat_models import init_chat_model

# 主模型
primary_model = init_chat_model("openai:gpt-4o")

# 备用模型
fallback1 = init_chat_model("openai:gpt-4o-mini")
fallback2 = init_chat_model("groq:llama-3.3-70b-versatile")

# 创建带降级的模型
model_with_fallback = primary_model.with_fallbacks(
    [fallback1, fallback2]
)

# 使用：先尝试 GPT-4o，失败后尝试 GPT-4o-mini，最后尝试 Groq
response = model_with_fallback.invoke("你好")
```

### 降级顺序设计

```
降级顺序建议：

1. 主模型（最强/最新）
   GPT-4o / Claude 3.5 Sonnet
   |
   失败
   v
2. 备用模型1（性价比高）
   GPT-4o-mini / Gemini Flash
   |
   失败
   v
3. 备用模型2（最稳定/最便宜）
   Groq Llama / 本地模型
   |
   失败
   v
4. 最终降级
   返回缓存结果 / 默认回复
```

### 代码示例

```python
"""
模型降级链示例
"""
from langchain.chat_models import init_chat_model

def create_resilient_model():
    """创建带降级机制的模型"""
    # 主模型
    primary = init_chat_model("openai:gpt-4o")

    # 备用模型
    fallbacks = [
        init_chat_model("openai:gpt-4o-mini"),
        init_chat_model("groq:llama-3.3-70b-versatile"),
    ]

    # 添加重试和降级
    model = primary.with_retry(
        stop_after_attempt=2,
        wait_exponential=True,
    ).with_fallbacks(fallbacks)

    return model

# 使用
model = create_resilient_model()
response = model.invoke("什么是 LangChain?")
```

## 自定义错误处理

### RunnableLambda 包装

使用 `RunnableLambda` 包装自定义错误处理逻辑：

```python
from langchain_core.runnables import RunnableLambda
from langchain.chat_models import init_chat_model

model = init_chat_model("groq:llama-3.3-70b-versatile")

def safe_invoke(input_data):
    """带错误处理的模型调用"""
    try:
        response = model.invoke(input_data)
        return response.content
    except Exception as e:
        error_type = type(e).__name__
        if "RateLimit" in error_type:
            return "服务繁忙，请稍后再试。"
        elif "Timeout" in error_type:
            return "请求超时，请重试。"
        elif "Authentication" in error_type:
            return "认证失败，请检查 API 配置。"
        else:
            return f"发生错误: {str(e)}"

# 包装为 Runnable
safe_model = RunnableLambda(safe_invoke)

# 使用
result = safe_model.invoke("你好")
```

### 节点中的 try-except

在 LangGraph 节点中使用 try-except：

```python
from typing import TypedDict
from langgraph.graph import StateGraph, START, END

class AppState(TypedDict):
    messages: list
    error: str
    result: str

def safe_node(state: AppState) -> dict:
    """带错误处理的节点"""
    try:
        # 尝试执行操作
        response = model.invoke(state["messages"])
        return {
            "result": response.content,
            "error": "",  # 清空错误
        }
    except RateLimitError:
        return {
            "error": "rate_limit",
            "result": "服务繁忙，请稍后再试。",
        }
    except TimeoutError:
        return {
            "error": "timeout",
            "result": "请求超时，请重试。",
        }
    except AuthenticationError:
        return {
            "error": "auth",
            "result": "认证失败，请检查配置。",
        }
    except Exception as e:
        return {
            "error": "unknown",
            "result": f"发生未知错误: {str(e)}",
        }

def check_error(state: AppState) -> str:
    """检查是否有错误"""
    if state.get("error"):
        return "handle_error"
    return "continue"

def handle_error(state: AppState) -> dict:
    """处理错误"""
    error = state["error"]

    if error == "rate_limit":
        # 可以添加延迟后重试的逻辑
        return {"result": "请等待一分钟后重试。"}
    elif error == "auth":
        return {"result": "请联系管理员检查 API 配置。"}
    else:
        return {"result": "服务暂时不可用，请稍后重试。"}
```

cache = {}

def cached_model_call(query: str) -> str:

    # 检查缓存

### 生产环境代码模板

```python
"""
生产环境错误处理模板
"""
import os
import logging
from typing import Optional
from functools import wraps
from dotenv import load_dotenv
from langchain.chat_models import init_chat_model
from langchain_core.runnables import RunnableConfig

load_dotenv()

# 配置日志
logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)

class LLMService:
    """带完善错误处理的 LLM 服务"""

    def __init__(self):
        self.primary_model = init_chat_model("groq:llama-3.3-70b-versatile")
        self.fallback_model = init_chat_model("groq:llama-3.3-70b-versatile")

        # 添加重试
        self.model = self.primary_model.with_retry(
            stop_after_attempt=3,
            wait_exponential=True,
        ).with_fallbacks([self.fallback_model])

    def invoke(self, prompt: str, config: Optional[RunnableConfig] = None) -> str:
        """带错误处理的调用"""
        try:
            response = self.model.invoke(prompt, config=config)
            return response.content

        except Exception as e:
            logger.error(f"LLM 调用失败: {type(e).__name__}: {e}")
            return self._handle_error(e)

    def _handle_error(self, error: Exception) -> str:
        """处理错误，返回用户友好的消息"""
        error_handlers = {
            "RateLimitError": "当前使用人数较多，请稍后再试。",
            "TimeoutError": "服务器响应较慢，请稍后重试。",
            "AuthenticationError": "服务配置有误，请联系管理员。",
            "ContextWindowExceededError": "输入内容过长，请缩短后重试。",
        }

        error_type = type(error).__name__
        return error_handlers.get(error_type, "服务暂时不可用，请稍后重试。")

# 使用
service = LLMService()
result = service.invoke("什么是 LangChain?")
```

### 错误监控和告警

```python
"""
错误监控示例
"""
import time
from collections import defaultdict
from datetime import datetime, timedelta

class ErrorMonitor:
    def __init__(self, alert_threshold=5, window_minutes=5):
        self.errors = defaultdict(list)
        self.alert_threshold = alert_threshold
        self.window = timedelta(minutes=window_minutes)

    def record_error(self, error_type: str):
        """记录错误"""
        now = datetime.now()
        self.errors[error_type].append(now)

        # 清理过期记录
        cutoff = now - self.window
        self.errors[error_type] = [
            t for t in self.errors[error_type] if t > cutoff
        ]

        # 检查是否需要告警
        if len(self.errors[error_type]) >= self.alert_threshold:
            self._send_alert(error_type)

    def _send_alert(self, error_type: str):
        """发送告警"""
        count = len(self.errors[error_type])
        logger.critical(
            f"告警: {error_type} 在过去 {self.window} 内发生 {count} 次"
        )
        # 这里可以集成邮件、Slack 等告警系统

    def get_stats(self) -> dict:
        """获取错误统计"""
        return {
            error_type: len(times)
            for error_type, times in self.errors.items()
        }

# 使用
monitor = ErrorMonitor()

def monitored_llm_call(prompt: str) -> str:
    try:
        return llm.invoke(prompt).content
    except Exception as e:
        monitor.record_error(type(e).__name__)
        raise
```

"""
带重试机制的 Agent

import os

### 示例2：带降级的多模型系统

```python
"""
带降级的多模型系统
"""
import os
from dotenv import load_dotenv
from langchain.chat_models import init_chat_model

load_dotenv()

class ResilientLLMSystem:
    """带降级机制的 LLM 系统"""

    def __init__(self):
        # 模型优先级列表
        self.models = [
            init_chat_model("openai:gpt-4o"),
            init_chat_model("openai:gpt-4o-mini"),
            init_chat_model("groq:llama-3.3-70b-versatile"),
        ]
        self.current_index = 0

    def invoke(self, prompt: str) -> str:
        """按优先级尝试调用模型"""
        errors = []

        for i, model in enumerate(self.models):
            try:
                response = model.invoke(prompt)
                self.current_index = i  # 记录成功的模型
                return response.content
            except Exception as e:
                errors.append(f"模型 {i}: {type(e).__name__}")
                continue

        # 所有模型都失败
        return f"所有模型都不可用。错误: {errors}"

    def invoke_with_cache(self, prompt: str, cache: dict) -> str:
        """带缓存的调用"""
        # 先检查缓存
        if prompt in cache:
            return cache[prompt]

        try:
            result = self.invoke(prompt)
            cache[prompt] = result
            return result
        except Exception:
            # 如果有缓存，返回缓存
            if prompt in cache:
                return f"[缓存] {cache[prompt]}"
            return "服务不可用"

# 使用
system = ResilientLLMSystem()
result = system.invoke("什么是机器学习？")
print(result)
```

### 示例3：LangGraph 中的错误处理

```python
"""
LangGraph 中的完整错误处理
"""
from typing import TypedDict, Annotated
from langgraph.graph import StateGraph, START, END
from langgraph.graph.message import add_messages
from langchain_core.messages import BaseMessage, HumanMessage, AIMessage
from langchain.chat_models import init_chat_model

model = init_chat_model("groq:llama-3.3-70b-versatile")
model_with_retry = model.with_retry(stop_after_attempt=3, wait_exponential=True)

class RobustState(TypedDict):
    messages: Annotated[list[BaseMessage], add_messages]
    error: str
    retry_count: int
    max_retries: int

def llm_node(state: RobustState) -> dict:
    """LLM 节点，带错误处理"""
    try:
        response = model_with_retry.invoke(state["messages"])
        return {
            "messages": [response],
            "error": "",  # 清空错误
        }
    except Exception as e:
        error_type = type(e).__name__
        return {
            "error": error_type,
            "retry_count": state.get("retry_count", 0) + 1,
            "messages": [AIMessage(content=f"处理出错: {error_type}")],
        }

def error_handler(state: RobustState) -> dict:
    """错误处理节点"""
    error = state["error"]

    if error == "RateLimitError":
        message = "服务繁忙，请稍后再试。"
    elif error == "TimeoutError":
        message = "请求超时，请重试。"
    elif error == "ContextWindowExceededError":
        message = "输入过长，请缩短后重试。"
    else:
        message = "服务暂时不可用，请稍后重试。"

    return {"messages": [AIMessage(content=message)]}

def check_error(state: RobustState) -> str:
    """检查是否有错误"""
    if state.get("error"):
        # 检查是否还能重试
        if state.get("retry_count", 0) < state.get("max_retries", 3):
            return "retry"
        return "error"
    return "success"

# 构建图
graph = StateGraph(RobustState)
graph.add_node("llm", llm_node)
graph.add_node("error_handler", error_handler)

graph.add_edge(START, "llm")
graph.add_conditional_edges(
    "llm",
    check_error,
    {
        "success": END,
        "retry": "llm",         # 重试
        "error": "error_handler", # 处理错误
    }
)
graph.add_edge("error_handler", END)

app = graph.compile()

# 使用
result = app.invoke({
    "messages": [HumanMessage(content="你好")],
    "error": "",
    "retry_count": 0,
    "max_retries": 3,
})
```

### 示例4：生产级错误处理

```python
"""
生产级错误处理综合示例
"""
import os
import logging
import time
from typing import Optional
from functools import wraps
from dotenv import load_dotenv
from langchain.chat_models import init_chat_model
from langchain_core.runnables import RunnableConfig

load_dotenv()

logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)

def retry_with_backoff(max_retries=3, initial_delay=1):
    """重试装饰器"""
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            delay = initial_delay
            last_exception = None

            for attempt in range(max_retries):
                try:
                    return func(*args, **kwargs)
                except Exception as e:
                    last_exception = e
                    if attempt < max_retries - 1:
                        logger.warning(
                            f"尝试 {attempt + 1} 失败: {e}, "
                            f"等待 {delay} 秒后重试"
                        )
                        time.sleep(delay)
                        delay *= 2  # 指数退避

            raise last_exception
        return wrapper
    return decorator

class ProductionLLMService:
    """生产级 LLM 服务"""

    def __init__(self):
        self.model = init_chat_model("groq:llama-3.3-70b-versatile")
        self.fallback_model = init_chat_model("groq:llama-3.3-70b-versatile")
        self.cache = {}
        self.error_count = 0

    @retry_with_backoff(max_retries=3)
    def _call_model(self, prompt: str) -> str:
        """调用模型（带重试）"""
        try:
            response = self.model.invoke(prompt)
            return response.content
        except Exception as e:
            # 尝试备用模型
            try:
                response = self.fallback_model.invoke(prompt)
                return response.content
            except Exception:
                raise e

    def invoke(self, prompt: str, use_cache: bool = True) -> str:
        """主调用方法"""
        # 检查缓存
        if use_cache and prompt in self.cache:
            logger.info("使用缓存结果")
            return self.cache[prompt]

        try:
            result = self._call_model(prompt)
            # 缓存成功结果
            if use_cache:
                self.cache[prompt] = result
            self.error_count = 0  # 重置错误计数
            return result

        except Exception as e:
            self.error_count += 1
            logger.error(f"调用失败 (连续失败 {self.error_count} 次): {e}")

            # 如果有缓存，返回缓存
            if use_cache and prompt in self.cache:
                logger.warning("返回缓存结果")
                return f"[缓存] {self.cache[prompt]}"

            # 返回用户友好的错误信息
            return self._user_friendly_error(e)

    def _user_friendly_error(self, error: Exception) -> str:
        """返回用户友好的错误信息"""
        error_type = type(error).__name__

        messages = {
            "RateLimitError": "当前使用人数较多，请稍后再试。",
            "TimeoutError": "服务器响应较慢，请稍后重试。",
            "AuthenticationError": "服务配置有误，请联系管理员。",
        }

        return messages.get(error_type, "服务暂时不可用，请稍后重试。")

# 使用
service = ProductionLLMService()
result = service.invoke("什么是 LangGraph?")
print(result)
```

## 常见错误

### 1. 没有错误处理直接调用

```python
# 错误：没有错误处理
response = model.invoke("你好")
# 如果 API 不可用，程序会崩溃

# 正确：添加错误处理
try:
    response = model.invoke("你好")
except Exception as e:
    print(f"调用失败: {e}")
    response = None
```

### 2. 重试次数过多

```python
# 错误：重试太多次
model.with_retry(stop_after_attempt=10)  # 可能等很久

# 正确：合理的重试次数
model.with_retry(stop_after_attempt=3)
```

### 3. 对不可恢复错误也重试

```python
# 错误：对所有错误都重试
model.with_retry()  # AuthenticationError 也会重试，但不会成功

# 正确：只对可恢复错误重试
model.with_retry(
    retry_if_exception_type=(
        "RateLimitError",
        "TimeoutError",
    )
)
```

### 4. 忽略 ContextWindowExceededError

```python
# 错误：不处理上下文超限
very_long_prompt = "..." * 10000
model.invoke(very_long_prompt)

# 正确：检查输入长度或截断
if len(prompt) > MAX_LENGTH:
    prompt = prompt[:MAX_LENGTH]
```
