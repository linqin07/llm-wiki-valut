## 1. 什么是意图识别

### 1.1 从咖啡店点单说起

想象你走进一家咖啡店，对服务员说：

> "好冷啊，来点热的。"

一个优秀的服务员会理解：你想要一杯**热饮**——可能是热咖啡、热巧克力或热茶。
他不会反问你"热的是什么？"，也不会回答"今天确实挺冷的"。

但如果换成一个死板的机器人呢？

```
用户：好冷啊，来点热的。
机器人：今天的气温是 5°C。
```

这就是**有没有意图识别**的区别。

### 1.2 AI Agent 中的意图识别

**意图识别（Intent Recognition）** 是指让机器理解用户说话背后**真实目的**的能力。
它是对话系统、智能客服、AI Agent 的核心模块。

```
┌─────────────────────────────────────────────────────────┐
│                    意图识别三层结构                        │
│                                                         │
│  ┌───────────┐    ┌───────────┐    ┌───────────┐        │
│  │  文本理解   │───▶│  意图分类   │───▶│  槽位填充   │      │
│  │           │    │           │    │           │        │
│  │ 用户说了啥 │    │ 用户想干啥 │    │ 需要啥参数 │        │
│  └───────────┘    └───────────┘    └───────────┘        │
│                                                         │
│  "明天北京天气  ──▶  查询天气    ──▶  城市:北京           │
│   怎么样"                         日期:明天              │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 1.3 为什么意图识别很重要

| 没有意图识别 | 有意图识别 |
|-------------|-----------|
| 只能做关键词匹配 | 理解用户真实目的 |
| 无法处理模糊表达 | 能理解"来点热的" = 想喝热饮 |
| 不支持多轮对话 | 记住上下文，持续服务 |
| 回答死板机械 | 像人类一样灵活应变 |

意图识别是连接**自然语言**和**机器动作**的桥梁。

```

  规则匹配        机器学习        深度学习         LLM
  ┌─────┐       ┌─────┐       ┌─────┐       ┌─────┐
  │关键词│       │TF-IDF│      │ BERT │      │GPT等 │
  │匹配  │       │+NB  │       │      │      │      │
  └──┬──┘       └──┬──┘       └──┬──┘       └──┬──┘

  简单快速        需要训练        需要GPU       无需训练
```

### 2.1 技术一：基于规则的意图识别

最简单直接的方式——用关键词匹配来判断意图。

```python
class RuleBasedIntentRecognizer:
    """基于规则的意图识别器

    原理：维护一个意图到关键词的映射表，
    用户输入中包含哪个关键词，就归类为对应意图。
    """

    def __init__(self):
        self.intent_rules = {
            "查询天气": ["天气", "温度", "下雨", "晴天", "气温", "预报"],
            "订票":     ["订票", "买票", "机票", "预订", "航班", "火车票"],
            "查询订单": ["订单", "物流", "快递", "发货", "到哪了"],
            "退款":     ["退款", "退货", "退钱", "不想要了", "质量问题"],
            "人工客服": ["人工", "客服", "转人工", "真人", "投诉"],
            "问候":     ["你好", "hi", "hello", "嗨", "在吗"],
        }

    def recognize(self, text: str) -> dict:
        """识别用户输入的意图

        Args:
            text: 用户输入的文本

        Returns:
            dict: {"intent": 意图名称, "confidence": 置信度}
        """
        text_lower = text.lower().strip()

        # 按优先级遍历所有意图规则
        matched_intents = []
        for intent, keywords in self.intent_rules.items():
            for keyword in keywords:
                if keyword in text_lower:
                    matched_intents.append(intent)
                    break  # 一个意图命中一个关键词就够了

        if len(matched_intents) == 1:
            return {"intent": matched_intents[0], "confidence": 0.9}
        elif len(matched_intents) > 1:
            # 多个意图命中，返回第一个（可以改为返回列表）
            return {"intent": matched_intents[0], "confidence": 0.6,
                    "all_intents": matched_intents}
        else:
            return {"intent": "未知意图", "confidence": 0.0}


# 测试
recognizer = RuleBasedIntentRecognizer()

test_cases = [
    "今天北京天气怎么样？",
    "我想订一张明天去上海的机票",
    "我的快递到哪了",
    "这个东西我不想要了想退款",
    "转人工客服",
    "你好呀",
    "帮我写一首诗",  # 无法识别
]

for text in test_cases:
    result = recognizer.recognize(text)
    print(f"输入: {text}")
    print(f"结果: {result}\n")
```

**输出示例：**

```
输入: 今天北京天气怎么样？
结果: {'intent': '查询天气', 'confidence': 0.9}

输入: 我想订一张明天去上海的机票
结果: {'intent': '订票', 'confidence': 0.9}

输入: 帮我写一首诗
结果: {'intent': '未知意图', 'confidence': 0.0}
```

**优点**：实现简单、响应快、不需要训练数据
**缺点**：无法处理同义表达、需要人工维护规则、泛化能力差

### 2.2 技术二：基于机器学习的意图识别

用 TF-IDF 提取文本特征，用朴素贝叶斯分类器进行意图分类。

```python
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.naive_bayes import MultinomialNB
from sklearn.pipeline import Pipeline
import numpy as np


class MLIntentRecognizer:
    """基于机器学习的意图识别器

    使用 TF-IDF + 朴素贝叶斯 实现意图分类。
    """

    def __init__(self):
        # 构建 Pipeline：TF-IDF 特征提取 → 朴素贝叶斯分类
        self.pipeline = Pipeline([
            ('tfidf', TfidfVectorizer(
                analyzer='char_wb',  # 字符级 n-gram，适合中文
                ngram_range=(1, 3),  # 1到3个字符的组合
                max_features=5000,
            )),
            ('classifier', MultinomialNB(alpha=0.1)),
        ])
        self.is_trained = False

    def _get_training_data(self):
        """准备训练数据（实际项目中从数据库或文件加载）"""
        training_data = {
            "查询天气": [
                "今天天气怎么样",
                "明天会下雨吗",
                "北京气温多少度",
                "这周天气预报",
                "外面冷不冷",
                "需要带伞吗",
                "明天晴天还是阴天",
                "最近天气如何",
            ],
            "订票": [
                "我想订一张机票",
                "帮我买明天去上海的票",
                "有没有北京到广州的航班",
                "预订一张火车票",
                "查一下后天的机票价格",
                "买一张高铁票",
                "从深圳到成都怎么走",
                "订个酒店",
            ],
            "查询订单": [
                "我的快递到哪了",
                "查一下我的订单状态",
                "物流信息帮我看看",
                "什么时候发货",
                "包裹怎么还没到",
                "我的东西寄出来了吗",
                "订单号查一下",
                "快递到哪个城市了",
            ],
            "退款": [
                "我要退款",
                "这个东西质量有问题想退",
                "不想要了可以退吗",
                "申请退货",
                "钱什么时候退回来",
                "退款流程是什么",
                "怎么申请退款",
                "我要退掉这个订单",
            ],
            "人工客服": [
                "转人工客服",
                "我要找人工",
                "有没有真人客服",
                "投诉",
                "让真人来跟我说",
                "机器人解决不了我的问题",
                "找你们经理",
                "人工服务在哪里",
            ],
        }

        texts, labels = [], []
        for intent, examples in training_data.items():
            for example in examples:
                texts.append(example)
                labels.append(intent)

        return texts, labels

    def train(self):
        """训练模型"""
        texts, labels = self._get_training_data()
        self.pipeline.fit(texts, labels)
        self.is_trained = True
        print(f"模型训练完成，共 {len(texts)} 条训练样本")

    def recognize(self, text: str) -> dict:
        """识别意图

        Args:
            text: 用户输入

        Returns:
            dict: {"intent": 意图, "confidence": 置信度, "probabilities": 所有概率}
        """
        if not self.is_trained:
            raise RuntimeError("请先调用 train() 训练模型")

        # 预测意图
        intent = self.pipeline.predict([text])[0]

        # 获取各类别的概率
        proba = self.pipeline.predict_proba([text])[0]
        classes = self.pipeline.classes_
        confidence = float(np.max(proba))

        # 构建概率字典
        prob_dict = {cls: float(prob) for cls, prob in zip(classes, proba)}

        return {
            "intent": intent,
            "confidence": round(confidence, 3),
            "probabilities": prob_dict,
        }


# 使用示例
recognizer = MLIntentRecognizer()
recognizer.train()

test_inputs = [
    "北京明天冷不冷",
    "帮我订个去三亚的机票",
    "我的包裹什么时候到",
    "这个商品有问题我要退",
    "找人工客服",
    "你好啊",  # 可能被归为某个已有类别
]

for text in test_inputs:
    result = recognizer.recognize(text)
    print(f"输入: {text}")
    print(f"意图: {result['intent']} (置信度: {result['confidence']})")
    print()
```

**优点**：能处理一定的同义表达、自动学习特征
**缺点**：需要训练数据、特征工程繁琐、对复杂语句理解有限

### 2.3 技术三：基于深度学习的意图识别（BERT）

利用预训练的 BERT 模型，通过微调实现高精度意图识别。

```python
# 注意：需要安装 transformers 和 torch
# pip install transformers torch

from transformers import BertTokenizer, BertForSequenceClassification
from transformers import Trainer, TrainingArguments
import torch
from torch.utils.data import Dataset


class IntentDataset(Dataset):
    """意图识别数据集"""

    def __init__(self, texts, labels, tokenizer, max_length=64):
        self.texts = texts
        self.labels = labels
        self.tokenizer = tokenizer
        self.max_length = max_length

    def __len__(self):
        return len(self.texts)

    def __getitem__(self, idx):
        encoding = self.tokenizer(
            self.texts[idx],
            truncation=True,
            padding='max_length',
            max_length=self.max_length,
            return_tensors='pt',
        )
        return {
            'input_ids': encoding['input_ids'].squeeze(),
            'attention_mask': encoding['attention_mask'].squeeze(),
            'labels': torch.tensor(self.labels[idx], dtype=torch.long),
        }


class BERTIntentRecognizer:
    """基于 BERT 的意图识别器

    使用预训练中文BERT模型进行意图分类微调。
    """

    def __init__(self, model_name='bert-base-chinese'):
        self.tokenizer = BertTokenizer.from_pretrained(model_name)
        self.label_map = {}    # 意图名称 → 数字ID
        self.id_to_label = {}  # 数字ID → 意图名称
        self.model = None

    def _prepare_data(self):
        """准备训练数据"""
        # 这里简化演示，实际项目中从文件加载
        data = {
            "查询天气": ["今天天气如何", "明天会下雨吗", "气温多少度"],
            "订票":     ["订一张机票", "买火车票", "预订航班"],
            "查询订单": ["快递到哪了", "查订单状态", "物流信息"],
            "退款":     ["我要退款", "申请退货", "退钱"],
            "人工客服": ["转人工", "找客服", "投诉"],
        }

        # 构建标签映射
        intents = list(data.keys())
        self.label_map = {intent: idx for idx, intent in enumerate(intents)}
        self.id_to_label = {idx: intent for intent, idx in self.label_map.items()}

        texts, labels = [], []
        for intent, examples in data.items():
            for example in examples:
                texts.append(example)
                labels.append(self.label_map[intent])

        return texts, labels

    def train(self, epochs=3, learning_rate=2e-5):
        """微调 BERT 模型"""
        texts, labels = self._prepare_data()

        # 初始化模型
        num_labels = len(self.label_map)
        self.model = BertForSequenceClassification.from_pretrained(
            'bert-base-chinese',
            num_labels=num_labels,
        )

        # 创建数据集
        dataset = IntentDataset(texts, labels, self.tokenizer)

        # 训练参数
        training_args = TrainingArguments(
            output_dir='./intent_model',
            num_train_epochs=epochs,
            per_device_train_batch_size=8,
            learning_rate=learning_rate,
            logging_steps=10,
            save_strategy='no',  # 不保存检查点（演示用）
        )

        # 开始训练
        trainer = Trainer(
            model=self.model,
            args=training_args,
            train_dataset=dataset,
        )
        trainer.train()
        print("BERT 微调完成！")

    def recognize(self, text: str) -> dict:
        """识别意图"""
        if self.model is None:
            raise RuntimeError("请先调用 train() 训练模型")

        self.model.eval()
        encoding = self.tokenizer(
            text, truncation=True, padding=True,
            max_length=64, return_tensors='pt',
        )

        with torch.no_grad():
            outputs = self.model(**encoding)
            probs = torch.softmax(outputs.logits, dim=-1)
            pred_id = torch.argmax(probs, dim=-1).item()
            confidence = probs[0][pred_id].item()

        return {
            "intent": self.id_to_label[pred_id],
            "confidence": round(confidence, 3),
        }


# 使用示例（需要安装 transformers 和 torch）

# print(result)  # {'intent': '查询天气', 'confidence': 0.96}
```

| 特性 | 规则匹配 | 机器学习(TF-IDF+NB) | 深度学习(BERT) |
|------|---------|-------------------|---------------|
| 准确率 | 低-中 | 中 | 高 |

| 泛化能力 | 差 | 中 | 强 |
| 开发成本 | 低 | 中 | 高 |

## 3. 槽位提取（Slot Filling）

### 3.1 什么是槽位

意图告诉我们用户**想做什么**，槽位告诉我们**具体参数**是什么。

```
用户输入："我想订一张明天北京到上海的机票"

意图识别结果：订票
槽位提取结果：
  ┌──────────┬────────┐
  │ 槽位名称  │  值    │
  ├──────────┼────────┤
  │ 出发地    │ 北京   │
  │ 目的地    │ 上海   │
  │ 日期      │ 明天   │
  │ 数量      │ 一张   │
  └──────────┴────────┘
```

### 3.2 槽位提取实现

```python
import re
from datetime import datetime, timedelta


class SlotExtractor:
    """槽位提取器

    根据不同的意图，使用正则表达式和规则提取关键参数。
    """

    def __init__(self):
        # 通用正则模式
        self.date_patterns = [
            (r'今天', self._today),
            (r'明天', self._tomorrow),
            (r'后天', self._day_after_tomorrow),
            (r'大后天', self._three_days_later),
            (r'(\d{1,2})月(\d{1,2})[日号]', self._specific_date),
        ]

        self.city_pattern = re.compile(
            r'([一-龥]{2,4}(?:市|省)?)'
        )

        self.quantity_pattern = re.compile(
            r'([一二三四五六七八九十\d]+)张|([一二三四五六七八九十\d]+)份'
        )

    def _today(self, match=None):
        return datetime.now().strftime('%Y-%m-%d')

    def _tomorrow(self, match=None):
        return (datetime.now() + timedelta(days=1)).strftime('%Y-%m-%d')

    def _day_after_tomorrow(self, match=None):
        return (datetime.now() + timedelta(days=2)).strftime('%Y-%m-%d')

    def _three_days_later(self, match=None):
        return (datetime.now() + timedelta(days=3)).strftime('%Y-%m-%d')

    def _specific_date(self, match):
        month, day = int(match.group(1)), int(match.group(2))
        year = datetime.now().year
        return f'{year}-{month:02d}-{day:02d}'

    def _extract_date(self, text: str) -> str | None:
        """提取日期信息"""
        for pattern, handler in self.date_patterns:
            match = re.search(pattern, text)
            if match:
                return handler(match)
        return None

    def _extract_cities(self, text: str) -> list:
        """提取城市名称（简单版本，实际项目用NER模型）"""
        # 常见城市列表（简化版）
        known_cities = [
            '北京', '上海', '广州', '深圳', '成都', '杭州',
            '武汉', '南京', '重庆', '西安', '天津', '苏州',
            '长沙', '青岛', '大连', '厦门', '三亚', '昆明',
        ]
        found = []
        for city in known_cities:
            if city in text:
                found.append(city)
        return found

    def _extract_quantity(self, text: str) -> int:
        """提取数量"""
        chinese_nums = {
            '一': 1, '二': 2, '两': 2, '三': 3,
            '四': 4, '五': 5, '六': 6, '七': 7,
            '八': 8, '九': 9, '十': 10,
        }

        # 先尝试中文数字
        for ch, num in chinese_nums.items():
            if ch + '张' in text or ch + '份' in text:
                return num

        # 再尝试阿拉伯数字
        match = re.search(r'(\d+)[张份]', text)
        if match:
            return int(match.group(1))

        return 1  # 默认1个

    def extract(self, text: str, intent: str) -> dict:
        """根据意图提取对应槽位

        Args:
            text: 用户输入
            intent: 已识别的意图

        Returns:
            dict: 槽位字典
        """
        slots = {}

        if intent == "查询天气":
            cities = self._extract_cities(text)
            if cities:
                slots['city'] = cities[0]
            date = self._extract_date(text)
            if date:
                slots['date'] = date

        elif intent == "订票":
            cities = self._extract_cities(text)
            if len(cities) >= 2:
                slots['departure'] = cities[0]
                slots['destination'] = cities[1]
            elif len(cities) == 1:
                # 只有一个城市，可能是目的地
                slots['destination'] = cities[0]

            date = self._extract_date(text)
            if date:
                slots['date'] = date

            quantity = self._extract_quantity(text)
            slots['quantity'] = quantity

        elif intent == "查询订单":
            # 提取订单号（假设格式：字母+数字）
            order_match = re.search(r'[A-Za-z]{2}\d{10,}', text)
            if order_match:
                slots['order_id'] = order_match.group()

        elif intent == "退款":
            order_match = re.search(r'[A-Za-z]{2}\d{10,}', text)
            if order_match:
                slots['order_id'] = order_match.group()

            # 退款原因
            reasons = ['质量问题', '不想要了', '买错了', '尺码不对']
            for reason in reasons:
                if reason in text:
                    slots['reason'] = reason
                    break

        return slots
```

## 4. LLM 意图识别（LangChain 方式）

### 4.1 为什么用 LLM 做意图识别

传统方法的痛点：
- 规则方法：覆盖不全，维护成本高
- 机器学习：需要大量标注数据
- 深度学习：需要GPU，部署复杂

LLM 的优势：
- **零样本**：不需要训练数据
- **理解能力强**：能理解复杂、模糊的表达
- **一次性输出**：同时完成意图分类和槽位提取
- **易于更新**：修改提示词即可调整

### 4.2 使用 LangChain 结构化输出

```python
from pydantic import BaseModel, Field
from langchain.chat_models import init_chat_model
from typing import Literal


class IntentResult(BaseModel):
    """意图识别结果的结构化定义"""

    intent: Literal[
        "查询天气", "订票", "查询订单",
        "退款", "人工客服", "问候", "其他"
    ] = Field(
        description="识别出的用户意图"
    )

    confidence: float = Field(
        description="置信度，0到1之间",
        ge=0.0,
        le=1.0,
    )

    slots: dict = Field(
        default_factory=dict,
        description="提取的槽位信息，如城市、日期等",
    )

    reasoning: str = Field(
        description="推理过程，解释为什么判断为此意图",
    )


class LLMIntentRecognizer:
    """基于 LLM 的意图识别器

    使用 LangChain 的结构化输出功能，
    让 LLM 一次性返回意图、置信度和槽位信息。
    """

    def __init__(self, model_string: str = "groq:llama-3.3-70b-versatile"):
        model = init_chat_model(model_string)
        self.structured_model = model.with_structured_output(IntentResult)

    def recognize(self, user_input: str) -> IntentResult:
        """识别用户意图

        Args:
            user_input: 用户输入的文本

        Returns:
            IntentResult: 结构化的意图识别结果
        """
        prompt = f"""请分析以下用户输入，识别用户的真实意图。

支持的意图类别：
- 查询天气：用户想了解天气、气温、是否下雨等
- 订票：用户想预订机票、火车票、酒店等
- 查询订单：用户想查看订单状态、物流信息等
- 退款：用户想退货、退款、投诉商品质量等
- 人工客服：用户想找真人客服、投诉等
- 问候：用户在打招呼
- 其他：不属于以上任何类别

用户输入：{user_input}"""

        result = self.structured_model.invoke(prompt)
        return result
```

## 5. 多意图识别

### 5.1 什么是多意图

用户一句话可能包含多个意图：

```
"帮我查明天北京天气，然后订张去上海的票"
  ├── 意图1：查询天气（城市=北京，日期=明天）
  └── 意图2：订票（目的地=上海）

"我要退款，另外帮我看看有没有新的推荐"
  ├── 意图1：退款
  └── 意图2：商品推荐
```

### 5.2 多意图识别实现

```python
import re
from pydantic import BaseModel, Field
from typing import List


class SingleIntent(BaseModel):
    """单个意图"""
    intent: str = Field(description="意图名称")
    confidence: float = Field(description="置信度")
    slots: dict = Field(description="槽位信息")
    related_text: str = Field(description="对应的原始文本片段")


class MultiIntentResult(BaseModel):
    """多意图识别结果"""
    intents: List[SingleIntent] = Field(description="识别出的意图列表")
    is_multi_intent: bool = Field(description="是否包含多个意图")


class MultiIntentRecognizer:
    """多意图识别器

    通过分句 + 逐句识别的方式处理多意图。
    """

    def __init__(self):
        # 连词和分隔符
        self.splitters = [
            '然后', '接着', '另外', '同时', '还有',
            '顺便', '再', '并且', '而且', '也',
            '，', '。', '；',
        ]

    def _split_sentences(self, text: str) -> list:
        """将包含多意图的文本分割成多个子句

        Args:
            text: 用户输入

        Returns:
            list: 分割后的子句列表
        """
        # 构建分割正则
        pattern = '|'.join(re.escape(s) for s in self.splitters)
        parts = re.split(pattern, text)

        # 过滤空串和过短的片段
        sentences = []
        for part in parts:
            part = part.strip()
            if len(part) >= 2:  # 至少2个字符才算有意义
                sentences.append(part)

        return sentences if sentences else [text]

    def recognize(self, text: str, single_recognizer) -> MultiIntentResult:
        """识别多个意图

        Args:
            text: 用户输入
            single_recognizer: 单意图识别器（需要有 recognize 方法）

        Returns:
            MultiIntentResult: 多意图识别结果
        """
        sentences = self._split_sentences(text)

        intents = []
        for sentence in sentences:
            result = single_recognizer.recognize(sentence)

            # 统一处理不同格式的结果
            if hasattr(result, 'intent'):
                # LLM 返回的 IntentResult
                intents.append(SingleIntent(
                    intent=result.intent,
                    confidence=result.confidence,
                    slots=result.slots if hasattr(result, 'slots') else {},
                    related_text=sentence,
                ))
            elif isinstance(result, dict):
                # 字典格式的结果
                intents.append(SingleIntent(
                    intent=result.get('intent', '未知'),
                    confidence=result.get('confidence', 0.0),
                    slots=result.get('slots', {}),
                    related_text=sentence,
                ))

        return MultiIntentResult(
            intents=intents,
            is_multi_intent=len(intents) > 1,
        )

    sentences = multi_recognizer._split_sentences(text)

    print()
```

## 6. 置信度校准

### 6.1 为什么要校准置信度

识别器返回的置信度不一定准确。一个返回0.9置信度的结果可能实际只有0.7的准确率。
置信度校准（Calibration）让置信度更接近真实准确率。

### 6.2 分级处理策略

```
置信度分级处理流程：

用户输入
    │
    ▼
┌──────────────┐
│  意图识别     │
└──────┬───────┘
       │
       ▼
┌──────────────────────────────────────────────┐
│            置信度判断                          │
│                                              │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐      │
│  │ >= 0.85 │  │ >= 0.60 │  │ >= 0.30 │      │
│  │ 高置信  │  │ 中置信  │  │ 低置信  │      │
│  └────┬────┘  └────┬────┘  └────┬────┘      │
│       │            │            │            │
│       ▼            ▼            ▼            │
│   直接执行     二次确认     提供选项          │
│                                              │
│  ┌─────────┐                                 │
│  │ < 0.30  │                                 │
│  │ 很低    │                                 │
│  └────┬────┘                                 │
│       │                                      │
│       ▼                                      │
│   拒绝识别                                   │
└──────────────────────────────────────────────┘
```

```python
class ConfidenceHandler:
    """置信度分级处理器

    根据不同的置信度水平，采取不同的处理策略。
    """

    def __init__(self, recognizer):
        self.recognizer = recognizer

        # 置信度阈值配置
        self.thresholds = {
            'high':   0.85,  # 高置信度：直接执行
            'medium': 0.60,  # 中置信度：二次确认
            'low':    0.30,  # 低置信度：提供选项
            # 低于0.30：拒绝识别
        }

    def process(self, user_input: str) -> dict:
        """处理用户输入，返回处理策略和结果

        Args:
            user_input: 用户输入

        Returns:
            dict: {
                'action': 处理动作,
                'intent': 识别的意图,
                'confidence': 置信度,
                'message': 回复用户的消息,
            }
        """
        result = self.recognizer.recognize(user_input)
        intent = result.get('intent', '未知意图')
        confidence = result.get('confidence', 0.0)

        if confidence >= self.thresholds['high']:
            return {
                'action': 'execute',
                'intent': intent,
                'confidence': confidence,
                'message': f'好的，正在为您{intent}...',
            }

        elif confidence >= self.thresholds['medium']:
            return {
                'action': 'confirm',
                'intent': intent,
                'confidence': confidence,
                'message': f'您是想{intent}吗？请确认。',
                'options': [intent, '其他需求'],
            }

        elif confidence >= self.thresholds['low']:
            return {
                'action': 'provide_options',
                'intent': intent,
                'confidence': confidence,
                'message': '我不太确定您的意思，您是想：',
                'options': [
                    '查询天气', '订票', '查询订单',
                    '退款', '转人工客服', '其他',
                ],
            }

        else:
            return {
                'action': 'reject',
                'intent': None,
                'confidence': confidence,
                'message': '抱歉，我没有理解您的意思。您可以换个说法，或者输入"人工客服"寻求帮助。',
            }
```

## 7. 完整实战案例：智能客服机器人

```python
from datetime import datetime
from typing import Optional


class ConversationMemory:
    """对话记忆管理"""

    def __init__(self, max_history: int = 10):
        self.history = []       # 对话历史
        self.max_history = max_history
        self.context = {}       # 上下文信息（跨轮次共享）

    def add_user_message(self, message: str):
        self.history.append({
            'role': 'user',
            'content': message,
            'timestamp': datetime.now().isoformat(),
        })
        # 保持历史长度
        if len(self.history) > self.max_history * 2:
            self.history = self.history[-self.max_history * 2:]

    def add_ai_message(self, message: str):
        self.history.append({
            'role': 'assistant',
            'content': message,
            'timestamp': datetime.now().isoformat(),
        })

    def update_context(self, key: str, value):
        """更新上下文（如当前正在处理的订单号）"""
        self.context[key] = value

    def get_context(self, key: str, default=None):
        return self.context.get(key, default)

    def get_recent_history(self, n: int = 5) -> list:
        return self.history[-n:]

    def clear(self):
        self.history.clear()
        self.context.clear()


class SmartCustomerServiceBot:
    """智能客服机器人

    整合意图识别、槽位提取、置信度处理和多轮对话。
    """

    def __init__(self):
        # 初始化各组件
        self.intent_recognizer = RuleBasedIntentRecognizer()
        self.slot_extractor = SlotExtractor()
        self.confidence_handler = ConfidenceHandler(self.intent_recognizer)
        self.memory = ConversationMemory(max_history=20)

        # 意图处理函数映射
        self.handlers = {
            "查询天气": self._handle_weather,
            "订票":     self._handle_booking,
            "查询订单": self._handle_order_query,
            "退款":     self._handle_refund,
            "人工客服": self._handle_human_agent,
            "问候":     self._handle_greeting,
        }

    def _handle_weather(self, slots: dict) -> str:
        """处理天气查询"""
        city = slots.get('city', '您所在的城市')
        date = slots.get('date', '今天')
        return (
            f"正在为您查询{date}{city}的天气...\n"
            f"{date}{city}天气：晴，气温 18-26°C，适合出行。"
        )

    def _handle_booking(self, slots: dict) -> str:
        """处理订票"""
        destination = slots.get('destination', '未知目的地')
        departure = slots.get('departure', '您的出发城市')
        date = slots.get('date', '待定')
        quantity = slots.get('quantity', 1)

        # 如果缺少关键信息，追问
        missing = []
        if 'destination' not in slots:
            missing.append('目的地')
        if 'departure' not in slots:
            missing.append('出发城市')
        if 'date' not in slots:
            missing.append('出发日期')

        if missing:
            return f"好的，帮您订票。请告诉我您的{'、'.join(missing)}。"

        return (
            f"为您查询 {departure} → {destination} {date} 的票务信息：\n"
            f"- 高铁：约3小时，票价 ￥553\n"
            f"- 飞机：约2小时，票价 ￥890\n"
            f"需要帮您预订哪个？（{quantity}张）"
        )

    def _handle_order_query(self, slots: dict) -> str:
        """处理订单查询"""
        order_id = slots.get('order_id',
                             self.memory.get_context('last_order_id'))
        if not order_id:
            return "请提供您的订单号，我帮您查询。"

        # 保存到上下文
        self.memory.update_context('last_order_id', order_id)

        return (
            f"订单 {order_id} 状态：\n"
            f"- 下单时间：2026-05-05 14:30\n"
            f"- 当前状态：已发货，运输中\n"
            f"- 预计送达：2026-05-08\n"
            f"- 物流公司：顺丰速运"
        )

    def _handle_refund(self, slots: dict) -> str:
        """处理退款"""
        order_id = slots.get('order_id',
                             self.memory.get_context('last_order_id'))
        reason = slots.get('reason', '未说明原因')

        if not order_id:
            return "请提供需要退款的订单号。"

        self.memory.update_context('refund_order_id', order_id)
        self.memory.update_context('refund_reason', reason)

        return (
            f"收到您的退款申请：\n"
            f"- 订单号：{order_id}\n"
            f"- 退款原因：{reason}\n"
            f"退款将在3-5个工作日内处理，金额原路退回。"
        )

    def _handle_human_agent(self, slots: dict) -> str:
        """转人工客服"""
        return (
            "正在为您转接人工客服...\n"
            "当前排队人数：3人，预计等待时间：5分钟。\n"
            "请稍候，人工客服即将接入。"
        )

    def _handle_greeting(self, slots: dict) -> str:
        """处理问候"""
        hour = datetime.now().hour
        if hour < 12:
            greeting = "上午好"
        elif hour < 18:
            greeting = "下午好"
        else:
            greeting = "晚上好"

        return (
            f"{greeting}！欢迎联系智能客服。\n"
            f"我可以帮您：查询天气、预订机票、查询订单、处理退款等。\n"
            f"请问有什么可以帮您的？"
        )

    def chat(self, user_input: str) -> str:
        """处理用户输入并返回回复

        Args:
            user_input: 用户输入

        Returns:
            str: 机器人回复
        """
        # 记录用户消息
        self.memory.add_user_message(user_input)

        # 1. 检查是否是确认/取消类回复（处理二次确认场景）
        last_action = self.memory.get_context('last_action')
        if last_action == 'waiting_confirm':
            if user_input.strip() in ['是', '对', '确认', '好', 'yes', 'y']:
                intent = self.memory.get_context('pending_intent')
                slots = self.memory.get_context('pending_slots')
                self.memory.update_context('last_action', None)
                handler = self.handlers.get(intent, self._handle_unknown)
                response = handler(slots)
            elif user_input.strip() in ['否', '不', '取消', 'no', 'n']:
                self.memory.update_context('last_action', None)
                response = "好的，已取消。请问还有什么可以帮您的？"
            else:
                # 用户说了别的，重新识别意图
                self.memory.update_context('last_action', None)
                return self.chat(user_input)
        else:
            # 2. 意图识别
            result = self.confidence_handler.process(user_input)
            action = result['action']
            intent = result.get('intent')
            confidence = result.get('confidence', 0)

            if action == 'execute':
                # 高置信度：直接执行
                slots = self.slot_extractor.extract(user_input, intent)
                handler = self.handlers.get(intent, self._handle_unknown)
                response = handler(slots)

            elif action == 'confirm':
                # 中置信度：二次确认
                self.memory.update_context('pending_intent', intent)
                self.memory.update_context('pending_slots',
                    self.slot_extractor.extract(user_input, intent))
                self.memory.update_context('last_action', 'waiting_confirm')
                response = result['message']

            elif action == 'provide_options':
                # 低置信度：提供选项
                options = result.get('options', [])
                response = result['message'] + '\n'
                for i, opt in enumerate(options, 1):
                    response += f"  {i}. {opt}\n"
                response += "请输入数字或直接告诉我您的需求。"

            else:
                # 极低置信度：拒绝
                response = result['message']

        # 3. 记录回复
        self.memory.add_ai_message(response)
        return response

    def _handle_unknown(self, slots: dict) -> str:
        return "抱歉，我暂时无法处理这个需求。需要转接人工客服吗？"
```

## 8. 常见错误与最佳实践

### 8.1 常见错误

**错误一：只用关键词匹配，不做语义理解**

```python
# 错误示例
def bad_recognizer(text):
    if "天气" in text:
        return "查询天气"
    # "外面冷不冷" 会被漏掉！

# 正确做法：结合同义词、上下文，或使用LLM
```

**错误二：忽略置信度阈值**

```python
# 错误示例：不管置信度多低都执行
result = recognizer.recognize(user_input)
execute(result['intent'])  # 置信度0.1也执行？太危险了

# 正确做法：设置阈值，低置信度时二次确认
```

**错误三：槽位缺失不追问**

```python
# 错误示例：缺少关键参数直接执行
def bad_booking(slots):
    # 没有目的地就订票？
    return book_ticket(slots)

# 正确做法：检查必要槽位，缺失时追问
def good_booking(slots):
    if 'destination' not in slots:
        return "请问您要去哪里？"
    return book_ticket(slots)
```

**错误四：对话历史无限增长**

```python
# 错误示例：永远追加，从不清理
self.history.append(message)  # 100轮后，token爆炸

# 正确做法：限制历史长度
if len(self.history) > self.max_history:
    self.history = self.history[-self.max_history:]
```

**错误五：硬编码所有逻辑**

```python
# 错误示例：每个新意图都要改代码
if intent == "天气":
    handle_weather()
elif intent == "订票":
    handle_booking()
# ... 100个 elif

# 正确做法：使用映射表，方便扩展
handlers = {"天气": handle_weather, "订票": handle_booking}
handler = handlers.get(intent, handle_unknown)
```

### 8.2 最佳实践

1. **混合策略**：简单场景用规则，复杂场景用LLM，兼顾速度和准确率
2. **置信度分级**：高置信度直接执行，低置信度要确认或提供选项
3. **槽位验证**：提取槽位后要验证合理性（如日期不能是过去的）
4. **上下文记忆**：记住之前的信息，避免重复询问
5. **优雅降级**：识别失败时给用户明确指引，不要卡死
6. **日志记录**：记录每次识别结果，便于分析和改进
7. **A/B测试**：新旧模型并行运行，对比效果后再切换
8. **定期更新**：根据用户反馈和新场景，持续优化意图库
