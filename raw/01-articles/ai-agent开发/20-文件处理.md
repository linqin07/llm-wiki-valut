## 文档加载器总览

### 什么是文档加载器

文档加载器（Document Loaders）是 LangChain 中用于从各种来源读取数据的组件。它们将不同格式的文件统一转换为 `Document` 对象。

```
各种文件格式:
  PDF, TXT, CSV, JSON, HTML, Word, Markdown
        |
        v
  +------------+
  | Document   |  <-- 统一格式
  | Loader     |
  +-----+------+
        |
        v
  Document 对象:
  {
    "page_content": "文件内容文本...",
    "metadata": {
        "source": "文件路径",
        "page": 1,
        ...
    }
  }
```

### Document 对象结构

```python
from langchain_core.documents import Document

# Document 对象包含两部分
doc = Document(
    page_content="这是文档的主要内容文本",  # 文本内容
    metadata={                              # 元数据
        "source": "path/to/file.pdf",
        "page": 1,
        "author": "张三",
    }
)
```

### 常用加载器一览

| 加载器 | 用途 | 依赖包 |
|--------|------|--------|
| `PyPDFLoader` | 加载 PDF | `pypdf` |
| `TextLoader` | 加载纯文本 | 内置 |
| `CSVLoader` | 加载 CSV | 内置 |
| `JSONLoader` | 加载 JSON | `jq` |
| `BSHTMLLoader` | 加载 HTML | `beautifulsoup4` |
| `UnstructuredWordDocumentLoader` | 加载 Word | `unstructured` |
| `MarkdownLoader` | 加载 Markdown | 内置 |
| `DirectoryLoader` | 批量加载文件夹 | 内置 |

## 格式专用加载器

### PyPDFLoader - 加载 PDF

```python
from langchain_community.document_loaders import PyPDFLoader

# 加载 PDF 文件
loader = PyPDFLoader("path/to/document.pdf")

# 加载所有页面
pages = loader.load()

# 查看结果
print(f"总页数: {len(pages)}")
for i, page in enumerate(pages):
    print(f"第 {i+1} 页: {page.page_content[:100]}...")
    print(f"  元数据: {page.metadata}")
```

**PDF 加载器特点：**

```
PDF 文件
  |
  +--- 第1页 --> Document(page_content="...", metadata={"page": 0})
  +--- 第2页 --> Document(page_content="...", metadata={"page": 1})
  +--- 第3页 --> Document(page_content="...", metadata={"page": 2})
```

**按页加载（适合大文件）：**

```python
# 懒加载：按需加载每页
loader = PyPDFLoader("large_document.pdf")

# 只加载特定页
async def load_page(page_num: int):
    async for page in loader.alazy_load():
        if page.metadata["page"] == page_num:
            return page

# 逐页处理
for page in loader.lazy_load():
    process_page(page)
```

### TextLoader - 加载纯文本

```python
from langchain_community.document_loaders import TextLoader

# 基本加载
loader = TextLoader("path/to/file.txt", encoding="utf-8")
documents = loader.load()

print(f"文档数量: {len(documents)}")
print(f"内容: {documents[0].page_content[:200]}")
```

**编码处理：**

```python
# 中文文件需要指定正确的编码
loader = TextLoader("chinese_text.txt", encoding="utf-8")

# 如果不确定编码，尝试常见编码
encodings = ["utf-8", "gbk", "gb2312", "latin-1"]
for enc in encodings:
    try:
        loader = TextLoader("file.txt", encoding=enc)
        docs = loader.load()
        print(f"使用编码 {enc} 成功加载")
        break
    except UnicodeDecodeError:
        continue
```

## DirectoryLoader 批量加载

### 基本用法

```python
from langchain_community.document_loaders import DirectoryLoader

# 加载整个目录
loader = DirectoryLoader("docs/", glob="**/*.txt")
documents = loader.load()

print(f"共加载 {len(documents)} 个文档")
```

### glob 模式

```python
# 加载所有 .txt 文件
loader = DirectoryLoader("docs/", glob="*.txt")

# 递归加载所有子目录中的 .pdf 文件
loader = DirectoryLoader("docs/", glob="**/*.pdf")

# 加载多种格式
loader = DirectoryLoader("docs/", glob="**/*.{txt,md,pdf}")

# 排除特定文件
loader = DirectoryLoader(
    "docs/",
    glob="**/*.txt",
    exclude="**/test_*",  # 排除 test_ 开头的文件
)
```

### 使用不同加载器

```python
from langchain_community.document_loaders import (
    DirectoryLoader,
    TextLoader,
    PyPDFLoader,
)

# 对不同格式使用不同加载器
txt_loader = DirectoryLoader(
    "docs/",
    glob="**/*.txt",
    loader_cls=TextLoader,
    loader_kwargs={"encoding": "utf-8"},
)

pdf_loader = DirectoryLoader(
    "docs/",
    glob="**/*.pdf",
    loader_cls=PyPDFLoader,
)

# 合并结果
all_documents = txt_loader.load() + pdf_loader.load()
```

### 懒加载（大目录推荐）

```python
# 懒加载：不一次性读取所有文件
loader = DirectoryLoader("large_docs/", glob="**/*.txt")

# 使用 lazy_load() 逐个加载
for doc in loader.lazy_load():
    process(doc)
```

### 多线程加载

```python
# 使用多线程加速加载
loader = DirectoryLoader(
    "docs/",
    glob="**/*.txt",
    use_multithreading=True,  # 启用多线程
)
documents = loader.load()
```

## 文本分块策略

### 为什么要分块

```
长文档（例如 10000 字）
        |
        v
  +------------+
  | 文本分块   |  <-- 将长文本切分为小块
  | Splitter   |
  +-----+------+
        |
        v
  块1 (500字) + 块2 (500字) + 块3 (500字) + ...

分块的好处：
1. 适应 LLM 上下文窗口限制
2. 提高检索精度（小块更相关）
3. 减少不必要的 token 消耗
```

### RecursiveCharacterTextSplitter

最常用的分块器，按递归优先级分割文本：

```python
from langchain_text_splitters import RecursiveCharacterTextSplitter

# 创建分块器
splitter = RecursiveCharacterTextSplitter(
    chunk_size=500,       # 每块最大字符数
    chunk_overlap=50,     # 块之间的重叠字符数
    length_function=len,  # 长度计算函数
)

# 分块
chunks = splitter.split_documents(documents)

print(f"原始文档数: {len(documents)}")
print(f"分块后: {len(chunks)}")
for i, chunk in enumerate(chunks[:3]):
    print(f"\n块 {i+1} (长度 {len(chunk.page_content)}):")
    print(chunk.page_content[:100] + "...")
```

### 分割优先级

RecursiveCharacterTextSplitter 按以下优先级尝试分割：

```
分割优先级（从高到低）:
1. "\n\n"  - 段落分隔
2. "\n"    - 换行
3. " "     - 空格（单词）
4. ""      - 字符（最后手段）

示例：
原文: "第一段内容。\n\n第二段内容。\n\n第三段内容。"
      |
      v 按 "\n\n" 分割
块1: "第一段内容。"
块2: "第二段内容。"
块3: "第三段内容。"
```

### chunk_size 和 chunk_overlap 的选择

```
chunk_size 选择指南：
+------------------+-----------------------------------+
| chunk_size       | 适用场景                          |
+------------------+-----------------------------------+
| 200-500          | 精确检索（FAQ、代码片段）         |
| 500-1000         | 通用文档（文章、报告）            |
| 1000-2000        | 长文档（论文、书籍章节）          |
| 2000+            | 需要大上下文的场景                |
+------------------+-----------------------------------+

chunk_overlap 选择指南：
+------------------+-----------------------------------+
| chunk_overlap    | 说明                              |
+------------------+-----------------------------------+
| 0                | 无重叠，可能丢失上下文            |
| 50-100           | 轻度重叠，适合短块                |
| 100-200          | 中度重叠，推荐大多数场景          |
| 200+             | 高度重叠，上下文连续性要求高时    |
+------------------+-----------------------------------+
```

**经验法则：**

```python
# chunk_overlap 通常设为 chunk_size 的 10%-20%
chunk_size = 500
chunk_overlap = 50  # 10%

# 或
chunk_size = 1000
chunk_overlap = 150  # 15%
```

## 与 RAG 管道的集成

### 完整的 RAG 文件处理流程

```
文件（PDF/TXT/CSV/...）
    |
    v
+---+---+
| 文档  |  DocumentLoader
| 加载  |
+---+---+
    |
    v
Document 列表
    |
    v
+---+---+
| 文本  |  TextSplitter
| 分块  |
+---+---+
    |
    v
Chunk 列表
    |
    v
+---+---+
| 向量  |  Embedding Model
| 嵌入  |
+---+---+
    |
    v
+---+---+
| 向量  |  VectorStore
| 存储  |
+---+---+
    |
    v
检索 + 生成回答
```

### 代码实现

```python
"""
完整的 RAG 文件处理管道
"""
from langchain_community.document_loaders import PyPDFLoader
from langchain_text_splitters import RecursiveCharacterTextSplitter
from langchain_core.vectorstores import InMemoryVectorStore
from langchain_openai import OpenAIEmbeddings
from langchain.chat_models import init_chat_model
from langchain_core.messages import HumanMessage

# 1. 加载文档
loader = PyPDFLoader("knowledge_base.pdf")
documents = loader.load()
print(f"加载了 {len(documents)} 页")

# 2. 分块
splitter = RecursiveCharacterTextSplitter(
    chunk_size=500,
    chunk_overlap=50,
)
chunks = splitter.split_documents(documents)
print(f"分块后 {len(chunks)} 块")

# 3. 向量化并存储
embeddings = OpenAIEmbeddings()
vectorstore = InMemoryVectorStore.from_documents(chunks, embeddings)

# 4. 检索
query = "什么是机器学习？"
relevant_docs = vectorstore.similarity_search(query, k=3)
context = "\n\n".join([doc.page_content for doc in relevant_docs])

# 5. 生成回答
model = init_chat_model("groq:llama-3.3-70b-versatile")
response = model.invoke([
    HumanMessage(content=f"根据以下上下文回答问题：\n\n上下文：{context}\n\n问题：{query}")
])
print(response.content)
```

## 完整代码示例

### 示例1：加载多种格式文件

```python
"""
文件处理综合示例
支持加载 PDF、TXT、CSV、Markdown 文件
"""
from langchain_community.document_loaders import (
    PyPDFLoader,
    TextLoader,
    CSVLoader,
    MarkdownLoader,
    DirectoryLoader,
)
from langchain_text_splitters import RecursiveCharacterTextSplitter

def load_single_file(file_path: str) -> list:
    """根据文件扩展名选择合适的加载器"""
    import os
    ext = os.path.splitext(file_path)[1].lower()

    loaders = {
        ".pdf": lambda: PyPDFLoader(file_path),
        ".txt": lambda: TextLoader(file_path, encoding="utf-8"),
        ".csv": lambda: CSVLoader(file_path),
        ".md": lambda: MarkdownLoader(file_path),
    }

    loader_factory = loaders.get(ext)
    if not loader_factory:
        raise ValueError(f"不支持的文件格式: {ext}")

    return loader_factory().load()

def load_directory(dir_path: str, glob_pattern: str = "**/*.*") -> list:
    """加载整个目录"""
    loader = DirectoryLoader(dir_path, glob=glob_pattern)
    return loader.load()

def split_documents(documents: list, chunk_size: int = 500, chunk_overlap: int = 50) -> list:
    """分块文档"""
    splitter = RecursiveCharacterTextSplitter(
        chunk_size=chunk_size,
        chunk_overlap=chunk_overlap,
    )
    return splitter.split_documents(documents)

# 使用示例
if __name__ == "__main__":
    # 加载单个文件
    docs = load_single_file("document.pdf")
    print(f"加载了 {len(docs)} 个文档")

    # 分块
    chunks = split_documents(docs, chunk_size=500, chunk_overlap=50)
    print(f"分块后 {len(chunks)} 块")

    # 查看前几块
    for i, chunk in enumerate(chunks[:3]):
        print(f"\n--- 块 {i+1} ---")
        print(chunk.page_content[:200])
        print(f"元数据: {chunk.metadata}")
```

### 示例2：PDF 处理管道

```python
"""
PDF 处理管道
从 PDF 文件构建可检索的知识库
"""
from langchain_community.document_loaders import PyPDFLoader
from langchain_text_splitters import RecursiveCharacterTextSplitter
from langchain_core.vectorstores import InMemoryVectorStore
from langchain_openai import OpenAIEmbeddings

class PDFProcessor:
    def __init__(self, chunk_size: int = 500, chunk_overlap: int = 50):
        self.chunk_size = chunk_size
        self.chunk_overlap = chunk_overlap
        self.vectorstore = None

    def load_pdf(self, pdf_path: str) -> list:
        """加载 PDF 文件"""
        loader = PyPDFLoader(pdf_path)
        return loader.load()

    def split_documents(self, documents: list) -> list:
        """分块文档"""
        splitter = RecursiveCharacterTextSplitter(
            chunk_size=self.chunk_size,
            chunk_overlap=self.chunk_overlap,
        )
        return splitter.split_documents(documents)

    def build_index(self, pdf_path: str):
        """构建索引"""
        print(f"正在加载 PDF: {pdf_path}")
        documents = self.load_pdf(pdf_path)
        print(f"  页数: {len(documents)}")

        print("正在分块...")
        chunks = self.split_documents(documents)
        print(f"  块数: {len(chunks)}")

        print("正在构建向量索引...")
        embeddings = OpenAIEmbeddings()
        self.vectorstore = InMemoryVectorStore.from_documents(chunks, embeddings)
        print("索引构建完成！")

    def search(self, query: str, k: int = 3) -> list:
        """搜索相关文档"""
        if not self.vectorstore:
            raise ValueError("请先调用 build_index() 构建索引")
        return self.vectorstore.similarity_search(query, k=k)

# 使用
processor = PDFProcessor(chunk_size=500, chunk_overlap=50)
processor.build_index("knowledge.pdf")

results = processor.search("什么是深度学习？")
for doc in results:
    print(f"相关度高的内容: {doc.page_content[:100]}...")
```

### 示例3：智能文件处理器

```python
"""
智能文件处理器
自动识别文件类型并处理
"""
import os
from typing import Optional
from langchain_community.document_loaders import (
    PyPDFLoader,
    TextLoader,
    CSVLoader,
    MarkdownLoader,
    BSHTMLLoader,
)
from langchain_text_splitters import RecursiveCharacterTextSplitter

class SmartFileProcessor:
    """智能文件处理器"""

    # 文件类型映射
    LOADER_MAP = {
        ".pdf": PyPDFLoader,
        ".txt": TextLoader,
        ".csv": CSVLoader,
        ".md": MarkdownLoader,
        ".html": BSHTMLLoader,
        ".htm": BSHTMLLoader,
    }

    def __init__(self, chunk_size: int = 500, chunk_overlap: int = 50):
        self.chunk_size = chunk_size
        self.chunk_overlap = chunk_overlap

    def get_loader(self, file_path: str):
        """根据文件类型获取加载器"""
        ext = os.path.splitext(file_path)[1].lower()

        loader_cls = self.LOADER_MAP.get(ext)
        if not loader_cls:
            raise ValueError(
                f"不支持的文件格式: {ext}\n"
                f"支持的格式: {', '.join(self.LOADER_MAP.keys())}"
            )

        # 特殊参数处理
        if ext in [".txt"]:
            return loader_cls(file_path, encoding="utf-8")
        return loader_cls(file_path)

    def process_file(self, file_path: str) -> list:
        """处理单个文件"""
        if not os.path.exists(file_path):
            raise FileNotFoundError(f"文件不存在: {file_path}")

        loader = self.get_loader(file_path)
        documents = loader.load()

        # 分块
        splitter = RecursiveCharacterTextSplitter(
            chunk_size=self.chunk_size,
            chunk_overlap=self.chunk_overlap,
        )
        chunks = splitter.split_documents(documents)

        return chunks

    def process_directory(self, dir_path: str) -> list:
        """处理目录中的所有支持文件"""
        all_chunks = []

        for root, dirs, files in os.walk(dir_path):
            for file in files:
                file_path = os.path.join(root, file)
                ext = os.path.splitext(file)[1].lower()

                if ext in self.LOADER_MAP:
                    try:
                        chunks = self.process_file(file_path)
                        all_chunks.extend(chunks)
                        print(f"  处理: {file} -> {len(chunks)} 块")
                    except Exception as e:
                        print(f"  跳过: {file} (错误: {e})")

        return all_chunks

# 使用
processor = SmartFileProcessor(chunk_size=500, chunk_overlap=50)
chunks = processor.process_directory("./documents")
print(f"总共处理了 {len(chunks)} 个文本块")
```

## 常见错误

### 1. 编码错误

```python
# 错误：未指定编码导致中文乱码
loader = TextLoader("chinese.txt")  # 默认可能不是 utf-8

# 正确：明确指定编码
loader = TextLoader("chinese.txt", encoding="utf-8")
```

### 2. 分块过大或过小

```python
# 错误：chunk_size 太大，超出模型上下文
splitter = RecursiveCharacterTextSplitter(chunk_size=10000)

# 错误：chunk_size 太小，丢失上下文
splitter = RecursiveCharacterTextSplitter(chunk_size=50)

# 正确：根据场景选择合适的大小
splitter = RecursiveCharacterTextSplitter(
    chunk_size=500,      # 通用推荐值
    chunk_overlap=50,    # 10% 重叠
)
```
