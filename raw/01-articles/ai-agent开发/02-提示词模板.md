## 为什么需要提示词模板

### 问题：硬编码提示词的困境

```python
# 硬编码提示词的问题
response = model.invoke("你是一个专业的翻译助手，请将以下句子翻译成英文：今天天气很好")
response2 = model.invoke("你是一个专业的翻译助手，请将以下句子翻译成英文：我喜欢编程")
response3 = model.invoke("你是一个专业的翻译助手，请将以下句子翻译成英文：Python很强大")
```

**问题**：
1. 重复代码多，难以维护
2. 修改角色描述需要改动多处
3. 无法参数化，灵活性差
4. 容易出现拼写不一致

### 解决方案：提示词模板

```python
from langchain_core.prompts import ChatPromptTemplate

# 创建模板
template = ChatPromptTemplate([
    ("system", "你是一个专业的翻译助手"),
    ("user", "请将以下句子翻译成英文：{sentence}")
])

# 使用模板，只需传入变量
prompt1 = template.invoke({"sentence": "今天天气很好"})
prompt2 = template.invoke({"sentence": "我喜欢编程"})
prompt3 = template.invoke({"sentence": "Python很强大"})
```

**优势**：
1. 代码复用，一次定义多处使用
2. 修改角色描述只需改一处
3. 变量参数化，灵活组合
4. 模板可保存、共享、版本管理

## PromptTemplate 三种创建方式

`PromptTemplate` 是 LangChain 中最基础的提示词模板类，用于生成纯文本提示词。

### 方式 1：from_template（推荐）

```python
from langchain_core.prompts import PromptTemplate

# 使用 from_template 创建
template = PromptTemplate.from_template(
    "告诉我关于{topic}的知识，用{language}回答"
)

# 填充变量
prompt = template.invoke({"topic": "量子计算", "language": "中文"})
print(prompt.text)
# 输出：告诉我关于量子计算的知识，用中文回答
```

**优点**：简洁，自动识别变量名，最常用。

### 方式 2：构造函数

```python
from langchain_core.prompts import PromptTemplate

# 使用构造函数创建
template = PromptTemplate(
    template="告诉我关于{topic}的知识，用{language}回答",
    input_variables=["topic", "language"]
)

# 填充变量
prompt = template.invoke({"topic": "量子计算", "language": "中文"})
print(prompt.text)
```

**优点**：可以显式指定变量名，适合需要精确控制的场景。

### 方式 3：从文件加载

```python
from langchain_core.prompts import PromptTemplate

# 假设 prompt.txt 内容为：
# 告诉我关于{topic}的知识，用{language}回答

# 从文件加载模板
template = PromptTemplate.from_file(
    "prompt.txt",
    input_variables=["topic", "language"]
)

# 填充变量
prompt = template.invoke({"topic": "量子计算", "language": "中文"})
print(prompt.text)
```

**优点**：适合复杂的长提示词，方便版本管理。

### 三种方式对比

| 方式 | 代码量 | 灵活性 | 适用场景 |
|------|--------|--------|---------|
| from_template | 最少 | 高 | **大多数场景推荐** |
| 构造函数 | 中等 | 最高 | 需要显式控制变量 |
| 从文件 | 中等 | 高 | 长提示词、版本管理 |

## ChatPromptTemplate 详解

`ChatPromptTemplate` 是专门用于**聊天模型**的模板，支持多角色消息。

### 基本用法：元组格式

```python
from langchain_core.prompts import ChatPromptTemplate

# 使用元组格式定义消息
template = ChatPromptTemplate([
    ("system", "你是一个专业的{role}助手"),
    ("user", "{input}")
])

# 填充变量
prompt = template.invoke({"role": "翻译", "input": "今天天气很好"})

# prompt 是一个 ChatPromptValue，可以直接传给模型
response = model.invoke(prompt)
```

### 元组格式详解

```python
# 每个元组包含两个元素：(角色, 内容)
template = ChatPromptTemplate([
    ("system", "系统提示词"),      # 系统角色
    ("user", "用户输入"),          # 用户角色
    ("assistant", "AI 回复"),      # 助手角色（用于少样本示例）
])

# 角色对应关系：
# "system"    → SystemMessage
# "user"      → HumanMessage
# "assistant" → AIMessage
```

### 字符串简写

```python
# 简写格式（不指定角色，默认为 user）
template = ChatPromptTemplate([
    "你是一个{role}助手",  # 等价于 ("user", "你是一个{role}助手")
])

# 也可以混合使用
template = ChatPromptTemplate([
    ("system", "你是一个专业的助手"),
    "请帮我{task}"  # 简写，等价于 ("user", "请帮我{task}")
])
```

### MessagePromptTemplate 高级用法

```python
from langchain_core.prompts import (
    ChatPromptTemplate,
    SystemMessagePromptTemplate,
    HumanMessagePromptTemplate,
)

# 使用具体的 MessagePromptTemplate 类
system_template = SystemMessagePromptTemplate.from_template(
    "你是一个专业的{domain}顾问，拥有{years}年经验"
)
human_template = HumanMessagePromptTemplate.from_template(
    "请回答以下问题：{question}"
)

# 组合模板
template = ChatPromptTemplate([
    system_template,
    human_template
])

# 填充变量
prompt = template.invoke({
    "domain": "人工智能",
    "years": "10",
    "question": "深度学习和机器学习有什么区别？"
})

response = model.invoke(prompt)
print(response.content)
```

### ChatPromptTemplate 结构图

```
ChatPromptTemplate
├── messages: List[Tuple[str, str]]
│   ├── ("system", "系统提示词")
│   ├── ("user", "用户输入")
│   └── ("assistant", "AI 回复示例")
│
├── invoke(variables) → ChatPromptValue
│   └── ChatPromptValue.to_messages()
│       ├── SystemMessage(content="系统提示词")
│       ├── HumanMessage(content="用户输入")
│       └── AIMessage(content="AI 回复示例")
│
└── partial(**kwargs) → ChatPromptTemplate（部分填充版本）
```

## 多轮对话模板设计

### 基本多轮对话模板

```python
from langchain_core.prompts import ChatPromptTemplate

# 设计支持多轮对话的模板
template = ChatPromptTemplate([
    ("system", "你是一个专业的AI助手，请用中文回答问题。"),
    # 使用 messages 变量接收历史消息
    ("placeholder", "{messages}"),
    ("user", "{input}")
])

# 构建对话历史
from langchain_core.messages import HumanMessage, AIMessage

chat_history = [
    HumanMessage(content="你好，我叫小明"),
    AIMessage(content="你好小明！很高兴认识你。"),
]

# 填充模板
prompt = template.invoke({
    "messages": chat_history,
    "input": "你还记得我的名字吗？"
})

response = model.invoke(prompt)
print(response.content)  # AI 应该记得用户叫小明
```

### 带上下文的对话模板

```python
template = ChatPromptTemplate([
    ("system", """你是一个专业的{domain}助手。

规则：
1. 用中文回答
2. 回答要简洁明了
3. 如果不确定，说明不确定"""),
    ("placeholder", "{history}"),
    ("user", "{input}")
])

# 使用示例
prompt = template.invoke({
    "domain": "Python编程",
    "history": [
        HumanMessage(content="什么是列表推导式？"),
        AIMessage(content="列表推导式是Python中创建列表的简洁方式...")
    ],
    "input": "能给个例子吗？"
})
```

## 部分变量（partial variables）

部分变量允许你预先填充模板中的某些变量，创建更专用的模板。

### 基本用法

```python
from langchain_core.prompts import ChatPromptTemplate

# 原始模板
template = ChatPromptTemplate([
    ("system", "你是一个专业的{domain}助手"),
    ("user", "{input}")
])

# 使用 partial() 预填充 domain
specialized_template = template.partial(domain="Python编程")

# 现在只需要填充 input
prompt = specialized_template.invoke({"input": "什么是装饰器？"})
response = model.invoke(prompt)
```

### 动态部分变量

```python
from datetime import datetime

# 使用函数作为部分变量（每次调用时动态计算）
template = ChatPromptTemplate([
    ("system", "你是一个AI助手。当前时间：{current_time}"),
    ("user", "{input}")
])

# partial 支持函数
def get_current_time():
    return datetime.now().strftime("%Y-%m-%d %H:%M:%S")

template_with_time = template.partial(current_time=get_current_time)

# 每次调用都会获取最新时间
prompt = template_with_time.invoke({"input": "你好"})
```

### 部分变量的实际应用

```python
# 创建不同领域的专用模板
base_template = ChatPromptTemplate([
    ("system", "你是一个专业的{domain}助手，擅长{skill}"),
    ("user", "{input}")
])

# Python 编程助手
python_helper = base_template.partial(
    domain="Python编程",
    skill="代码编写、调试和优化"
)

# 数据分析助手
data_analyst = base_template.partial(
    domain="数据分析",
    skill="数据清洗、统计分析和可视化"
)

# 使用不同助手
prompt1 = python_helper.invoke({"input": "如何读取CSV文件？"})
prompt2 = data_analyst.invoke({"input": "如何处理缺失值？"})
```

## 模板组合与复用

### 构建可复用模板库

```python
"""
templates.py - 模板库
集中管理所有提示词模板
"""

from langchain_core.prompts import ChatPromptTemplate


class PromptTemplates:
    """提示词模板库"""

    # 翻译助手
    TRANSLATOR = ChatPromptTemplate([
        ("system", "你是一个专业的翻译助手，精通{source_lang}和{target_lang}之间的翻译。"),
        ("user", "请将以下{source_lang}文本翻译成{target_lang}：\n\n{text}")
    ])

    # 代码审查员
    CODE_REVIEWER = ChatPromptTemplate([
        ("system", """你是一个资深的代码审查员。
请从以下方面审查代码：
1. 代码质量
2. 性能问题
3. 安全漏洞
4. 最佳实践"""),
        ("user", "请审查以下{language}代码：\n\n```{language}\n{code}\n```")
    ])

    # 通用问答
    QA_ASSISTANT = ChatPromptTemplate([
        ("system", "你是一个知识渊博的AI助手，请用{language}回答问题。"),
        ("placeholder", "{history}"),
        ("user", "{question}")
    ])

    # 文本摘要
    SUMMARIZER = ChatPromptTemplate([
        ("system", "你是一个文本摘要专家，请用{style}风格生成摘要。"),
        ("user", "请为以下文本生成摘要，长度不超过{max_length}字：\n\n{text}")
    ])


# 使用示例
if __name__ == "__main__":
    from langchain.chat_models import init_chat_model
    from dotenv import load_dotenv

    load_dotenv()
    model = init_chat_model("groq:llama-3.3-70b-versatile")

    # 使用翻译模板
    prompt = PromptTemplates.TRANSLATOR.invoke({
        "source_lang": "中文",
        "target_lang": "英文",
        "text": "今天天气真好"
    })
    response = model.invoke(prompt)
    print(response.content)
```

## LCEL 链预览

LCEL（LangChain Expression Language）使用管道语法 `|` 将组件串联。

### 基本管道语法

```python
from langchain_core.prompts import ChatPromptTemplate
from langchain.chat_models import init_chat_model
from dotenv import load_dotenv

load_dotenv()

# 创建模板
prompt = ChatPromptTemplate([
    ("system", "你是一个{role}助手"),
    ("user", "{input}")
])

# 创建模型
model = init_chat_model("groq:llama-3.3-70b-versatile")

# 使用管道语法组合（LCEL）
chain = prompt | model

# 调用链
response = chain.invoke({"role": "翻译", "input": "今天天气很好"})
print(response.content)
```

### 管道语法的工作流程

```
输入变量 {"role": "翻译", "input": "今天天气很好"}
    │
    ▼
┌─────────────────────┐
│  prompt (模板)       │
│  填充变量生成消息     │
└──────────┬──────────┘
           │
           ▼
   ChatPromptValue
   ├── SystemMessage("你是一个翻译助手")
   └── HumanMessage("今天天气很好")
           │
           ▼
┌─────────────────────┐
│  model (模型)        │
│  调用 LLM 生成回复   │
└──────────┬──────────┘
           │
           ▼
   AIMessage("The weather is nice today")
```

### 链的优势

```python
# 链可以复用
translator = prompt | model
reviewer = code_prompt | model

# 链可以组合
complex_chain = preprocess | translator | postprocess

# 链支持流式输出
for chunk in chain.stream({"role": "翻译", "input": "你好"}):
    print(chunk.content, end="", flush=True)
```

## 提示词工程最佳实践

### 1. 清晰的指令

```python
# 不好的提示词
template = ChatPromptTemplate([
    ("user", "帮我处理这个文本：{text}")
])

# 好的提示词：明确任务、输出格式、约束条件
template = ChatPromptTemplate([
    ("system", """你是一个文本处理专家。
任务：对输入文本进行情感分析
输出格式：JSON格式，包含以下字段：
- sentiment: "positive" / "negative" / "neutral"
- confidence: 0-100 的置信度
- summary: 一句话总结

约束：
- 只输出JSON，不要其他内容
- 不要编造信息"""),
    ("user", "{text}")
])
```

### 2. 角色设定

```python
# 详细的角色设定能显著提升输出质量
template = ChatPromptTemplate([
    ("system", """你是一位拥有15年经验的高级Python开发者。
专长：
- Web开发（Django, FastAPI）
- 数据科学（Pandas, NumPy）
- 系统设计和架构

风格：
- 代码注释使用中文
- 遵循PEP 8规范
- 优先使用标准库"""),
    ("user", "{input}")
])
```

### 3. 输出格式指定

```python
# 指定输出格式，避免AI自由发挥
template = ChatPromptTemplate([
    ("system", """请按照以下格式回答：

## 问题分析
[简要分析问题]

## 解决方案
[具体方案]

## 代码示例
```python
[代码]
```

## 注意事项
[要点列表]"""),
    ("user", "{input}")
])
```

### 4. 少样本示例

```python
# 使用示例指导AI的输出格式
template = ChatPromptTemplate([
    ("system", "你是一个情感分析专家"),
    ("user", "分析以下文本的情感："),
    ("assistant", "文本：这部电影太棒了！\n情感：正面\n置信度：95%"),
    ("user", "分析以下文本的情感："),
    ("assistant", "文本：服务态度很差，再也不来了。\n情感：负面\n置信度：90%"),
    ("user", "分析以下文本的情感：\n{text}")
])
```

## 常见错误

### 错误 1：变量名不匹配

```python
# 错误：模板中的变量名和传入的变量名不一致
template = ChatPromptTemplate([
    ("user", "告诉我关于{topic}的知识")
])

# 错误：传入了 theme 而不是 topic
prompt = template.invoke({"theme": "Python"})  # 报错！

# 正确：变量名必须一致
prompt = template.invoke({"topic": "Python"})
```

### 错误 2：忘记调用 invoke

```python
# 错误：直接把模板传给模型
template = ChatPromptTemplate([
    ("user", "告诉我关于{topic}的知识")
])

response = model.invoke(template)  # 错误！模板不是消息

# 正确：先填充变量
prompt = template.invoke({"topic": "Python"})
response = model.invoke(prompt)
```

### 错误 3：在 system 消息中使用变量但未提供

```python
template = ChatPromptTemplate([
    ("system", "你是一个{role}助手"),
    ("user", "{input}")
])

# 错误：没有提供 role 变量
prompt = template.invoke({"input": "你好"})  # 报错！

# 正确：提供所有必需变量
prompt = template.invoke({"role": "翻译", "input": "你好"})
```

### 错误 4：混淆 PromptTemplate 和 ChatPromptTemplate

```python
# PromptTemplate 生成纯文本，ChatPromptTemplate 生成消息列表
from langchain_core.prompts import PromptTemplate, ChatPromptTemplate

# PromptTemplate 用于非聊天模型
text_template = PromptTemplate.from_template("告诉我关于{topic}的知识")

# ChatPromptTemplate 用于聊天模型（推荐）
chat_template = ChatPromptTemplate([
    ("system", "你是一个AI助手"),
    ("user", "告诉我关于{topic}的知识")
])
```

## 最佳实践

1. **使用 ChatPromptTemplate**：对于聊天模型（如 Groq、OpenAI），优先使用 `ChatPromptTemplate`。

2. **集中管理模板**：将所有模板放在一个文件中（如 `templates.py`），便于维护。

3. **变量命名清晰**：使用有意义的变量名（`{domain}` 而不是 `{d}`）。

4. **系统提示词要详细**：角色、规则、输出格式都要明确说明。

5. **使用 partial 变量**：对于固定值（如角色、语言），使用 `partial()` 预填充。

6. **模板复用**：通过组合和 partial 变量，构建可复用的模板库。

7. **使用少样本示例**：通过示例指导 AI 的输出格式和质量。
