## 什么是工具（Tool）

### 工具的定义

工具（Tool）是**让 AI 能够执行实际操作的函数**。LLM 本身只能生成文本，
但通过工具，它可以：

- 查询天气、搜索网页
- 执行数学计算
- 读写数据库
- 调用 API
- 操作文件系统

### 为什么需要工具

```
没有工具的 LLM：
用户："今天北京天气怎么样？"
AI："抱歉，我无法获取实时天气信息..."  ← 只能猜测或拒绝

有工具的 LLM：
用户："今天北京天气怎么样？"
AI：[调用 get_weather("北京")]  →  {"temp": 25, "condition": "晴"}
AI："今天北京天气晴朗，气温25°C。"  ← 基于真实数据回答
```

### 工具在 Agent 中的作用

```
用户提问
    │
    ▼
┌──────────┐     ┌─────────────┐
│   LLM    │────→│  决定是否    │
│ (推理)   │     │  需要工具    │
└──────────┘     └──────┬──────┘
                        │
              ┌─────────┴─────────┐
              │                   │
              ▼                   ▼
        需要工具              不需要工具
              │                   │
              ▼                   ▼
     ┌──────────────┐    直接生成回答
     │  选择工具并   │
     │  确定参数     │
     └──────┬───────┘
            │
            ▼
     ┌──────────────┐
     │  执行工具     │
     └──────┬───────┘
            │
            ▼
     ┌──────────────┐
     │  工具返回结果 │
     └──────┬───────┘
            │
            ▼
     LLM 基于结果生成回答
```

## @tool 装饰器详解

### 基本用法

```python
from langchain_core.tools import tool

@tool
def get_weather(city: str) -> str:
    """获取指定城市的当前天气信息。

    Args:
        city: 城市名称，例如"北京"、"上海"
    """
    # 模拟天气查询
    weather_data = {
        "北京": "晴天，25°C",
        "上海": "多云，22°C",
        "广州": "阵雨，28°C",
    }
    return weather_data.get(city, f"未找到 {city} 的天气信息")
```

### @tool 装饰器的作用

```
普通函数：
def get_weather(city: str) -> str:
    ...

    ↓ @tool 装饰后

Tool 对象：
├── name: "get_weather"           ← 函数名作为工具名
├── description: "获取指定城市..."  ← docstring 作为描述
├── args_schema: {...}            ← 从类型注解自动生成参数schema
└── func: <function>              ← 原始函数
```

### Docstring 的重要性

**AI 通过 docstring 理解工具的用途**，所以 docstring 要写得清晰、详细。

```python
# ❌ 不好的 docstring
@tool
def calc(expression: str) -> str:
    """计算"""
    return str(eval(expression))

# ✅ 好的 docstring
@tool
def calculator(expression: str) -> str:
    """计算数学表达式的结果。

    支持基本运算符：+, -, *, /, **
    支持函数：abs, round, min, max

    Args:
        expression: 数学表达式字符串，例如 "2 + 3 * 4" 或 "10 ** 2"

    Returns:
        计算结果的字符串表示
    """
    return str(eval(expression))
```

### 类型注解的必要性

类型注解帮助 AI 理解参数的类型，并用于自动生成参数 schema。

```python
from typing import Optional

@tool
def search_web(
    query: str,
    max_results: int = 5,
    language: Optional[str] = None
) -> str:
    """搜索网页并返回结果摘要。

    Args:
        query: 搜索关键词
        max_results: 最大返回结果数，默认为5
        language: 搜索语言，可选，默认为中文
    """
    # 搜索逻辑...
    return f"搜索 '{query}' 的结果（最多{max_results}条）..."
```

### 可选参数与默认值

```python
from typing import Optional

@tool
def format_text(
    text: str,
    style: str = "normal",
    max_length: Optional[int] = None
) -> str:
    """格式化文本。

    Args:
        text: 待格式化的文本
        style: 格式风格，可选 "normal", "upper", "lower", "title"，默认 "normal"
        max_length: 最大长度限制，可选，超出部分将被截断
    """
    result = text

    if style == "upper":
        result = result.upper()
    elif style == "lower":
        result = result.lower()
    elif style == "title":
        result = result.title()

    if max_length and len(result) > max_length:
        result = result[:max_length] + "..."

    return result
```

### 返回值处理

工具的返回值应该是**字符串**或**可序列化的对象**。

```python
import json

@tool
def get_user_info(user_id: str) -> str:
    """获取用户信息。

    Args:
        user_id: 用户ID
    """
    # 返回复杂数据时，使用 JSON 格式
    user_data = {
        "id": user_id,
        "name": "张三",
        "email": "zhangsan@example.com",
        "age": 25
    }
    return json.dumps(user_data, ensure_ascii=False)

@tool
def calculate_area(length: float, width: float) -> str:
    """计算矩形面积。

    Args:
        length: 长度
        width: 宽度
    """
    area = length * width
    return f"矩形面积为：{area} 平方米"
```

## model.bind_tools() 详解

`bind_tools()` 将工具列表绑定到模型，使模型知道有哪些工具可用。

### 基本用法

```python
from langchain.chat_models import init_chat_model
from langchain_core.tools import tool

# 定义工具
@tool
def get_weather(city: str) -> str:
    """获取指定城市的天气信息。"""
    return f"{city}：晴天，25°C"

# 初始化模型
model = init_chat_model("groq:llama-3.3-70b-versatile")

# 绑定工具到模型
model_with_tools = model.bind_tools([get_weather])

# 调用模型（AI 可能会决定调用工具）
response = model_with_tools.invoke("北京今天天气怎么样？")

# 检查是否有工具调用
if response.tool_calls:
    print("AI 决定调用工具：")
    for tc in response.tool_calls:
        print(f"  工具：{tc['name']}")
        print(f"  参数：{tc['args']}")
else:
    print("AI 直接回复：", response.content)
```

### bind_tools 的工作原理

```
model.bind_tools([get_weather, calculator])
    │
    ▼
模型收到的系统信息（自动生成）：

你可以使用以下工具：

1. get_weather
   描述：获取指定城市的天气信息
   参数：
   - city (str): 城市名称

2. calculator
   描述：计算数学表达式
   参数：
   - expression (str): 数学表达式

如果你需要使用工具，请以 JSON 格式返回工具调用请求。
```

### 工具调用后的处理

```python
from langchain_core.messages import HumanMessage, ToolMessage

# 绑定工具
model_with_tools = model.bind_tools([get_weather])

# 第1步：AI 决定调用工具
response = model_with_tools.invoke("北京天气怎么样？")

if response.tool_calls:
    # 第2步：执行工具
    messages = [HumanMessage(content="北京天气怎么样？"), response]

    for tool_call in response.tool_calls:
        # 执行工具函数
        if tool_call["name"] == "get_weather":
            result = get_weather.invoke(tool_call["args"])
            # 添加工具结果
            messages.append(ToolMessage(
                content=result,
                tool_call_id=tool_call["id"]
            ))

    # 第3步：AI 基于工具结果生成最终回复
    final_response = model_with_tools.invoke(messages)
    print(final_response.content)
```

```python
# phase1_fundamentals/04_custom_tools/tools/weather.py

from langchain_core.tools import tool

@tool
def get_weather(city: str) -> str:
    """获取指定城市的当前天气信息。

    这是一个模拟工具，返回预设的天气数据。
    在实际应用中，可以替换为真实的天气 API 调用。

    Args:
        city: 城市名称，例如"北京"、"上海"、"广州"

    Returns:
        包含天气信息的字符串，包括温度和天气状况
    """
    # 模拟天气数据
    weather_data = {
        "北京": "晴天，25°C，湿度 40%",
        "上海": "多云，22°C，湿度 65%",
        "广州": "阵雨，28°C，湿度 80%",
        "深圳": "阴天，26°C，湿度 70%",
        "杭州": "晴转多云，24°C，湿度 55%",
    }

    if city in weather_data:
        return f"{city}当前天气：{weather_data[city]}"
    else:
        return f"未找到 {city} 的天气信息，请检查城市名称。"

@tool
def get_weather_forecast(city: str, days: int = 3) -> str:
    """获取指定城市未来几天的天气预报。

    Args:
        city: 城市名称
        days: 预报天数，默认3天，最多7天
    """
    return f"{city}未来{days}天的天气预报：晴天为主，气温稳定。"
```

### calculator.py - 计算器工具

```python
# phase1_fundamentals/04_custom_tools/tools/calculator.py

import math
from langchain_core.tools import tool

@tool
def calculator(expression: str) -> str:
    """计算数学表达式的结果。

    支持基本运算符：+, -, *, /, //(整除), %(取余), **(幂)
    支持数学函数：abs, round, min, max, sqrt, sin, cos, tan, log, pi, e

    Args:
        expression: 数学表达式字符串，例如 "2 + 3 * 4" 或 "sqrt(16)"

    Returns:
        计算结果的字符串表示
    """
    # 安全的数学环境
    safe_dict = {
        "__builtins__": {},
        "abs": abs,
        "round": round,
        "min": min,
        "max": max,
        "sqrt": math.sqrt,
        "sin": math.sin,
        "cos": math.cos,
        "tan": math.tan,
        "log": math.log,
        "log10": math.log10,
        "pi": math.pi,
        "e": math.e,
        "pow": pow,
    }

    try:
        result = eval(expression, safe_dict)
        return f"计算结果：{expression} = {result}"
    except Exception as e:
        return f"计算错误：{str(e)}。请检查表达式是否正确。"

@tool
def unit_converter(value: float, from_unit: str, to_unit: str) -> str:
    """转换单位。

    支持的单位：
    - 长度：km, m, cm, mm, mile
    - 重量：kg, g, mg, lb
    - 温度：celsius, fahrenheit, kelvin

    Args:
        value: 要转换的数值
        from_unit: 源单位
        to_unit: 目标单位
    """
    conversions = {
        ("km", "mile"): 0.621371,
        ("mile", "km"): 1.60934,
        ("kg", "lb"): 2.20462,
        ("lb", "kg"): 0.453592,
    }

    key = (from_unit, to_unit)
    if key in conversions:
        result = value * conversions[key]
        return f"{value} {from_unit} = {result:.2f} {to_unit}"
    else:
        return f"不支持从 {from_unit} 到 {to_unit} 的转换"
```

## 工具调用流程

### 完整的工具调用流程

```python
"""
完整的工具调用示例
展示从用户提问到工具执行到最终回复的完整流程
"""

import os
from dotenv import load_dotenv
from langchain.chat_models import init_chat_model
from langchain_core.messages import HumanMessage, AIMessage, ToolMessage
from langchain_core.tools import tool

load_dotenv()

# 定义工具
@tool
def get_weather(city: str) -> str:
    """获取指定城市的天气信息。

    Args:
        city: 城市名称
    """
    weather_data = {
        "北京": "晴天，25°C",
        "上海": "多云，22°C",
    }
    return weather_data.get(city, f"未找到{city}天气")

@tool
def calculator(expression: str) -> str:
    """计算数学表达式。

    Args:
        expression: 数学表达式
    """
    try:
        return str(eval(expression))
    except Exception as e:
        return f"计算错误：{e}"


def run_with_tools(question: str):
    """带工具调用的完整流程"""
    model = init_chat_model("groq:llama-3.3-70b-versatile")
    model_with_tools = model.bind_tools([get_weather, calculator])

    print(f"用户问题：{question}")
    print("-" * 50)

    # 第1步：发送问题给模型
    messages = [HumanMessage(content=question)]
    response = model_with_tools.invoke(messages)

    # 第2步：检查是否有工具调用
    if not response.tool_calls:
        print("AI 直接回复（无需工具）：")
        print(response.content)
        return

    # 第3步：执行所有工具调用
    print("AI 决定调用以下工具：")
    messages.append(response)  # 添加 AI 的工具调用消息

    for tool_call in response.tool_calls:
        tool_name = tool_call["name"]
        tool_args = tool_call["args"]
        tool_id = tool_call["id"]

        print(f"  - {tool_name}({tool_args})")

        # 执行工具
        if tool_name == "get_weather":
            result = get_weather.invoke(tool_args)
        elif tool_name == "calculator":
            result = calculator.invoke(tool_args)
        else:
            result = f"未知工具：{tool_name}"

        print(f"    结果：{result}")

        # 添加工具结果到消息
        messages.append(ToolMessage(
            content=result,
            tool_call_id=tool_id
        ))

    # 第4步：基于工具结果生成最终回复
    print("-" * 50)
    final_response = model_with_tools.invoke(messages)
    print("AI 最终回复：")
    print(final_response.content)


# 测试
if __name__ == "__main__":
    run_with_tools("北京今天天气怎么样？")
    print("\n" + "=" * 60 + "\n")
    run_with_tools("计算 15 * 23 + 47")
```

## 工具设计最佳实践

### 1. 命名清晰

```python
# ❌ 不好的命名
@tool
def f(x: str) -> str:
    """..."""

@tool
def do_stuff(input: str) -> str:
    """..."""

# ✅ 好的命名
@tool
def get_weather(city: str) -> str:
    """获取天气信息。"""

@tool
def calculate_area(length: float, width: float) -> str:
    """计算矩形面积。"""
```

### 2. Docstring 详细描述

```python
@tool
def search_products(

    """
```

### 3. 错误处理

```python
@tool
def safe_divide(a: float, b: float) -> str:
    """安全除法，避免除零错误。

    Args:
        a: 被除数
        b: 除数
    """
    try:
        if b == 0:
            return "错误：除数不能为零"
        result = a / b
        return f"{a} / {b} = {result}"
    except Exception as e:
        return f"计算错误：{str(e)}"
```

### 4. 单一职责

```python
# ❌ 不好：一个工具做太多事情
@tool
def process_data(action: str, data: str) -> str:
    """处理数据（可以排序、过滤、统计...）"""

# ✅ 好：每个工具做一件事
@tool
def sort_data(data: str, order: str = "asc") -> str:
    """对数据进行排序。"""

@tool
def filter_data(data: str, condition: str) -> str:
    """按条件过滤数据。"""

@tool
def calculate_statistics(data: str) -> str:
    """计算数据的统计信息。"""
```

### 5. 返回有用的信息

```python
# ❌ 不好的返回
@tool
def get_user(user_id: str) -> str:
    """获取用户信息。"""
    return "成功"  # 太简略

# ✅ 好的返回
@tool
def get_user(user_id: str) -> str:
    """获取用户信息。"""
    user = database.find_user(user_id)
    if user:
        return json.dumps({
            "id": user.id,
            "name": user.name,
            "email": user.email,
            "created_at": user.created_at
        }, ensure_ascii=False)
    else:
        return f"未找到ID为 {user_id} 的用户"
```

## 常见错误

### 错误 1：缺少类型注解

```python
# ❌ 错误：没有类型注解
@tool
def get_weather(city):
    """获取天气信息。"""
    return f"{city}天气晴朗"

# ✅ 正确：添加类型注解
@tool
def get_weather(city: str) -> str:
    """获取天气信息。"""
    return f"{city}天气晴朗"
```

### 错误 2：Docstring 太简略

```python
# ❌ 错误：docstring 太简略，AI 无法理解工具用途
@tool
def calc(x):
    """计算"""
    return str(eval(x))

# ✅ 正确：详细描述工具用途和参数
@tool
def calculator(expression: str) -> str:
    """计算数学表达式的结果。

    Args:
        expression: 数学表达式，例如 "2 + 3" 或 "10 ** 2"
    """
    return str(eval(expression))
```

### 错误 3：工具返回非字符串

```python
# ❌ 错误：返回非字符串类型
@tool
def get_count(items: list) -> int:
    """获取列表长度。"""
    return len(items)  # 返回 int，可能不被正确处理

# ✅ 正确：返回字符串
@tool
def get_count(items: str) -> str:
    """获取列表长度。"""
    item_list = items.split(",")
    return f"列表包含 {len(item_list)} 个元素"
```

### 错误 4：忘记处理工具调用结果

```python
# ❌ 错误：不处理工具调用结果
response = model_with_tools.invoke("北京天气怎么样？")
print(response.content)  # 可能是空的，因为 AI 决定调用工具

# ✅ 正确：检查是否有工具调用
response = model_with_tools.invoke("北京天气怎么样？")
if response.tool_calls:
    # 执行工具并处理结果
    for tc in response.tool_calls:
        result = get_weather.invoke(tc["args"])
        print(f"工具结果：{result}")
else:
    print(response.content)
```

### 错误 5：工具函数有副作用

```python
# ❌ 不好：工具函数有副作用（修改全局状态）
counter = 0

@tool
def increment() -> str:
    """增加计数器。"""
    global counter
    counter += 1  # 修改全局状态
    return f"计数器：{counter}"

# ✅ 好：工具函数是无副作用的纯函数
@tool
def calculate_sum(numbers: str) -> str:
    """计算数字列表的和。

    Args:
        numbers: 逗号分隔的数字，例如 "1,2,3,4,5"
    """
    nums = [float(n) for n in numbers.split(",")]
    return f"总和：{sum(nums)}"
```

## 最佳实践

1. **清晰的命名**：工具名应该清楚地描述其功能（`get_weather` 而不是 `gw`）。

2. **详细的 Docstring**：AI 靠 docstring 理解工具，写得越详细，AI 使用越准确。

3. **类型注解**：所有参数和返回值都要有类型注解。

4. **错误处理**：工具内部处理异常，返回友好的错误信息，不要抛出异常。

5. **单一职责**：每个工具只做一件事，功能复杂时拆分成多个工具。

6. **返回字符串**：工具的返回值应该是字符串或 JSON 字符串。

7. **无副作用**：工具函数应该是纯函数，避免修改外部状态。

8. **共享工具**：将常用工具放在共享目录，通过 `sys.path.insert()` 导入。
