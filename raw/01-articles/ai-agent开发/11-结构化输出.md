## 1. 为什么需要结构化输出

### LLM 返回纯文本的问题

```
┌─────────────────────────────────────────────────────────────┐
│              LLM 输出的不确定性                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  用户请求: "分析这段文本的情感"                                │
│                                                             │
│  LLM可能返回:                                                │
│  1. "这段文本的情感是积极的。"                                 │
│  2. "情感分析结果：积极"                                      │
│  3. "根据分析，该文本表达了积极的情感。"                        │
│  4. "情感倾向：正面 😊"                                      │
│  5. "该文本的情感基调为positive。"                            │
│                                                             │
│  问题：                                                      │
│  - 格式不统一，难以程序解析                                    │
│  - 可能包含多余信息                                           │
│  - 可能使用不同的术语                                         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 结构化输出的优势

```python
# 结构化输出确保返回固定格式的数据
class SentimentResult(BaseModel):
    sentiment: str = Field(description="情感：positive/negative/neutral")
    confidence: float = Field(description="置信度：0-1")
    reason: str = Field(description="分析原因")

# 无论LLM如何生成，最终结果都是：
# SentimentResult(sentiment="positive", confidence=0.85, reason="文本表达了积极的情感")
```

## 3. model.with_structured_output() 使用方法

### 基本用法

```python
from langchain.chat_models import init_chat_model
from pydantic import BaseModel, Field


class MovieReview(BaseModel):
    """电影评论分析"""
    title: str = Field(description="电影名称")
    rating: float = Field(description="评分：1-10", ge=1, le=10)
    summary: str = Field(description="评论摘要，不超过100字")
    recommend: bool = Field(description="是否推荐观看")


def basic_structured_output():
    """基础结构化输出示例"""

    # 1. 初始化模型
    model = init_chat_model("groq:llama-3.3-70b-versatile")

    # 2. 创建结构化输出模型
    structured_model = model.with_structured_output(MovieReview)

    # 3. 调用模型
    result = structured_model.invoke(
        "请分析这段电影评论：'这部电影太棒了！特效震撼，剧情紧凑，强烈推荐！'"
    )

    # 4. 使用结果
    print(f"电影: {result.title}")
    print(f"评分: {result.rating}")
    print(f"摘要: {result.summary}")
    print(f"推荐: {result.recommend}")

    # result是MovieReview类型，可以直接访问属性
    print(f"类型: {type(result)}")  # <class 'MovieReview'>


if __name__ == "__main__":
    basic_structured_output()
```

### 在 Agent 中使用

```python
from langchain.chat_models import init_chat_model
from langchain.agents import create_agent
from langchain_core.tools import tool
from pydantic import BaseModel, Field


class WeatherInfo(BaseModel):
    """天气信息"""
    city: str = Field(description="城市名称")
    temperature: float = Field(description="温度（摄氏度）")
    condition: str = Field(description="天气状况：晴/多云/雨/雪")
    humidity: float = Field(description="湿度百分比", ge=0, le=100)


@tool
def get_weather(city: str) -> str:
    """获取天气信息"""
    # 模拟天气API
    return f"{city}今天晴天，25°C，湿度40%"


def agent_with_structured_output():
    """Agent中使用结构化输出"""

    model = init_chat_model("groq:llama-3.3-70b-versatile")

    # 创建带工具的Agent
    agent = create_agent(
        model=model,
        tools=[get_weather],
        system_prompt="""你是天气助手。
当用户询问天气时，使用get_weather工具获取信息。
然后将信息格式化为WeatherInfo结构返回。"""
    )

    # 调用Agent
    response = agent.invoke({
        "messages": [{"role": "user", "content": "北京今天天气怎么样？"}]
    })

    # 最后一条消息可能是结构化的
    print(response["messages"][-1].content)
```

## 4. 结构化输出的工作原理

### 工作流程图

```
┌─────────────────────────────────────────────────────────────┐
│              结构化输出工作流程                                │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 用户请求                                                 │
│     "分析这段文本的情感"                                      │
│           │                                                 │
│           ▼                                                 │
│  2. 构建Prompt                                               │
│     System: 请以JSON格式返回结果，符合以下schema:             │
│     {schema定义}                                            │
│     User: 分析这段文本的情感                                  │
│           │                                                 │
│           ▼                                                 │
│  3. LLM生成JSON                                              │
│     {                                                       │
│       "sentiment": "positive",                              │
│       "confidence": 0.85,                                   │
│       "reason": "文本表达了积极的情感"                        │
│     }                                                       │
│           │                                                 │
│           ▼                                                 │
│  4. Pydantic验证                                             │
│     SentimentResult(**json_data)                            │
│           │                                                 │
│           ▼                                                 │
│  5. 返回结构化对象                                            │
│     SentimentResult(sentiment="positive", ...)              │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

```python
from pydantic import BaseModel, Field
from typing import List
from langchain.chat_models import init_chat_model


class Entity(BaseModel):
    """实体"""
    name: str = Field(description="实体名称")
    entity_type: str = Field(description="实体类型：人名/地名/组织/其他")
    description: str = Field(description="实体描述")


class EntityExtraction(BaseModel):
    """实体提取结果"""
    entities: List[Entity] = Field(
        description="提取的实体列表",
        min_length=1
    )
    total_count: int = Field(description="实体总数")


def extract_entities():
    """从文本中提取实体"""

    model = init_chat_model("groq:llama-3.3-70b-versatile")
    structured_model = model.with_structured_output(EntityExtraction)

    text = """
    张三是北京大学的教授，他住在北京海淀区。
    他的同事李四也在北京大学工作，是一位著名的AI研究员。
    他们经常在清华大学的图书馆讨论学术问题。
    """

    result = structured_model.invoke(
        f"请从以下文本中提取所有实体（人名、地名、组织名）：\n{text}"
    )

    print(f"提取到 {result.total_count} 个实体：")
    for entity in result.entities:
        print(f"  - {entity.name} ({entity.entity_type}): {entity.description}")


if __name__ == "__main__":
    extract_entities()
```

## 6. 安全结构化输出

### safe_structured_output() 带 JSON 降级

```python
"""
安全结构化输出：带JSON降级
"""
from pydantic import BaseModel, Field
from typing import Optional
from langchain.chat_models import init_chat_model


class AnalysisResult(BaseModel):
    """分析结果"""
    sentiment: str = Field(description="情感：positive/negative/neutral")
    confidence: float = Field(description="置信度：0-1")
    reason: str = Field(description="分析原因")


def safe_structured_output(text: str) -> dict:
    """
    安全的结构化输出，带JSON降级

    优先使用Pydantic验证，失败则返回原始JSON
    """
    import json

    model = init_chat_model("groq:llama-3.3-70b-versatile")

    # 尝试使用结构化输出
    try:
        structured_model = model.with_structured_output(AnalysisResult)
        result = structured_model.invoke(f"分析以下文本的情感：{text}")

        return {
            "success": True,
            "data": result.model_dump(),
            "format": "pydantic"
        }

    except Exception as e:
        print(f"结构化输出失败: {e}")
        print("尝试JSON降级...")

        # 降级：直接请求JSON格式
        response = model.invoke(
            f"请分析以下文本的情感，并以JSON格式返回（包含sentiment, confidence, reason字段）：\n{text}"
        )

        try:
            # 尝试解析JSON
            json_data = json.loads(response.content)
            return {
                "success": True,
                "data": json_data,
                "format": "json_fallback"
            }
        except json.JSONDecodeError:
            return {
                "success": False,
                "data": {"raw_response": response.content},
                "format": "raw_text"
            }


def safe_output_example():
    """安全输出示例"""

    texts = [
        "这部电影太棒了！",
        "今天天气真糟糕。",
        "还行吧，一般般。",
    ]

    for text in texts:
        print(f"\n文本: {text}")
        result = safe_structured_output(text)
        print(f"成功: {result['success']}")
        print(f"格式: {result['format']}")
        print(f"数据: {result['data']}")


if __name__ == "__main__":
    safe_output_example()
```

```python
"""
多语言情感分析示例
"""
from pydantic import BaseModel, Field
from typing import List, Optional
from enum import Enum
from langchain.chat_models import init_chat_model


class Language(str, Enum):
    """语言枚举"""
    CHINESE = "zh"
    ENGLISH = "en"
    JAPANESE = "ja"
    OTHER = "other"


class Sentiment(str, Enum):
    """情感枚举"""
    VERY_POSITIVE = "very_positive"
    POSITIVE = "positive"
    NEUTRAL = "neutral"
    NEGATIVE = "negative"
    VERY_NEGATIVE = "very_negative"


class SentimentAnalysis(BaseModel):
    """情感分析结果"""
    text: str = Field(description="原始文本")
    language: Language = Field(description="文本语言")
    sentiment: Sentiment = Field(description="情感倾向")
    confidence: float = Field(description="置信度：0-1", ge=0, le=1)
    keywords: List[str] = Field(description="关键词列表", min_length=1, max_length=5)
    reason: str = Field(description="分析原因", max_length=200)


def multilingual_sentiment():
    """多语言情感分析"""

    model = init_chat_model("groq:llama-3.3-70b-versatile")
    structured_model = model.with_structured_output(SentimentAnalysis)

    texts = [
        "这个产品太棒了，强烈推荐！",
        "This is terrible, I hate it.",
        "还可以吧，一般般。",
        "Absolutely amazing experience!",
    ]

    for text in texts:
        result = structured_model.invoke(f"分析以下文本的情感：\n{text}")

        print(f"\n文本: {result.text}")
        print(f"语言: {result.language.value}")
        print(f"情感: {result.sentiment.value}")
        print(f"置信度: {result.confidence:.2f}")
        print(f"关键词: {', '.join(result.keywords)}")
        print(f"原因: {result.reason}")


if __name__ == "__main__":
    multilingual_sentiment()
```

```python
"""

from pydantic import BaseModel, Field
from typing import List, Optional
from enum import Enum
from langchain.chat_models import init_chat_model


class Severity(str, Enum):
    """严重程度"""

    HIGH = "high"
    MEDIUM = "medium"
    LOW = "low"
    INFO = "info"


class Issue(BaseModel):

    line: Optional[int] = Field(description="问题所在行号", ge=1)

    suggestion: str = Field(description="修复建议")


class CodeReview(BaseModel):
    """代码审查结果"""
    language: str = Field(description="编程语言")
    total_lines: int = Field(description="总行数", ge=1)
    issues: List[Issue] = Field(description="问题列表")
    score: float = Field(description="代码质量评分：0-100", ge=0, le=100)
    summary: str = Field(description="审查总结", max_length=500)


def review_code():
    """代码审查"""

    model = init_chat_model("groq:llama-3.3-70b-versatile")

def process_data(data):

    return result

password = "admin123"
api_key = "sk-1234567890"
    """

    result = structured_model.invoke(

        print(f"    建议: {issue.suggestion}")

if __name__ == "__main__":
```

```python
"""

from pydantic import BaseModel, Field
from typing import List, Optional
from langchain.chat_models import init_chat_model

    end_date: Optional[str] = Field(description="结束日期，在职则为None")
    responsibilities: List[str] = Field(description="职责列表")


class Education(BaseModel):
    """教育经历"""
    school: str = Field(description="学校名称")
    degree: str = Field(description="学位")
    major: str = Field(description="专业")
    graduation_year: int = Field(description="毕业年份")


class Resume(BaseModel):
    """简历信息"""
    name: str = Field(description="姓名")
    email: Optional[str] = Field(description="邮箱")
    phone: Optional[str] = Field(description="电话")

    summary: Optional[str] = Field(description="个人简介")

def parse_resume():

    邮箱：zhangsan@example.com
```

## 8. 常见错误

### 错误1：忘记 Field 描述

```python
# 错误：没有Field描述，LLM不知道如何填充
class BadModel(BaseModel):
    name: str
    value: int

# 正确：添加详细的Field描述
class GoodModel(BaseModel):
    name: str = Field(description="项目名称，例如：项目A")
    value: int = Field(description="项目数值，范围：0-100", ge=0, le=100)
```

### 错误2：类型定义过于宽松

```python
# 错误：使用Any类型
class BadModel(BaseModel):
    data: Any  # LLM不知道返回什么格式

# 正确：明确定义类型
class GoodModel(BaseModel):
    name: str = Field(description="名称")
    count: int = Field(description="数量", ge=0)
    items: List[str] = Field(description="项目列表")
```

### 错误3：嵌套模型过深

```python
# 错误：嵌套太深，LLM可能无法正确生成
class TooDeep(BaseModel):
    level1: "Level1"

class Level1(BaseModel):
    level2: "Level2"

class Level2(BaseModel):
    level3: "Level3"

# 正确：保持合理的嵌套层级
class Reasonable(BaseModel):
    name: str
    items: List[str]
    metadata: Optional[dict] = None
```

### 错误4：required 和 Optional 混淆

```python
# 错误：忘记设置默认值
class BadModel(BaseModel):
    optional_field: Optional[str]  # 没有默认值，Pydantic会报错

# 正确：Optional字段必须有默认值
class GoodModel(BaseModel):
    optional_field: Optional[str] = None
```

## 9. 最佳实践

### 1. 使用枚举限制取值范围

```python
from enum import Enum

class Status(str, Enum):
    ACTIVE = "active"
    INACTIVE = "inactive"
    PENDING = "pending"

class Record(BaseModel):
    status: Status  # LLM只能返回这三个值之一
```

### 2. 添加验证约束

```python
class User(BaseModel):
    age: int = Field(ge=0, le=150)  # 年龄范围
    email: str = Field(description="邮箱格式：user@example.com")
    score: float = Field(ge=0, le=100)  # 分数范围
```

```python
class Analysis(BaseModel):

        description="置信度，0-1之间的小数，例如：0.85"
    )
```

### 4. 处理可选字段

```python
class Result(BaseModel):
```
