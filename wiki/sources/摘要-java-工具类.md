## 核心摘要
Java 常用工具类共 3 篇。Guava 提供 Optional 空值处理、不可变集合、Multiset 频次统计、Joiner/Splitter 字符串处理和本地缓存。MapStruct 是编译时 Bean 映射框架，通过 @Mapper 注解定义 DTO 转换。OkHttp3 封装了企业级 HTTP 工具类，支持重试、连接池、SSL 免验证和文件上传下载。
