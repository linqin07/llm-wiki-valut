## 定义

分库分表是将大型数据库或表拆分成更小、更易管理的部分的技术，用于解决单库/单表数据量过大导致的性能问题。

## 关键信息

### 分表方式

#### 物理分表

- 实际上将数据分散到多个表
- 需要修改代码逻辑
- 如：读写分离

#### 逻辑分表

- 使用中间件进行逻辑连接
- 对应用来说还是一个数据库
- 普通大表的横向或纵向分表

### 水平拆分 vs 垂直拆分

| 类型 | 说明 | 适用场景 |
|------|------|----------|
| 水平拆分 | 将同一表的数据按行分散到多个表 | 单表数据量过大 |
| 垂直拆分 | 将不同字段分散到多个表 | 表字段过多，访问频率差异大 |

### MERGE 存储引擎实现

使用 MyISAM 的 MERGE 存储引擎实现逻辑分表：

```sql
-- 创建子表
CREATE TABLE user1 (...) ENGINE=MyISAM;
CREATE TABLE user2 (...) ENGINE=MyISAM;

-- 创建 MERGE 表
CREATE TABLE alluser (
    ...
) ENGINE=MERGE UNION=(user1,user2) INSERT_METHOD=LAST;
```

**特点：**
- 不需要修改 SQL 语句
- 查询 MERGE 表即可获取所有子表数据
- INSERT_METHOD=LAST 指定插入到哪个子表

### 分片策略

| 策略 | 说明 | 优缺点 |
|------|------|--------|
| 范围分片 | 按 ID 范围分 | 简单，但可能数据不均 |
| 哈希分片 | 按哈希值分 | 数据均匀，但扩容困难 |
| 时间分片 | 按时间分 | 适合时序数据 |
