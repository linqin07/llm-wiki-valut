## 什么是混合模态

### 概念介绍

混合模态（Multimodal）是指在一个工作流中同时处理多种类型的数据输入，包括文本、图像、结构化数据等。

```
单一模态:
  文本 --> [LLM] --> 文本输出

混合模态:
  文本 ----+
           |
  图像 ----+--> [多模态系统] --> 文本/结构化输出
           |
  结构化数据+
```

### 为什么需要混合模态

| 场景 | 单一模态的局限 | 混合模态的优势 |
|------|--------------|--------------|
| 报告分析 | 只能分析文本部分 | 同时理解图表和文字 |
| 内容审核 | 只能审核文字 | 同时审核图片和文字 |
| 数据解读 | 需要手动描述图表 | 直接从图表提取信息 |
| 文档理解 | 只能处理纯文本 | 理解包含图表的文档 |
| 产品分析 | 只能分析描述文字 | 同时分析产品图片和描述 |

### 混合模态 vs 多模态

```
多模态（Multimodal）:
  - 指模型本身的能力（能处理图像+文本）
  - 如 GPT-4o, Gemini

混合模态（Mixed Modality）:
  - 指应用层面的设计（在工作流中组合多种数据源）
  - 可能涉及多个模型、多个处理步骤
  - 更强调"工作流"的设计
```

## 混合模态工作流设计

### 设计模式1：单次 Agent 调用

在一次 Agent 调用中同时传入多种类型的输入：

```
用户请求 + 图片
       |
       v
+------+------+
|  多模态 LLM |  <-- GPT-4o 同时处理文本和图像
+------+------+
       |
       v
   综合分析结果
```

```python
from langchain_core.messages import HumanMessage
from langchain.chat_models import init_chat_model

model = init_chat_model("openai:gpt-4o")

# 同时传入文本和图像
message = HumanMessage(
    content=[
        {"type": "text", "text": "请分析这张销售图表，结合以下文字报告给出综合分析。"},
        {"type": "text", "text": "本季度销售额增长15%，利润率提升3%。"},
        {"type": "image_url", "image_url": {"url": "https://example.com/chart.png"}}
    ]
)

response = model.invoke([message])
```

### 设计模式2：分步处理管道

不同模态的数据分别处理，然后合并结果：

```
图像 --+                     +-- 图像分析结果 --+
       |                     |                   |
       +--> 分别处理 --------+                   +--> 合并 --> 最终输出
       |                     |                   |
文本 --+                     +-- 文本分析结果 --+
```

```python

    combined_result: str

    """分析图像"""
    # 调用视觉模型分析图像
    image_result = vision_model.invoke([...])
    return {"image_analysis": image_result.content}

def analyze_text(state: MixedState) -> dict:
    """分析文本"""
    # 调用文本模型分析
    text_result = text_model.invoke([...])
    return {"text_analysis": text_result.content}

def combine_results(state: MixedState) -> dict:
    """合并两种分析结果"""
    combined = combine_model.invoke([
        f"图像分析结果：{state['image_analysis']}",
        f"文本分析结果：{state['text_analysis']}",
        "请综合以上两方面给出完整分析。"
    ])
    return {"combined_result": combined.content}
```

### 设计模式3：并行处理 + 汇总

使用 LangGraph 的 Send 并行处理不同模态：

```
          +--- 图像处理 (并行) ---+
          |                       |
输入数据 -+--- 文本处理 (并行) ---+--> 汇总节点 --> 输出
          |                       |
          +--- 数据处理 (并行) ---+
```

## 应用场景

### 场景1：报告生成

结合文本分析和图像解读，生成综合报告：

```
输入:
  - 文本报告
  - 数据图表
  - 表格数据

处理流程:
  1. 分析文本报告提取关键信息
  2. 分析图表提取数据趋势
  3. 解析表格获取精确数据
  4. 综合三方面生成完整报告
```

### 场景2：内容审核

跨模态审核用户生成的内容：

```
用户提交:
  - 文字评论
  - 配图

审核流程:
  1. 文本审核：检查是否有敏感词、虚假信息
  2. 图像审核：检查是否有不当内容
  3. 一致性检查：文字和图片是否匹配
  4. 综合评分，决定是否通过
```

### 场景3：数据可视化解读

解读图表和数据：

```
输入:
  - 数据可视化图片（柱状图、折线图等）
  - 原始数据（CSV/JSON）

处理:
  1. 从图表中读取视觉信息（趋势、极值）
  2. 从原始数据中计算统计指标
  3. 结合两者给出数据洞察
```

### 场景4：电商产品分析

```
产品信息:
  - 产品图片
  - 产品描述文本
  - 用户评论
  - 价格数据

分析:
  1. 图片分析：产品质量、外观
  2. 文本分析：描述准确性、关键词
  3. 评论分析：用户情感、常见问题
  4. 价格分析：竞争力
  5. 综合评估
```

## 混合模态 Agent 构建

### 基础架构

```python
"""
混合模态 Agent 基础架构
"""
from typing import TypedDict, Annotated
from langgraph.graph import StateGraph, START, END
from langgraph.graph.message import add_messages
from langchain_core.messages import BaseMessage, HumanMessage, AIMessage, SystemMessage
from langchain.chat_models import init_chat_model

# 需要 OPENAI_API_KEY
vision_model = init_chat_model("openai:gpt-4o")
text_model = init_chat_model("groq:llama-3.3-70b-versatile")

class MultimodalState(TypedDict):
    messages: Annotated[list[BaseMessage], add_messages]
    image_url: str
    text_input: str
    image_analysis: str
    text_analysis: str
    final_output: str

def image_analyzer(state: MultimodalState) -> dict:
    """图像分析节点"""
    if not state.get("image_url"):
        return {"image_analysis": "未提供图片"}

    message = HumanMessage(
        content=[
            {"type": "text", "text": "请详细描述这张图片的内容，包括主要元素、颜色、布局等。"},
            {"type": "image_url", "image_url": {"url": state["image_url"]}}
        ]
    )
    response = vision_model.invoke([message])
    return {"image_analysis": response.content}

def text_analyzer(state: MultimodalState) -> dict:
    """文本分析节点"""
    response = text_model.invoke([
        SystemMessage(content="请分析以下文本，提取关键信息和要点。"),
        HumanMessage(content=state["text_input"])
    ])
    return {"text_analysis": response.content}

def synthesizer(state: MultimodalState) -> dict:
    """综合分析节点"""
    prompt = f"""请综合以下两方面的分析结果，给出完整的综合分析：

图像分析结果：
{state['image_analysis']}

文本分析结果：
{state['text_analysis']}

请给出综合性的结论和建议。"""

    response = text_model.invoke([HumanMessage(content=prompt)])
    return {"final_output": response.content}

# 构建图
graph = StateGraph(MultimodalState)
graph.add_node("image_analyzer", image_analyzer)
graph.add_node("text_analyzer", text_analyzer)
graph.add_node("synthesizer", synthesizer)

# 并行分析
graph.add_edge(START, "image_analyzer")
graph.add_edge(START, "text_analyzer")
graph.add_edge("image_analyzer", "synthesizer")
graph.add_edge("text_analyzer", "synthesizer")
graph.add_edge("synthesizer", END)

app = graph.compile()
```

### 带工具的混合模态 Agent

```python
"""
带工具的混合模态 Agent
"""
from langchain_core.tools import tool
from langchain.agents import create_agent

@tool
def analyze_image(image_url: str, question: str) -> str:
    """分析图片并回答关于图片的问题"""
    message = HumanMessage(
        content=[
            {"type": "text", "text": question},
            {"type": "image_url", "image_url": {"url": image_url}}
        ]
    )
    response = vision_model.invoke([message])
    return response.content

@tool
def search_web(query: str) -> str:
    """搜索网页信息"""
    # 模拟搜索
    return f"搜索结果: {query}"

@tool
def calculate(expression: str) -> str:
    """进行数学计算"""
    try:
        return str(eval(expression))
    except:
        return "计算错误"

# 创建混合模态 Agent
agent = create_agent(
    model=vision_model,
    tools=[analyze_image, search_web, calculate],
    system_prompt="""你是一个多模态助手，可以：
1. 分析图片内容
2. 搜索网页信息
3. 进行数学计算

根据用户的需求选择合适的工具。"""
)

# 使用
response = agent.invoke({
    "messages": [{
        "role": "user",
        "content": "分析这张图片中的数据图表：https://example.com/chart.png，并计算增长率。"
    }]
})
```

## 完整代码示例

### 示例1：图片+文本综合分析

```python
"""
混合模态示例：图片+文本综合分析
需要 OPENAI_API_KEY
"""
import os
from dotenv import load_dotenv
from typing import TypedDict, Annotated
from langgraph.graph import StateGraph, START, END
from langgraph.graph.message import add_messages
from langchain_core.messages import BaseMessage, HumanMessage, AIMessage, SystemMessage
from langchain.chat_models import init_chat_model

load_dotenv()

vision_model = init_chat_model("openai:gpt-4o")

class AnalysisState(TypedDict):
    messages: Annotated[list[BaseMessage], add_messages]
    image_url: str
    context_text: str
    image_findings: str
    text_findings: str
    conclusion: str

def analyze_image(state: AnalysisState) -> dict:
    """分析图像"""
    message = HumanMessage(
        content=[
            {
                "type": "text",
                "text": "请详细分析这张图片，提取所有可见的信息、数据、趋势等。"
            },
            {
                "type": "image_url",
                "image_url": {"url": state["image_url"]}
            }
        ]
    )
    response = vision_model.invoke([message])
    return {
        "image_findings": response.content,
        "messages": [AIMessage(content=f"[图像分析] {response.content[:100]}...")],
    }

def analyze_context(state: AnalysisState) -> dict:
    """分析文本上下文"""
    response = vision_model.invoke([
        SystemMessage(content="请分析以下文本，提取关键信息和要点。"),
        HumanMessage(content=state["context_text"])
    ])
    return {
        "text_findings": response.content,
        "messages": [AIMessage(content=f"[文本分析] {response.content[:100]}...")],
    }

def synthesize(state: AnalysisState) -> dict:
    """综合分析"""
    prompt = f"""基于以下分析结果，请给出综合结论：

## 图像分析发现
{state['image_findings']}

## 文本分析发现
{state['text_findings']}

请综合两方面信息，给出：
1. 主要发现
2. 关键洞察
3. 建议行动"""

    response = vision_model.invoke([HumanMessage(content=prompt)])
    return {
        "conclusion": response.content,
        "messages": [AIMessage(content=response.content)],
    }

# 构建图
graph = StateGraph(AnalysisState)
graph.add_node("analyze_image", analyze_image)
graph.add_node("analyze_text", analyze_context)
graph.add_node("synthesize", synthesize)

# 并行执行图像和文本分析
graph.add_edge(START, "analyze_image")
graph.add_edge(START, "analyze_text")
graph.add_edge("analyze_image", "synthesize")
graph.add_edge("analyze_text", "synthesize")
graph.add_edge("synthesize", END)

app = graph.compile()

# 运行
result = app.invoke({
    "messages": [],
    "image_url": "https://example.com/sales_chart.png",
    "context_text": "本季度销售额达到500万元，同比增长15%。利润率从12%提升到15%。",
    "image_findings": "",
    "text_findings": "",
    "conclusion": "",
})

print("=== 综合分析结论 ===")
print(result["conclusion"])
```

### 示例2：多模态内容审核

```python
"""
多模态内容审核系统
同时审核文本和图片内容
"""
from typing import TypedDict, Literal
from langgraph.graph import StateGraph, START, END
from langchain_core.messages import HumanMessage, SystemMessage
from langchain.chat_models import init_chat_model

model = init_chat_model("openai:gpt-4o")

class ModerationState(TypedDict):
    text_content: str
    image_url: str
    text_score: float       # 0-1, 0=安全, 1=违规
    image_score: float
    consistency_score: float
    final_decision: str     # "approve", "reject", "review"
    reasons: list

def moderate_text(state: ModerationState) -> dict:
    """审核文本内容"""
    response = model.invoke([
        SystemMessage(content="""请审核以下文本内容的安全性。
评估以下方面：
1. 是否包含敏感信息
2. 是否包含不当言论
3. 是否包含虚假信息

返回 JSON 格式：
{"score": 0-1, "issues": [...], "reason": "..."}"""),
        HumanMessage(content=state["text_content"])
    ])

    # 解析结果（简化处理）
    score = 0.1  # 假设安全
    return {"text_score": score}

def moderate_image(state: ModerationState) -> dict:
    """审核图片内容"""
    if not state.get("image_url"):
        return {"image_score": 0.0}

    message = HumanMessage(
        content=[
            {
                "type": "text",
                "text": "请审核这张图片的内容安全性。返回 0-1 的评分，0=完全安全，1=严重违规。"
            },
            {"type": "image_url", "image_url": {"url": state["image_url"]}}
        ]
    )
    response = model.invoke([message])

    score = 0.1  # 假设安全
    return {"image_score": score}

def check_consistency(state: ModerationState) -> dict:
    """检查文本和图片的一致性"""
    if not state.get("image_url"):
        return {"consistency_score": 1.0}

    message = HumanMessage(
        content=[
            {
                "type": "text",
                "text": f"文本内容：{state['text_content']}\n\n请检查图片与文本内容是否一致。返回 0-1 评分。"
            },
            {"type": "image_url", "image_url": {"url": state["image_url"]}}
        ]
    )
    response = model.invoke([message])

    score = 0.9  # 假设一致
    return {"consistency_score": score}

def make_decision(state: ModerationState) -> dict:
    """做出最终决定"""
    reasons = []

    if state["text_score"] > 0.7:
        reasons.append("文本内容不安全")
    if state["image_score"] > 0.7:
        reasons.append("图片内容不安全")
    if state["consistency_score"] < 0.5:
        reasons.append("文本和图片不一致")

    if any(s > 0.7 for s in [state["text_score"], state["image_score"]]):
        decision = "reject"
    elif state["consistency_score"] < 0.5:
        decision = "review"
    else:
        decision = "approve"

    return {
        "final_decision": decision,
        "reasons": reasons,
    }

# 构建图
graph = StateGraph(ModerationState)
graph.add_node("moderate_text", moderate_text)
graph.add_node("moderate_image", moderate_image)
graph.add_node("check_consistency", check_consistency)
graph.add_node("decide", make_decision)

graph.add_edge(START, "moderate_text")
graph.add_edge(START, "moderate_image")
graph.add_edge("moderate_text", "check_consistency")
graph.add_edge("moderate_image", "check_consistency")
graph.add_edge("check_consistency", "decide")
graph.add_edge("decide", END)

app = graph.compile()

# 运行
result = app.invoke({
    "text_content": "这是一篇关于 AI 发展的文章...",
    "image_url": "https://example.com/article_image.jpg",
    "text_score": 0.0,
    "image_score": 0.0,
    "consistency_score": 0.0,
    "final_decision": "",
    "reasons": [],
})

print(f"审核结果: {result['final_decision']}")
print(f"原因: {result['reasons']}")
```

### 示例3：图表数据提取与分析

```python
"""
图表数据提取与分析
从图表图片中提取数据，结合原始数据进行分析
"""
from typing import TypedDict, Annotated
from langgraph.graph import StateGraph, START, END
from langgraph.graph.message import add_messages
from langchain_core.messages import BaseMessage, HumanMessage, AIMessage
from langchain.chat_models import init_chat_model

model = init_chat_model("openai:gpt-4o")

class ChartState(TypedDict):
    messages: Annotated[list[BaseMessage], add_messages]
    chart_image_url: str
    raw_data: str
    extracted_data: str
    data_analysis: str
    insights: str

def extract_from_chart(state: ChartState) -> dict:
    """从图表中提取数据"""
    message = HumanMessage(
        content=[
            {
                "type": "text",
                "text": """请从这张图表中提取所有可见的数据点。
以 JSON 格式输出：
{
  "chart_type": "柱状图/折线图/饼图",
  "data_points": [
    {"label": "...", "value": ...},
    ...
  ],
  "trend": "上升/下降/平稳"
}"""
            },
            {"type": "image_url", "image_url": {"url": state["chart_image_url"]}}
        ]
    )
    response = model.invoke([message])
    return {"extracted_data": response.content}

def analyze_raw_data(state: ChartState) -> dict:
    """分析原始数据"""
    response = model.invoke([
        HumanMessage(content=f"请分析以下数据，计算关键统计指标：\n{state['raw_data']}")
    ])
    return {"data_analysis": response.content}

def generate_insights(state: ChartState) -> dict:
    """生成数据洞察"""
    prompt = f"""基于以下信息，生成数据洞察：

图表提取的数据：
{state['extracted_data']}

原始数据分析：
{state['data_analysis']}

请提供：
1. 关键发现
2. 趋势分析
3. 异常点
4. 建议"""

    response = model.invoke([HumanMessage(content=prompt)])
    return {
        "insights": response.content,
        "messages": [AIMessage(content=response.content)],
    }

# 构建图
graph = StateGraph(ChartState)
graph.add_node("extract_chart", extract_from_chart)
graph.add_node("analyze_data", analyze_raw_data)
graph.add_node("insights", generate_insights)

graph.add_edge(START, "extract_chart")
graph.add_edge(START, "analyze_data")
graph.add_edge("extract_chart", "insights")
graph.add_edge("analyze_data", "insights")
graph.add_edge("insights", END)

app = graph.compile()
```

## 常见错误

### 1. 使用不支持视觉的模型

```python
# 错误：Groq 不支持图像
model = init_chat_model("groq:llama-3.3-70b-versatile")
message = HumanMessage(content=[
    {"type": "text", "text": "描述图片"},
    {"type": "image_url", "image_url": {"url": "..."}}
])
model.invoke([message])  # 会报错！

# 正确：使用支持视觉的模型
model = init_chat_model("openai:gpt-4o")
```

### 2. 混用不同模型的能力

```python
# 错误：用文本模型处理图像
text_model = init_chat_model("groq:llama-3.3-70b-versatile")
text_model.invoke([image_message])  # 不支持！

# 正确：根据任务选择合适的模型
vision_model = init_chat_model("openai:gpt-4o")  # 图像任务
text_model = init_chat_model("groq:llama-3.3-70b-versatile")  # 纯文本任务
```

### 3. 忘记设置 OPENAI_API_KEY

```python
# 错误：未配置 API Key
# AuthenticationError: No API key provided

# 正确：在 .env 中配置
# OPENAI_API_KEY=sk-xxxx
from dotenv import load_dotenv
load_dotenv()
```

### 4. 图像 URL 无效

```python
# 错误：URL 已失效或无法访问
image_url = "https://expired-link.com/image.jpg"

# 正确：确保 URL 可访问
# 使用公开可访问的 URL，或使用 base64 编码本地图片
```
