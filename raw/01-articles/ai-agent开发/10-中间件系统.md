## 1. 什么是中间件

### 中间件的定义

中间件（Middleware）是一种在 Agent 执行周期中插入自定义逻辑的机制。它允许你在不修改 Agent 核心代码的情况下，添加日志记录、监控、消息处理等功能。

```
┌─────────────────────────────────────────────────────────────┐
│                    中间件的作用                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  没有中间件:                                                 │
│  用户输入 ──→ Agent ──→ LLM ──→ 输出                        │
│                                                             │
│  有中间件:                                                   │
│  用户输入 ──→ [中间件] ──→ Agent ──→ [中间件] ──→ 输出       │
│                │                              │             │
│                ▼                              ▼             │
│          可以修改输入                    可以修改输出         │
│          可以记录日志                    可以验证结果         │
│          可以拦截请求                    可以转换格式         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 中间件 vs 装饰器

| 特性 | 中间件 | 装饰器 |
|------|--------|--------|
| 执行时机 | before_model / after_model | 函数调用前后 |
| 访问状态 | 可以访问完整Agent状态 | 只能访问函数参数 |
| 链式组合 | 支持多个中间件组合 | 支持多层装饰 |
| 应用场景 | Agent级别控制 | 函数级别控制 |

### 常见中间件用途

1. **日志记录**：记录每次Agent调用的输入输出
2. **性能监控**：测量LLM调用延迟
3. **消息裁剪**：自动管理上下文长度
4. **输入验证**：验证用户输入的合法性
5. **输出格式化**：统一输出格式
6. **错误处理**：捕获和处理异常
7. **缓存**：缓存频繁的LLM调用结果
8. **限流**：限制API调用频率

### AgentMiddleware 的方法

```python
from langchain.agents.middleware import AgentMiddleware
from typing import Any, Dict, List, Optional
from langchain_core.messages import BaseMessage


class MyMiddleware(AgentMiddleware):
    """自定义中间件基类"""

    async def before_model(
        self,
        messages: List[BaseMessage],
        **kwargs
    ) -> Optional[List[BaseMessage]]:
        """
        在LLM调用前执行

        参数:
            messages: 当前的消息列表
            **kwargs: 其他参数

        返回:
            修改后的消息列表，或None（不修改）
        """
        # 在这里执行前置逻辑
        return messages  # 返回修改后的消息，或None保持原样

    async def after_model(
        self,
        messages: List[BaseMessage],
        response: Any,
        **kwargs
    ) -> Optional[Any]:
        """
        在LLM调用后执行

        参数:
            messages: 发送给LLM的消息列表
            response: LLM的响应
            **kwargs: 其他参数

        返回:
            修改后的响应，或None（使用原始响应）
        """
        # 在这里执行后置逻辑
        return response  # 返回修改后的响应，或None保持原样
```

### before_model 详解

```python
class InputLoggerMiddleware(AgentMiddleware):
    """输入日志中间件"""

    async def before_model(self, messages, **kwargs):
        # 记录输入
        print(f"[InputLogger] 收到 {len(messages)} 条消息")

        for i, msg in enumerate(messages):
            content_preview = msg.content[:50] if msg.content else "(空)"
            print(f"  [{i}] {msg.__class__.__name__}: {content_preview}...")

        # 返回None表示不修改消息
        return None
```

### after_model 详解

```python
class OutputLoggerMiddleware(AgentMiddleware):
    """输出日志中间件"""

    async def after_model(self, messages, response, **kwargs):
        # 记录输出
        if hasattr(response, 'content'):
            print(f"[OutputLogger] AI回复: {response.content[:100]}...")

        if hasattr(response, 'tool_calls') and response.tool_calls:
            for tc in response.tool_calls:
                print(f"[OutputLogger] 工具调用: {tc['name']}")

        # 返回None表示不修改响应
        return None
```

| 阶段 | 执行顺序 | 说明 |
|------|---------|------|
| before_model | 后注册 → 先执行 | 最后添加的中间件最先执行 |

| after_model | 先注册 → 先执行 | 最先添加的中间件最先执行 |

## 4. 自定义中间件示例

### 示例1：LoggingMiddleware（日志记录）

```python
import time
from langchain.agents.middleware import AgentMiddleware
from typing import List, Optional, Any
from langchain_core.messages import BaseMessage


class LoggingMiddleware(AgentMiddleware):
    """日志记录中间件"""

    def __init__(self, log_level: str = "INFO"):
        self.log_level = log_level
        self.call_count = 0

    async def before_model(self, messages: List[BaseMessage], **kwargs):
        self.call_count += 1
        self._start_time = time.time()

        print(f"[LOG-{self.log_level}] 调用 #{self.call_count} 开始")
        print(f"  消息数: {len(messages)}")

        # 计算总字符数
        total_chars = sum(len(msg.content or "") for msg in messages)
        print(f"  总字符数: {total_chars}")

        return None

    async def after_model(self, messages, response, **kwargs):
        elapsed = time.time() - self._start_time
        print(f"[LOG-{self.log_level}] 调用 #{self.call_count} 完成")
        print(f"  耗时: {elapsed:.2f}秒")

        if hasattr(response, 'content'):
            print(f"  回复长度: {len(response.content)}字符")

        return None
```

### 示例2：CallCounterMiddleware（调用计数）

```python
from langchain.agents.middleware import AgentMiddleware
from typing import List, Optional, Any
from langchain_core.messages import BaseMessage
from collections import defaultdict
from datetime import datetime


class CallCounterMiddleware(AgentMiddleware):
    """调用计数中间件"""

    def __init__(self):
        self.total_calls = 0
        self.thread_calls = defaultdict(int)
        self.call_history = []

    async def before_model(self, messages, **kwargs):
        self.total_calls += 1

        # 获取thread_id（如果存在）
        thread_id = kwargs.get("config", {}).get("configurable", {}).get("thread_id", "unknown")
        self.thread_calls[thread_id] += 1

        # 记录调用历史
        self.call_history.append({
            "timestamp": datetime.now().isoformat(),
            "thread_id": thread_id,
            "message_count": len(messages),
        })

        print(f"[Counter] 总调用: {self.total_calls}, "
              f"当前线程: {self.thread_calls[thread_id]}")

        return None

    def get_stats(self):
        """获取统计信息"""
        return {
            "total_calls": self.total_calls,
            "thread_counts": dict(self.thread_calls),
            "unique_threads": len(self.thread_calls),
        }
```

### 示例3：MessageTrimmerMiddleware（消息裁剪）

```python
from langchain.agents.middleware import AgentMiddleware
from langchain_core.messages import trim_messages, SystemMessage
from typing import List, Optional, Any
from langchain_core.messages import BaseMessage


class MessageTrimmerMiddleware(AgentMiddleware):
    """消息裁剪中间件"""

    def __init__(self, max_messages: int = 20, keep_system: bool = True):
        self.max_messages = max_messages
        self.keep_system = keep_system

    async def before_model(self, messages: List[BaseMessage], **kwargs):
        if len(messages) <= self.max_messages:
            return None  # 不需要裁剪

        original_count = len(messages)

        # 裁剪消息
        trimmed = trim_messages(
            messages,
            max_messages=self.max_messages,
            strategy="last",
            include_system=self.keep_system,
        )

        print(f"[Trimmer] 消息裁剪: {original_count} -> {len(trimmed)}")

        return trimmed  # 返回裁剪后的消息

    async def after_model(self, messages, response, **kwargs):
        return None
```

### 示例4：OutputValidationMiddleware（输出验证）

```python
from langchain.agents.middleware import AgentMiddleware
from typing import List, Optional, Any
from langchain_core.messages import BaseMessage, AIMessage


class OutputValidationMiddleware(AgentMiddleware):
    """输出验证中间件"""

    def __init__(self, max_length: int = 5000, forbidden_words: list = None):
        self.max_length = max_length
        self.forbidden_words = forbidden_words or []

    async def before_model(self, messages, **kwargs):
        return None

    async def after_model(self, messages, response, **kwargs):
        if not isinstance(response, AIMessage):
            return None

        content = response.content or ""

        # 检查长度
        if len(content) > self.max_length:
            print(f"[Validator] 警告: 回复过长 ({len(content)} > {self.max_length})")
            # 截断回复
            response.content = content[:self.max_length] + "..."

        # 检查禁用词
        for word in self.forbidden_words:
            if word in content:
                print(f"[Validator] 警告: 发现禁用词 '{word}'")
                # 可以选择替换或抛出异常
                response.content = response.content.replace(word, "***")

        return response  # 返回修改后的响应
```

### 示例5：MaxCallsMiddleware（最大调用次数限制）

```python
from langchain.agents.middleware import AgentMiddleware
from typing import List, Optional, Any
from langchain_core.messages import BaseMessage


class MaxCallsLimitExceeded(Exception):
    """超出最大调用次数异常"""
    pass


class MaxCallsMiddleware(AgentMiddleware):
    """限制最大调用次数中间件"""

    def __init__(self, max_calls: int = 10):
        self.max_calls = max_calls
        self.call_count = 0

    async def before_model(self, messages, **kwargs):
        self.call_count += 1

        if self.call_count > self.max_calls:
            raise MaxCallsLimitExceeded(
                f"已达到最大调用次数限制 ({self.max_calls})"
            )

        print(f"[MaxCalls] 调用次数: {self.call_count}/{self.max_calls}")

        return None

    def reset(self):
        """重置计数器"""
        self.call_count = 0
```

### SummarizationMiddleware 的实现原理

```python
from langchain.agents.middleware import SummarizationMiddleware
```

### 与自定义中间件的结合

```python
"""
组合使用内置和自定义中间件
"""
from langchain.chat_models import init_chat_model
from langchain.agents import create_agent
from langchain.agents.middleware import SummarizationMiddleware
from langgraph.checkpoint.memory import InMemorySaver


class CustomLoggingMiddleware(AgentMiddleware):
    """自定义日志中间件"""
    async def before_model(self, messages, **kwargs):
        print(f"[Custom] 消息数: {len(messages)}")
        return None

    async def after_model(self, messages, response, **kwargs):
        return None


def combined_middleware_example():
    """组合中间件示例"""

    model = init_chat_model("groq:llama-3.3-70b-versatile")
    checkpointer = InMemorySaver()

    # 组合多个中间件
    agent = create_agent(
        model=model,
        tools=[],
        system_prompt="你是一个助手。",
        checkpointer=checkpointer,
        middleware=[
            CustomLoggingMiddleware(),           # 自定义日志
            SummarizationMiddleware(             # 内置摘要
                token_threshold=2000,
                summary_prompt="请压缩对话历史："
            ),
        ]
    )

    return agent


if __name__ == "__main__":
    agent = combined_middleware_example()
    config = {"configurable": {"thread_id": "combined-demo"}}

    response = agent.invoke(
        {"messages": [{"role": "user", "content": "你好"}]},
        config=config
    )
    print(f"AI: {response['messages'][-1].content}")
```

## 6. 中间件中的流程控制

### 抛出异常中断执行

```python
from langchain.agents.middleware import AgentMiddleware


class SecurityMiddleware(AgentMiddleware):
    """安全检查中间件"""

    def __init__(self, blocked_patterns: list = None):
        self.blocked_patterns = blocked_patterns or []

    async def before_model(self, messages, **kwargs):
        # 检查最后一条用户消息
        last_user_msg = None
        for msg in reversed(messages):
            if msg.__class__.__name__ == "HumanMessage":
                last_user_msg = msg.content
                break

        if last_user_msg:
            for pattern in self.blocked_patterns:
                if pattern in last_user_msg:
                    # 抛出异常，中断执行
                    raise ValueError(
                        f"安全检查失败: 消息包含禁止内容 '{pattern}'"
                    )

        return None

    async def after_model(self, messages, response, **kwargs):
        return None
```

```python
class MessageInjectionMiddleware(AgentMiddleware):
    """消息注入中间件"""

    def __init__(self, system_message: str):
        self.system_message = system_message

    async def before_model(self, messages, **kwargs):
        from langchain_core.messages import SystemMessage

        # 检查是否已有系统消息
        has_system = any(
            isinstance(msg, SystemMessage) for msg in messages
        )

        if not has_system:
            # 注入系统消息
            messages = [SystemMessage(content=self.system_message)] + messages
            print("[Injection] 注入系统消息")

        return messages  # 返回修改后的消息

    async def after_model(self, messages, response, **kwargs):
        return None
```

```python
from langchain.agents.middleware import AgentMiddleware


class AMiddleware(AgentMiddleware):
    async def before_model(self, messages, **kwargs):
        print("[A] before - 可能修改消息")
        return None
    async def after_model(self, messages, response, **kwargs):
        print("[A] after")
        return None


class BMiddleware(AgentMiddleware):
    async def before_model(self, messages, **kwargs):
        print("[B] before")
        return None
    async def after_model(self, messages, response, **kwargs):
        print("[B] after - 可能修改响应")
        return None


# 顺序1: [A, B]
# before: B → A → LLM → after: A → B

# 顺序2: [B, A]

```

## 8. 完整代码示例

### 示例1：完整的中间件管理系统

```python
"""
完整的中间件管理系统
"""
import time
from datetime import datetime
from typing import List, Optional, Any, Dict
from collections import defaultdict

from langchain.chat_models import init_chat_model
from langchain.agents import create_agent
from langchain.agents.middleware import AgentMiddleware, SummarizationMiddleware
from langchain_core.messages import BaseMessage, AIMessage, SystemMessage
from langgraph.checkpoint.memory import InMemorySaver


class TimingMiddleware(AgentMiddleware):
    """计时中间件"""

    def __init__(self):
        self.timings = []

    async def before_model(self, messages, **kwargs):
        self._start_time = time.time()
        return None

    async def after_model(self, messages, response, **kwargs):
        elapsed = time.time() - self._start_time
        self.timings.append(elapsed)
        print(f"[Timing] LLM调用耗时: {elapsed:.2f}秒")
        return None

    def get_average_time(self):
        """获取平均调用时间"""
        if not self.timings:
            return 0
        return sum(self.timings) / len(self.timings)


class MessageCounterMiddleware(AgentMiddleware):
    """消息计数中间件"""

    def __init__(self):
        self.counts = defaultdict(int)

    async def before_model(self, messages, **kwargs):
        for msg in messages:
            self.counts[msg.__class__.__name__] += 1
        return None

    async def after_model(self, messages, response, **kwargs):
        if isinstance(response, AIMessage):
            self.counts["AIMessage"] += 1
        return None

    def get_stats(self):
        """获取统计信息"""
        return dict(self.counts)


class ContentFilterMiddleware(AgentMiddleware):
    """内容过滤中间件"""

    def __init__(self, forbidden_words: List[str] = None):
        self.forbidden_words = forbidden_words or []
        self.filter_count = 0

    async def before_model(self, messages, **kwargs):
        # 检查用户输入
        for msg in messages:
            if msg.__class__.__name__ == "HumanMessage":
                content = msg.content or ""
                for word in self.forbidden_words:
                    if word in content:
                        raise ValueError(f"输入包含禁止内容: '{word}'")
        return None

    async def after_model(self, messages, response, **kwargs):
        # 检查AI输出
        if isinstance(response, AIMessage):
            content = response.content or ""
            for word in self.forbidden_words:
                if word in content:
                    self.filter_count += 1
                    response.content = response.content.replace(word, "***")
                    print(f"[Filter] 过滤了禁止词: '{word}'")
        return response


class CompleteMiddlewareAgent:
    """完整的中间件管理Agent"""

    def __init__(self):
        self.model = init_chat_model("groq:llama-3.3-70b-versatile")
        self.checkpointer = InMemorySaver()

        # 创建中间件实例
        self.timing = TimingMiddleware()
        self.counter = MessageCounterMiddleware()
        self.filter = ContentFilterMiddleware(
            forbidden_words=["hack", "exploit"]
        )

        # 创建Agent
        self.agent = create_agent(
            model=self.model,
            tools=[],
            system_prompt="你是一个有帮助的助手。",
            checkpointer=self.checkpointer,
            middleware=[
                self.filter,      # 1. 内容过滤（最先）
                self.counter,     # 2. 消息计数
                self.timing,      # 3. 性能计时
                SummarizationMiddleware(token_threshold=2000),  # 4. 自动摘要
            ]
        )

    def chat(self, user_input: str, thread_id: str = "default") -> str:
        """聊天接口"""
        config = {"configurable": {"thread_id": thread_id}}

        try:
            response = self.agent.invoke(
                {"messages": [{"role": "user", "content": user_input}]},
                config=config
            )
            return response["messages"][-1].content
        except ValueError as e:
            return f"输入被拒绝: {e}"

    def get_stats(self) -> Dict:
        """获取统计信息"""
        return {
            "timing": {
                "average": self.timing.get_average_time(),
                "count": len(self.timing.timings),
            },
            "messages": self.counter.get_stats(),
            "filtered": self.filter.filter_count,
        }


def complete_middleware_example():
    """完整中间件示例"""

    agent = CompleteMiddlewareAgent()

    # 模拟对话
    conversations = [
        "你好，我想学习Python",
        "什么是装饰器？",
        "能给我一个例子吗？",
        "谢谢你的帮助",
    ]

    for i, user_input in enumerate(conversations, 1):
        print(f"\n[轮次 {i}] 用户: {user_input}")
        response = agent.chat(user_input, thread_id="demo")
        print(f"[轮次 {i}] AI: {response}")

    # 输出统计
    print("\n" + "=" * 50)
    print("统计信息")
    print("=" * 50)
    stats = agent.get_stats()
    print(f"平均LLM调用时间: {stats['timing']['average']:.2f}秒")
    print(f"消息类型统计: {stats['messages']}")
    print(f"过滤次数: {stats['filtered']}")


if __name__ == "__main__":
    complete_middleware_example()
```

### 示例2：中间件链式处理

```python
"""
中间件链式处理示例
"""
from langchain.agents.middleware import AgentMiddleware
from typing import List, Optional, Any
from langchain_core.messages import BaseMessage, AIMessage


class TransformChainMiddleware(AgentMiddleware):
    """转换链中间件"""

    def __init__(self, name: str, transform_func):
        self.name = name
        self.transform_func = transform_func

    async def before_model(self, messages, **kwargs):
        print(f"[{self.name}] 处理输入")
        return None

    async def after_model(self, messages, response, **kwargs):
        if isinstance(response, AIMessage):
            print(f"[{self.name}] 处理输出")
            response = self.transform_func(response)
        return response


def uppercase_transform(response: AIMessage) -> AIMessage:
    """转换为大写"""
    response.content = response.content.upper()
    return response


def add_prefix_transform(prefix: str):
    """添加前缀的工厂函数"""
    def transform(response: AIMessage) -> AIMessage:
        response.content = f"{prefix}: {response.content}"
        return response
    return transform


def chain_example():
    """链式处理示例"""
    from langchain.chat_models import init_chat_model
    from langchain.agents import create_agent
    from langgraph.checkpoint.memory import InMemorySaver

    model = init_chat_model("groq:llama-3.3-70b-versatile")
    checkpointer = InMemorySaver()

    agent = create_agent(
        model=model,
        tools=[],
        system_prompt="你是一个助手。",
        checkpointer=checkpointer,
        middleware=[
            TransformChainMiddleware("UpperCase", uppercase_transform),
            TransformChainMiddleware("Prefix", add_prefix_transform("AI")),
        ]
    )

    config = {"configurable": {"thread_id": "chain-demo"}}
    response = agent.invoke(
        {"messages": [{"role": "user", "content": "你好"}]},
        config=config
    )
    print(f"最终输出: {response['messages'][-1].content}")
    # 输出类似: "AI: 你好！有什么可以帮助你的？".upper()


if __name__ == "__main__":
    chain_example()
```

## 9. 常见错误

### 错误1：中间件顺序错误

```python
# 错误：安全检查在摘要之后
middleware=[
    SummarizationMiddleware(token_threshold=2000),  # 先摘要
    SecurityMiddleware(blocked_patterns=[...]),      # 后检查
]
# 问题：摘要可能已经处理了不安全内容

# 正确：安全检查在摘要之前
middleware=[
    SecurityMiddleware(blocked_patterns=[...]),      # 先检查
    SummarizationMiddleware(token_threshold=2000),   # 后摘要
]
```

### 错误2：忘记返回值

```python
# 错误：before_model没有返回值
async def before_model(self, messages, **kwargs):
    print("处理消息")
    # 没有return语句，默认返回None

# 如果需要修改消息，必须返回修改后的列表
async def before_model(self, messages, **kwargs):
    print("处理消息")
    return modified_messages  # 必须返回
```

### 错误3：中间件中的异常处理

```python
# 错误：中间件中抛出未捕获的异常
async def before_model(self, messages, **kwargs):
    # 如果这里抛出异常，整个Agent调用会失败
    raise Exception("中间件错误")

# 正确：捕获异常或使用自定义异常
async def before_model(self, messages, **kwargs):
    try:
        # 处理逻辑
        pass
    except SomeError as e:
        print(f"中间件错误: {e}")
        return None  # 返回None表示不修改
```

### 错误4：状态管理不当

```python
# 错误：在中间件中存储可变状态，但没有考虑线程安全
class BadMiddleware(AgentMiddleware):
    def __init__(self):
        self.counter = 0  # 可能有并发问题

# 正确：使用线程安全的方式
import threading

class GoodMiddleware(AgentMiddleware):
    def __init__(self):
        self._lock = threading.Lock()
        self.counter = 0

    async def before_model(self, messages, **kwargs):
        with self._lock:
            self.counter += 1
        return None
```

## 10. 最佳实践

### 1. 保持中间件职责单一

```python
# 好：每个中间件只做一件事
class LoggingMiddleware(AgentMiddleware):
    """只负责日志记录"""
    pass

class SecurityMiddleware(AgentMiddleware):
    """只负责安全检查"""
    pass

# 不好：一个中间件做太多事情
class DoEverythingMiddleware(AgentMiddleware):
    """日志、安全、验证、转换..."""
    pass
```

### 2. 合理的中间件顺序

```python
middleware = [
    # 1. 安全检查（最先）
    SecurityMiddleware(),

    # 2. 输入验证
    InputValidationMiddleware(),

    # 3. 日志记录
    LoggingMiddleware(),

    # 4. 消息处理
    SummarizationMiddleware(token_threshold=2000),

    # 5. 输出验证（最后）
    OutputValidationMiddleware(),
]
```

### 3. 中间件应该是可配置的

```python
class ConfigurableMiddleware(AgentMiddleware):
    """可配置的中间件"""

    def __init__(self, config: dict = None):
        self.config = config or {}

    async def before_model(self, messages, **kwargs):
        # 使用self.config中的配置
        if self.config.get("enable_logging"):
            print(f"消息数: {len(messages)}")
        return None
```

### 4. 中间件应该是可测试的

```python
import pytest

class TestLoggingMiddleware:
    """中间件测试"""

    @pytest.fixture
    def middleware(self):
        return LoggingMiddleware()

    @pytest.mark.asyncio
    async def test_before_model(self, middleware):
        messages = [HumanMessage(content="测试")]
        result = await middleware.before_model(messages)
        assert result is None  # 不修改消息
```
