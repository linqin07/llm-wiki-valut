## 项目概述

研究助手是一个**多阶段、有状态的工作流系统**，能够自动完成从问题分析到报告生成的完整研究过程。与简单的问答系统不同，研究助手模拟了人类研究者的工作方式：先规划、再收集、然后分析、最后撰写报告。

### 项目目标

构建一个**多阶段研究工作流**，具备以下能力：

1. **智能规划**：将复杂研究问题分解为可执行的子任务
2. **信息收集**：利用搜索工具和文档检索获取相关信息
3. **分析综合**：从多个来源中提取关键发现并整合
4. **报告生成**：支持多种格式（简报、详细报告、学术报告）
5. **迭代优化**：自动评估报告质量并改进

### 与 RAG 系统的区别

| 特性 | RAG 系统 | 研究助手 |
|------|---------|---------|
| 目标 | 回答具体问题 | 完成完整研究任务 |
| 流程 | 单轮检索+生成 | 多阶段迭代工作流 |
| 输出 | 简短回答 | 结构化研究报告 |
| 复杂度 | 低-中 | 中-高 |
| 状态管理 | 简单 | 复杂（多阶段状态） |

## 核心阶段实现

### 1. 研究规划阶段

规划阶段将用户的宽泛研究主题分解为具体的、可执行的研究问题。

```python
"""研究规划阶段 - 问题分解与计划制定"""

from typing import Optional
from pydantic import BaseModel, Field
from langchain_core.messages import SystemMessage, HumanMessage


# ========== 数据模型 ==========
class ResearchPlan(BaseModel):
    """研究计划"""
    main_question: str = Field(
        description="核心研究问题，一句话概括"
    )
    sub_questions: list[str] = Field(
        description="3-5 个子问题，用于系统性地回答核心问题"
    )
    methodology: str = Field(
        description="建议的研究方法和步骤"
    )
    scope: str = Field(
        description="研究范围界定，明确哪些内容在范围内，哪些不在"
    )
    expected_output: str = Field(
        description="预期输出格式和内容"
    )
    estimated_complexity: str = Field(
        description="复杂度评估：low/medium/high"
    )


# ========== 规划提示词 ==========
PLANNING_PROMPT = """你是一个专业的研究规划师。用户会给你一个研究主题，你需要制定一个系统性的研究计划。

你的任务：
1. 将研究主题转化为一个明确的核心研究问题
2. 分解为 3-5 个子问题，确保逻辑完整
3. 确定研究方法和步骤
4. 明确研究范围
5. 预估复杂度

注意：
- 子问题应该从不同角度覆盖核心问题
- 研究方法要具体可执行
- 范围界定要清晰，避免过于宽泛
- 用中文输出所有内容
"""


async def plan_research(llm, topic: str) -> ResearchPlan:
    """制定研究计划"""
    structured_llm = llm.with_structured_output(ResearchPlan)

    plan = await structured_llm.ainvoke([
        SystemMessage(content=PLANNING_PROMPT),
        HumanMessage(content=f"请为以下主题制定研究计划：\n\n{topic}"),
    ])

    return plan


def format_plan(plan: ResearchPlan) -> str:
    """格式化研究计划为可读文本"""
    lines = [
        f"研究计划",
        f"{'='*50}",
        f"核心问题: {plan.main_question}",
        f"复杂度: {plan.estimated_complexity}",
        f"\n子问题:",
    ]
    for i, sq in enumerate(plan.sub_questions, 1):
        lines.append(f"  {i}. {sq}")

    lines.extend([
        f"\n研究方法:\n  {plan.methodology}",
        f"\n范围界定:\n  {plan.scope}",
        f"\n预期输出:\n  {plan.expected_output}",
    ])

    return "\n".join(lines)
```

### 2. 信息收集阶段

信息收集阶段根据研究计划，使用工具搜索相关信息。

```python
"""信息收集阶段 - 使用工具获取信息"""

from typing import Optional
from pydantic import BaseModel, Field
from langchain_core.tools import tool
from langchain_core.messages import SystemMessage, HumanMessage


# ========== 数据模型 ==========
class CollectedInfo(BaseModel):
    """收集到的信息条目"""
    source: str = Field(description="信息来源")
    content: str = Field(description="信息内容摘要")
    relevance: float = Field(description="与研究问题的相关度 0-1", ge=0.0, le=1.0)
    sub_question: str = Field(description="对应的子问题")


# ========== 搜索工具 ==========
@tool
def web_search(query: str) -> str:
    """搜索互联网获取最新信息。

    Args:
        query: 搜索关键词
    """
    # 实际项目中接入搜索 API（如 Tavily, SerpAPI）
    # 这里使用模拟数据
    mock_results = {
        "LangChain": (
            "LangChain 是一个用于构建 LLM 应用的框架。"
            "最新版本 1.0 引入了重大 API 变更，包括 create_agent 替代 create_react_agent。"
            "GitHub star 数超过 90k。"
        ),
        "LangGraph": (
            "LangGraph 是 LangChain 生态中的状态图框架。"
            "用于构建有状态的多步骤工作流。"
            "最新版本 1.0 稳定了 StateGraph API。"
        ),
        "RAG": (
            "RAG（检索增强生成）是当前最流行的 LLM 应用模式。"
            "通过外部知识库增强 LLM 的回答质量。"
            "关键技术包括：向量检索、重排序、查询改写。"
        ),
    }

    for key, value in mock_results.items():
        if key.lower() in query.lower():
            return value

    return f"搜索 '{query}' 的结果：未找到高度相关的信息。建议尝试更具体的关键词。"


@tool
def search_documents(topic: str) -> str:
    """在本地文档库中搜索相关信息。

    Args:
        topic: 搜索主题
    """
    # 实际项目中接入向量检索
    return (
        f"在本地文档库中搜索 '{topic}' 的结果：\n"
        f"- 找到 3 篇相关文档\n"
        f"- 主要内容涉及 {topic} 的基本概念和实践案例\n"
        f"- 建议结合网络搜索获取最新信息"
    )


@tool
def analyze_data_source(source_name: str) -> str:
    """分析特定数据源的可信度和信息质量。

    Args:
        source_name: 数据源名称或 URL
    """
    return (
        f"数据源分析: {source_name}\n"
        f"- 可信度: 高\n"
        f"- 时效性: 近期更新\n"
        f"- 覆盖范围: 中等\n"
        f"- 建议: 可作为主要参考来源"
    )


# ========== 收集器实现 ==========
COLLECTION_PROMPT = """你是一个专业的研究信息收集员。

根据研究计划中的子问题，使用可用的搜索工具收集相关信息。

工作流程：
1. 针对每个子问题，制定搜索策略
2. 使用搜索工具获取信息
3. 评估信息的相关性和可靠性
4. 整理收集到的信息

注意：
- 每个子问题至少搜索一次
- 记录信息来源
- 评估每个信息条目的相关度
- 如果信息不足，尝试不同的搜索关键词
"""


async def collect_information(llm, plan, tools=None) -> list:
    """根据研究计划收集信息"""
    if tools is None:
        tools = [web_search, search_documents, analyze_data_source]

    # 创建带工具的 Agent
    from langchain.agents import create_agent
    collector_agent = create_agent(
        model=llm,
        tools=tools,
        system_prompt=COLLECTION_PROMPT,
    )

    collected = []

    for i, sub_question in enumerate(plan.sub_questions, 1):
        print(f"[信息收集] 正在处理子问题 {i}/{len(plan.sub_questions)}: {sub_question}")

        response = await collector_agent.ainvoke({
            "messages": [{"role": "user", "content": f"请收集关于以下问题的信息：{sub_question}"}],
        })

        # 提取收集到的信息
        for msg in response.get("messages", []):
            if hasattr(msg, "content") and msg.content:
                collected.append(CollectedInfo(
                    source=f"子问题{i}搜索结果",
                    content=msg.content[:500],  # 截取摘要
                    relevance=0.8,
                    sub_question=sub_question,
                ))

    return collected
```

### 3. 分析综合阶段

```python
"""分析综合阶段 - 信息整理与关键发现提取"""

from typing import Optional
from pydantic import BaseModel, Field
from langchain_core.messages import SystemMessage, HumanMessage


# ========== 数据模型 ==========
class KeyFinding(BaseModel):
    """关键发现"""
    finding: str = Field(description="发现内容")
    supporting_evidence: list[str] = Field(description="支持证据")
    confidence: float = Field(description="置信度 0-1", ge=0.0, le=1.0)
    category: str = Field(description="发现类别：事实/趋势/观点/数据")


class AnalysisResult(BaseModel):
    """分析结果"""
    key_findings: list[KeyFinding] = Field(description="关键发现列表")
    patterns: list[str] = Field(description="发现的模式或趋势")
    contradictions: list[str] = Field(description="信息中的矛盾或分歧")
    gaps: list[str] = Field(description="信息空白或需要进一步研究的领域")
    summary: str = Field(description="分析总结")


# ========== 分析提示词 ==========
ANALYSIS_PROMPT = """你是一个专业的研究分析师。

根据收集到的信息，进行深入分析和综合。

分析维度：
1. 提取关键发现（重要事实、数据、观点）
2. 识别信息中的模式和趋势
3. 发现矛盾或分歧之处
4. 指出信息空白

注意：
- 每个关键发现都要有支持证据
- 区分事实和观点
- 对矛盾信息进行标注
- 用中文输出
"""


async def analyze_findings(llm, collected_info: list, plan) -> AnalysisResult:
    """分析收集到的信息"""
    structured_llm = llm.with_structured_output(AnalysisResult)

    # 构建信息摘要
    info_summary = "\n\n".join([
        f"[来源: {info.source}] (相关度: {info.relevance:.1f})\n{info.content}"
        for info in collected_info
    ])

    analysis = await structured_llm.ainvoke([
        SystemMessage(content=ANALYSIS_PROMPT),
        HumanMessage(content=(
            f"研究主题: {plan.main_question}\n\n"
            f"收集到的信息:\n{info_summary}\n\n"
            f"请进行深入分析。"
        )),
    ])

    return analysis
```

### 4. 报告生成阶段

```python
"""报告生成阶段 - 多格式结构化报告输出"""

from typing import Optional
from enum import Enum
from pydantic import BaseModel, Field
from langchain_core.messages import SystemMessage, HumanMessage


# ========== 报告格式 ==========
class ReportFormat(str, Enum):
    """报告格式类型"""
    BRIEF = "brief"           # 简报（1-2 页）
    DETAILED = "detailed"     # 详细报告（5-10 页）
    ACADEMIC = "academic"     # 学术报告


# ========== 报告结构 ==========
class ReportSection(BaseModel):
    """报告章节"""
    title: str = Field(description="章节标题")
    content: str = Field(description="章节内容")
    subsections: list["ReportSection"] = Field(
        default_factory=list,
        description="子章节"
    )


class Report(BaseModel):
    """完整研究报告"""
    title: str = Field(description="报告标题")
    executive_summary: str = Field(description="执行摘要/概要")
    sections: list[ReportSection] = Field(description="报告章节列表")
    conclusions: str = Field(description="结论")
    recommendations: list[str] = Field(default_factory=list, description="建议")
    references: list[str] = Field(default_factory=list, description="参考来源")
    format_type: ReportFormat = Field(description="报告格式")


# ========== 生成提示词 ==========
REPORT_PROMPT_BRIEF = """你是一个专业的报告撰写者。请根据研究分析结果撰写一份简报。

简报要求：
- 标题简洁有力
- 执行摘要不超过 200 字
- 2-3 个核心要点
- 简短结论
- 适合快速阅读

用中文撰写。"""

REPORT_PROMPT_DETAILED = """你是一个专业的报告撰写者。请根据研究分析结果撰写一份详细报告。

详细报告要求：
- 结构完整：引言、方法、发现、分析、结论、建议
- 每个章节内容充实
- 引用具体证据
- 提出可操作的建议
- 适合深入研究

用中文撰写。"""

REPORT_PROMPT_ACADEMIC = """你是一个专业的学术报告撰写者。请根据研究分析结果撰写一份学术风格的报告。

学术报告要求：
- 严格遵循学术写作规范
- 摘要、关键词、引言、文献综述、方法、结果、讨论、结论
- 引用格式规范
- 语言严谨客观
- 适合学术场景

用中文撰写。"""


async def generate_report(
    llm,
    plan,
    analysis: AnalysisResult,
    report_format: ReportFormat = ReportFormat.DETAILED,
) -> Report:
    """生成研究报告"""
    structured_llm = llm.with_structured_output(Report)

    # 选择对应的提示词
    prompt_map = {
        ReportFormat.BRIEF: REPORT_PROMPT_BRIEF,
        ReportFormat.DETAILED: REPORT_PROMPT_DETAILED,
        ReportFormat.ACADEMIC: REPORT_PROMPT_ACADEMIC,
    }
    prompt = prompt_map[report_format]

    # 构建分析摘要
    analysis_summary = (
        f"关键发现:\n" +
        "\n".join([f"- {f.finding}" for f in analysis.key_findings]) +
        f"\n\n模式与趋势:\n" +
        "\n".join([f"- {p}" for p in analysis.patterns]) +
        f"\n\n分析总结:\n{analysis.summary}"
    )

    report = await structured_llm.ainvoke([
        SystemMessage(content=prompt),
        HumanMessage(content=(
            f"研究主题: {plan.main_question}\n"
            f"研究范围: {plan.scope}\n\n"
            f"分析结果:\n{analysis_summary}\n\n"
            f"参考来源: {', '.join(plan.sub_questions)}\n\n"
            f"请生成 {report_format.value} 格式的报告。"
        )),
    ])

    return report


def format_report_markdown(report: Report) -> str:
    """将报告格式化为 Markdown"""
    lines = [
        f"# {report.title}\n",
        f"## 执行摘要\n{report.executive_summary}\n",
    ]

    for section in report.sections:
        lines.append(f"## {section.title}\n{section.content}\n")
        for sub in section.subsections:
            lines.append(f"### {sub.title}\n{sub.content}\n")

    if report.conclusions:
        lines.append(f"## 结论\n{report.conclusions}\n")

    if report.recommendations:
        lines.append("## 建议\n")
        for i, rec in enumerate(report.recommendations, 1):
            lines.append(f"{i}. {rec}")
        lines.append("")

    if report.references:
        lines.append("## 参考来源\n")
        for i, ref in enumerate(report.references, 1):
            lines.append(f"[{i}] {ref}")

    return "\n".join(lines)
```

### 5. 迭代优化阶段

```python
"""迭代优化阶段 - 报告质量评估与自动改进"""

from pydantic import BaseModel, Field
from langchain_core.messages import SystemMessage, HumanMessage


# ========== 评估模型 ==========
class ReportEvaluation(BaseModel):
    """报告质量评估"""
    overall_score: float = Field(
        description="总体质量评分 0-1",
        ge=0.0, le=1.0,
    )
    completeness: float = Field(
        description="内容完整性 0-1",
        ge=0.0, le=1.0,
    )
    accuracy: float = Field(
        description="信息准确性 0-1",
        ge=0.0, le=1.0,
    )
    clarity: float = Field(
        description="表达清晰度 0-1",
        ge=0.0, le=1.0,
    )
    structure: float = Field(
        description="结构合理性 0-1",
        ge=0.0, le=1.0,
    )
    feedback: str = Field(
        description="具体的改进建议"
    )
    needs_revision: bool = Field(
        description="是否需要修订"
    )
    revision_focus: list[str] = Field(
        default_factory=list,
        description="需要修订的重点领域"
    )


# ========== 评估提示词 ==========
EVALUATION_PROMPT = """你是一个研究报告质量评估专家。

请从以下维度评估研究报告的质量：

1. 完整性：是否覆盖了研究计划中的所有子问题
2. 准确性：信息是否有据可查，是否存在明显的错误
3. 清晰度：语言表达是否清晰，逻辑是否连贯
4. 结构性：报告结构是否合理，章节安排是否得当

评分标准：
- 0.8-1.0: 优秀，可以直接输出
- 0.6-0.8: 合格，建议修订后输出
- 0.0-0.6: 需要大幅修订

如果评分低于 0.7，设置 needs_revision 为 true。
"""


async def evaluate_report(
    llm,
    report: Report,
    plan,
) -> ReportEvaluation:
    """评估报告质量"""
    structured_llm = llm.with_structured_output(ReportEvaluation)

    # 将报告转为文本
    report_text = format_report_markdown(report)

    evaluation = await structured_llm.ainvoke([
        SystemMessage(content=EVALUATION_PROMPT),
        HumanMessage(content=(
            f"研究计划:\n"
            f"- 核心问题: {plan.main_question}\n"
            f"- 子问题: {', '.join(plan.sub_questions)}\n\n"
            f"报告内容:\n{report_text}\n\n"
            f"请评估报告质量。"
        )),
    ])

    return evaluation


async def revise_report(
    llm,
    report: Report,
    evaluation: ReportEvaluation,
    plan,
    analysis,
) -> Report:
    """根据评估反馈修订报告"""
    structured_llm = llm.with_structured_output(Report)

    revision_prompt = f"""请根据以下反馈修订研究报告。

修订重点：
{chr(10).join(f'- {focus}' for focus in evaluation.revision_focus)}

具体反馈：
{evaluation.feedback}

要求：
1. 保持报告的整体结构
2. 针对反馈的每个问题进行改进
3. 补充缺失的内容
4. 纠正不准确的信息
"""

    revised_report = await structured_llm.ainvoke([
        SystemMessage(content=revision_prompt),
        HumanMessage(content=(
            f"原报告:\n{format_report_markdown(report)}\n\n"
            f"研究主题: {plan.main_question}\n"
            f"分析摘要: {analysis.summary}"
        )),
    ])

    return revised_report
```

## LangGraph 多阶段图

将所有阶段组装成完整的 LangGraph 工作流。

```python
"""LangGraph 多阶段研究工作流"""

from typing import Annotated, TypedDict, Optional
from langgraph.graph import StateGraph, START, END
from langchain_core.messages import BaseMessage


# ========== 状态定义 ==========
class ResearchState(TypedDict):
    """研究助手全局状态"""
    # 输入
    topic: str                           # 研究主题
    report_format: str                   # 报告格式: brief/detailed/academic

    # 规划阶段
    research_plan: Optional[dict]        # 研究计划

    # 收集阶段
    collected_info: list[dict]           # 收集到的信息

    # 分析阶段
    analysis_result: Optional[dict]      # 分析结果

    # 报告阶段
    report: Optional[dict]               # 生成的报告
    formatted_report: str                # 格式化的报告文本

    # 评估阶段
    evaluation: Optional[dict]           # 质量评估
    quality_score: float                 # 质量评分
    iteration: int                       # 迭代次数
    max_iterations: int                  # 最大迭代次数

    # 输出
    final_output: str                    # 最终输出


# ========== 节点函数 ==========
async def plan_node(state: ResearchState, llm) -> dict:
    """规划节点"""
    from planning import plan_research, format_plan

    print("\n[阶段1] 制定研究计划...")
    plan = await plan_research(llm, state["topic"])
    print(format_plan(plan))

    return {
        "research_plan": plan.model_dump(),
        "iteration": 0,
    }


async def collect_node(state: ResearchState, llm) -> dict:
    """信息收集节点"""
    from collection import collect_information, CollectedInfo
    from planning import ResearchPlan

    print("\n[阶段2] 收集信息...")
    plan = ResearchPlan(**state["research_plan"])
    collected = await collect_information(llm, plan)

    # 合并已有信息（如果是迭代）
    existing = state.get("collected_info", [])
    all_info = existing + [c.model_dump() for c in collected]

    print(f"[信息收集] 共收集 {len(all_info)} 条信息")

    return {"collected_info": all_info}


async def analyze_node(state: ResearchState, llm) -> dict:
    """分析节点"""
    from analysis import analyze_findings, AnalysisResult
    from collection import CollectedInfo
    from planning import ResearchPlan

    print("\n[阶段3] 分析信息...")
    plan = ResearchPlan(**state["research_plan"])
    info_list = [CollectedInfo(**i) for i in state["collected_info"]]
    analysis = await analyze_findings(llm, info_list, plan)

    print(f"[分析] 发现 {len(analysis.key_findings)} 个关键发现")

    return {"analysis_result": analysis.model_dump()}


async def report_node(state: ResearchState, llm) -> dict:
    """报告生成节点"""
    from report_generator import (
        generate_report, format_report_markdown, ReportFormat
    )
    from planning import ResearchPlan
    from analysis import AnalysisResult

    print("\n[阶段4] 生成报告...")
    plan = ResearchPlan(**state["research_plan"])
    analysis = AnalysisResult(**state["analysis_result"])

    # 解析报告格式
    format_str = state.get("report_format", "detailed")
    report_format = ReportFormat(format_str)

    report = await generate_report(llm, plan, analysis, report_format)
    formatted = format_report_markdown(report)

    print(f"[报告] 已生成 {report_format.value} 格式报告")

    return {
        "report": report.model_dump(),
        "formatted_report": formatted,
    }


async def evaluate_node(state: ResearchState, llm) -> dict:
    """评估节点"""
    from evaluator import evaluate_report, ReportEvaluation
    from report_generator import Report
    from planning import ResearchPlan

    print("\n[阶段5] 评估报告质量...")
    report = Report(**state["report"])
    plan = ResearchPlan(**state["research_plan"])

    evaluation = await evaluate_report(llm, report, plan)

    print(f"[评估] 质量评分: {evaluation.overall_score:.2f}")
    print(f"[评估] 需要修订: {evaluation.needs_revision}")

    return {
        "evaluation": evaluation.model_dump(),
        "quality_score": evaluation.overall_score,
        "iteration": state.get("iteration", 0) + 1,
    }


async def revise_node(state: ResearchState, llm) -> dict:
    """修订节点"""
    from evaluator import revise_report, ReportEvaluation
    from report_generator import Report, format_report_markdown
    from planning import ResearchPlan
    from analysis import AnalysisResult

    print("\n[修订] 根据反馈改进报告...")
    report = Report(**state["report"])
    evaluation = ReportEvaluation(**state["evaluation"])
    plan = ResearchPlan(**state["research_plan"])
    analysis = AnalysisResult(**state["analysis_result"])

    revised = await revise_report(llm, report, evaluation, plan, analysis)
    formatted = format_report_markdown(revised)

    return {
        "report": revised.model_dump(),
        "formatted_report": formatted,
    }


def output_node(state: ResearchState) -> dict:
    """输出节点"""
    print("\n[完成] 研究报告已生成！")
    return {"final_output": state["formatted_report"]}


# ========== 条件路由 ==========
def should_revise(state: ResearchState) -> str:
    """判断是否需要修订"""
    quality_score = state.get("quality_score", 0)
    iteration = state.get("iteration", 0)
    max_iterations = state.get("max_iterations", 3)

    if quality_score >= 0.7 or iteration >= max_iterations:
        return "output"

    return "revise"


# ========== 图构建 ==========
def build_research_graph(llm, max_iterations: int = 3):
    """构建研究助手工作流图"""
    graph = StateGraph(ResearchState)

    # 添加节点（使用闭包传入 llm）
    graph.add_node("plan", lambda state: plan_node(state, llm))
    graph.add_node("collect", lambda state: collect_node(state, llm))
    graph.add_node("analyze", lambda state: analyze_node(state, llm))
    graph.add_node("report", lambda state: report_node(state, llm))
    graph.add_node("evaluate", lambda state: evaluate_node(state, llm))
    graph.add_node("revise", lambda state: revise_node(state, llm))
    graph.add_node("output", output_node)

    # 定义边
    graph.add_edge(START, "plan")
    graph.add_edge("plan", "collect")
    graph.add_edge("collect", "analyze")
    graph.add_edge("analyze", "report")
    graph.add_edge("report", "evaluate")

    # 条件边：评估后决定是修订还是输出
    graph.add_conditional_edges(
        "evaluate",
        should_revise,
        {
            "revise": "revise",
            "output": "output",
        },
    )

    # 修订后回到报告生成
    graph.add_edge("revise", "report")
    graph.add_edge("output", END)

    return graph.compile()
```

"""研究助手 - 主入口"""

import asyncio
from dotenv import load_dotenv

load_dotenv()

from langchain.chat_models import init_chat_model
from graph import build_research_graph


async def run_research(topic: str, report_format: str = "detailed"):
    """执行研究任务"""
    print(f"{'='*60}")
    print(f"研究主题: {topic}")
    print(f"报告格式: {report_format}")
    print(f"{'='*60}")

    # 初始化 LLM
    llm = init_chat_model("groq:llama-3.3-70b-versatile")

    # 构建工作流
    graph = build_research_graph(llm, max_iterations=2)

    # 执行
    result = await graph.ainvoke({
        "topic": topic,
        "report_format": report_format,
        "research_plan": None,
        "collected_info": [],
        "analysis_result": None,
        "report": None,
        "formatted_report": "",
        "evaluation": None,
        "quality_score": 0.0,
        "iteration": 0,
        "max_iterations": 2,
        "final_output": "",
    })

    # 保存报告
    output_path = f"output/report_{topic[:20].replace(' ', '_')}.md"
    import os
    os.makedirs("output", exist_ok=True)
    with open(output_path, "w", encoding="utf-8") as f:
        f.write(result["final_output"])

    print(f"\n报告已保存到: {output_path}")
    return result


async def main():
    """主函数"""
    # 示例研究主题
    topics = [
        ("LangChain 1.0 的主要变化与迁移指南", "brief"),
        ("RAG 技术的最新进展与最佳实践", "detailed"),
    ]

    for topic, fmt in topics:
        await run_research(topic, fmt)
        print("\n" + "="*60 + "\n")


if __name__ == "__main__":
    asyncio.run(main())

## 常见错误

### 1. 结构化输出嵌套过深

```
错误: Pydantic 模型嵌套层数过多导致 LLM 输出不稳定
```

**解决方案**：限制嵌套层级，将复杂结构拆分为多次调用：
```python
# 不推荐：深层嵌套
class DeepModel(BaseModel):
    level1: Level1Model  # 包含 Level2Model -> Level3Model

# 推荐：扁平化或分步生成
class FlatModel(BaseModel):
    field1: str
    field2: list[str]
    field3: float
```

### 2. 工具调用循环

```
错误: Agent 无限循环调用同一工具
```

**解决方案**：
```python
# 设置最大迭代次数
agent = create_agent(
    model=llm,
    tools=tools,
    system_prompt=prompt,
    max_iterations=5,  # 限制最大工具调用次数
)
```

### 3. 状态更新遗漏

```
错误: 某个节点未返回所有必需的状态字段
```

**解决方案**：使用 TypedDict 明确所有字段，并在节点函数中确保返回完整：
```python
# 确保返回值包含所有需要更新的字段
async def my_node(state: ResearchState) -> dict:
    # ... 处理逻辑
    return {
        "field1": value1,
        "field2": value2,
        # 不需要返回所有字段，只返回变更的字段
    }
```

### 4. 异步调用错误

```
错误: RuntimeError: This event loop is already running
```

**解决方案**：
```python
# 使用 asyncio.run() 而非嵌套事件循环
if __name__ == "__main__":
    asyncio.run(main())

# 或在 Jupyter 中使用 nest_asyncio
import nest_asyncio
nest_asyncio.apply()
```

## 最佳实践

1. **阶段解耦**：每个阶段独立测试，确保输入输出格式一致
2. **状态最小化**：只在状态中存储必要信息，避免膨胀
3. **迭代次数限制**：设置合理的最大迭代次数（建议 2-3 次）
4. **质量阈值**：根据应用场景调整质量阈值，不必追求完美
5. **错误恢复**：每个阶段都应有超时和错误处理机制
6. **日志追踪**：记录每个阶段的输入输出，便于调试和优化
7. **增量更新**：修订阶段只修改需要改进的部分，而非重写整个报告
8. **缓存利用**：对相同主题的重复研究可利用缓存结果
