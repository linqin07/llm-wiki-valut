## 核心摘要

这是一套完整的 GoF（Gang of Four）设计模式 Java 实现指南，包含 23 种经典设计模式的详细说明、UML 类图和代码示例。资料按照创建型、结构型、行为型三大类组织，每种模式都包含意图定义、适用场景、关键代码和实际案例。

**主要内容：**
- 5 种创建型模式：单例、工厂、抽象工厂、建造者、原型
- 7 种结构型模式：适配器、装饰者、外观、桥接、代理、组合、享元
- 11 种行为型模式：责任链、命令、解释器、迭代器、中介者、备忘录、观察者、状态、策略、模板、访问者

**特色：**
- 结合实际开发案例
- 提供 UML 类图
- 包含多种实现方式（如单例模式的饿汉式、懒汉式、双重校验锁）
